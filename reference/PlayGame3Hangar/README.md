# Play_Game_3 격납고 상한 조사 — 2026-11-16

사용자의 ‘최종티어 항공모함 최대5격납고→100함재기’ 추정을 첨부 원형에서 확인했다. 정적 소스 조사이며 원형 또는 UE를 실행한 검사가 아니다. [발췌](source_excerpts.txt), [원본/ZIP 해시](provenance.json)를 보존한다.

| 원형 코드 | 확인값 |
| --- | --- |
| ShipState.gd:255 | FIGHTERS_PER_SMALL_SLOT=20 |
| DataCatalog.gd:272 CARRIER | 함재기 용량6×20=120, 소형함 상한99 |
| DataCatalog.gd:289 DREADNOUGHT | 함재기 용량5×20=100, 소형함 상한5 |
| DataCatalog.gd:298 BATTLECARRIER | 함재기 용량8×20=160, 소형함 상한99 |
| DataCatalog.gd:432/438/439 | 항모계열 초기 시설 배치에서 HANGAR 두 번 설치 |
| ShipLayout.gd:189~191 | 층수에 따른 설치 제한. 이 경로에5개 설치 상한 검사는 없음 |

따라서 원형의 용량값은 설치 격납고 수와 직접 일치하지 않는다. 확인한 코드/첨부 기획에서 ‘최종 티어 항모는 최대5개’ 근거를 찾지 못했으며, 구축전함의100이 과거 설명과 섞였는지도 입증할 수 없다. 제공되지 않은 다른 버전의 값을 추정해 확정하지 않는다.

**현행 규칙:** 사용자 명시대로 격납고시설1개당 소형함1척 또는 함재기20대. 5개일 때100은 산술 예시이며 함체/티어별 최대 설치수는 아직 결정하지 않는다. 원형의120/160이나 소형함99도 UE 확정 규칙으로 가져오지 않는다. [모함 명세](../../docs/CARRIER_OPERATIONS.md), [R15](../../docs/OPEN_QUESTIONS.md#r15)를 따른다.

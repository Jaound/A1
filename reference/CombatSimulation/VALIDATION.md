- 규칙 검사: `python -m unittest discover -s reference/CombatSimulation -p 'test_*.py' -v` — **22/22 통과**.

- 유효 평가: 함대320회+영웅560회+연동256회. 별도 해상도24회, 쉴드 지연 민감도16회. 교정/구버전/수정 후 재실행을 유효 표본수에 중복 합산하지 않았다.
- 파일: `results.json`은현행, `archive/results_v01.json`은이전후보. 영웅/연동 시드는4000번대이며 변경 없는 함대는1000번대 결과를 구성요소/입력 해시 검증 후 재사용했다.
- 해상도: 0.1/0.05초 비교12쌍 중3쌍에서 승자가 달랐다. 수렴 완료를 주장하지 않고 고정 스텝/분리 RNG/사건 시간 처리 후 재검증 대상으로 남겼다.
- 수치표/명세 참조의 로컬 링크 검사 통과. `git diff --check` 통과.
- 그래프는 원시 요약에서 PNG/SVG로 생성하고 시각 확인했다. 개별 시행의 승률 구간은95% Wilson이며 모델 밖 전장/플레이어 다양성을 포함하지 않는다.

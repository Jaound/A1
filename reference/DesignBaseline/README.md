# DesignBaseline v0.5

[영웅](../../docs/01_design/boarding/HERO_SYSTEMS.md) · [수리/보급](../../docs/01_design/fleet/REPAIR_LOGISTICS.md)

`v05.json`은D114의 두 확정 조건(전체세력 동시 영웅15명, 현장수리 비용1.5배/속도50%)을 구체화한 **미시뮬레이션 설계 데이터**다. 영웅1점/명·단계3/6/10/15·L20·스킬/성장/정원·수리속도/견적/적재 등 신규값은 제안이다. 초대형 무장과 기존 전체 함대 프로필은 변경하지 않는다.

```bash
python reference/DesignBaseline/validate_design.py
```

이 명령은JSON 산술/범위 일관성만 확인한다. 전투 엔진을 import하지 않고 시간을 진행하거나 전투/UE/기존모형 테스트를 실행하지 않는다. 과거 모형의 승률/전투시간은v0.5의 검증 결과가 아니다.

수리 재가동/인원/점령의 독립 상태, 실제 방/문·팀 정원·의무/정비/경험치·전체15명 배치/경제를 모두 연결한 시뮬레이션은 사용자 요청대로 후속 작업으로 보류했다.

D115는 영웅의 정체성과 표시 명칭을 초능력자·강화인간으로 변경했다. `heroes.concept`와 스킬 `display_name`은 설명/표시용이며 기존 키·수치·계산식은 유지한다. 과거 모형 프로필은 당시 입력으로 고정한다.

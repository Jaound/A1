# D116 통합 모형 검증

## 검사와 실행

- 규칙 검사 **36/36 통과**: 쉴드 활성 회복 금지/무지연/인원 영향, 무장 초과 피해의 선체 미전달, 적 정보 비공개/탐지 상실, 개인12포드, 강습선PD 금지, 실제 자원/비용/수리 비중첩, 실제 함교 재탈환, 성장/스킬 예산, 전체 세력15명, 완파 사망, 유폭 재발생/연결 장갑/점령 명령/살보 소속, 강습선 회수/비상 탈출 준비.
- 주 결과 **111조건·1328개 결과**. 독립 선내816회는 코드/초기화 의존성 동일성 증명 후 재사용했다. 네 경계 오류 수정 뒤 함대/연동512회를 재실행했고, 강습선 귀환 후속 수정 뒤 해당104회를 다시 실행했다. 단계별 중복 시행을 표본에 합산하지 않는다.
- 보조 **40회**: 세력 배치6/10/15명, 좌측 무장 무력화/선체 명령 비교.
- 연속 교전 **16개 시나리오**, 각 최대2교전: 손상/인원/영웅/소모품/기체/화물 유지. 무상 정비/재생성 없음.
- 저장 결과 검증: 원본 입력/현재 코드 해시, 요약 재계산, 사례별 표본 수,16함종 포함, 영웅 수 보존/한도, 개인ID·작전 시각, 재사용 원문 동일성·변경 메서드 범위, 연속/보조 해시.

```bash
python -X utf8 -m unittest discover -s reference/IntegratedCombat -p 'test_*.py' -v
python -X utf8 reference/IntegratedCombat/verify.py
python -X utf8 tools/check_docs.py
```

전체 반복 실행/조건 선택·선택 재사용 명령은 [README](README.md), 수치/결과 해석은 [보고서](../../docs/04_analysis/INTEGRATED_COMBAT_RESULTS.md)를 따른다. `verify.py`는 저장 결과를 검사하며 새 전투를 실행하지 않는다. Windows의 한국어JSON은UTF-8 모드로 읽는다.

## 판정의 범위

검사 통과는 Python 모형의 지정 계약과 데이터 일관성이다. UE 빌드/PIE/실제 입력·최종3D 에셋을 실행하지 않았다. 임시 방 그래프, 표본 외부 피격/비행 근사, 그룹 함재기, 기본 PD 처리 순서를 사용한다. 전체 문 봉쇄/비상탈출·포로 확보·복수 강습팀/구조 경쟁·기지전·5시간 성장/경제는 완성된 범위가 아니다.

일반 혼성전 종료 중앙값100/200/300은 약18.02/19.34/15.50분으로 **목표10~15분 최종 밸런스 미달**이다. 작은 표본의 승률을 보편 승률로 제시하지 않으며 시간 간격 민감도도 보고한다. 초대형 함체/무장/전용 주포 수치는 변경하지 않았다.

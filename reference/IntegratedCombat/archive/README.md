# D116 경계 검토 전 평가 — 현행 결과 아님

첫1328회 평가를 마친 뒤 추가 경계 검사에서 네 오류를 재현했다. 외부 시설 파괴의 연결 장갑 누락, 수리 후 탄약고의 영구 유폭 면역, 목표 명령 없는 방의 자동 점령, 공격자 나포 뒤 미발사 살보 잔존이다. 이 결과를 최종 밸런스 자료로 쓰지 않고 소스/입력/원시 결과를 보존했다.

- `results.json.before_review.gz`: 수정 전1328회 원시 입력/해시/결과, gzip JSON.
- `continuation_results.json.before_review.gz`: 수정 전 연속 교전 진단.
- `*.before_review.txt`: 해당 평가 당시의 소스/입력 원문. 원래 파일명으로 별도 임시 폴더에 복원하면 당시 결과 재현에 사용할 수 있다. 현재 작업 파일을 덮어쓰지 않는다.

수정 후 함대/연동/민감도512회를 재실행한다. 독립 선내전816회는 `indoor.py`, 프로필, `indoor_trial`, 함선/유닛 초기화와 관련 함수가 동일함을 AST/해시로 증명하고 재사용한다. `dependencies.py`가 이를 검사하고 새 `results.json.reused_indoor`에 출처/해시/표본 수를 기록한다. 선내 결과를 새 규칙으로 재계산했다고 표기하지 않는다. 수정 전/후 중복 시행을 합쳐 표본수를 부풀리지 않는다.

현행 결과는 [최신 보고서](../../../docs/04_analysis/INTEGRATED_COMBAT_RESULTS.md)를 따른다.

`post_guard_review/`는 위 네 오류 수정 후의 평가/보조 원시 결과와 입력/소스다. 이후 강습선 진입자가 포드로 귀환하는 경로를 수정했다. `refine.py`가 프로필/선내/실행기 동일성과 변경 메서드2개를 검사하고 강습선 모드104회만 재실행했다. 나머지1224회는 강습선 귀환 분기를 실행하지 않는 조건이므로 재사용하며 원시 `extraction_refinement`에 근거/해시를 기록한다. 연속 교전/보조40회는 따로 재실행한다.

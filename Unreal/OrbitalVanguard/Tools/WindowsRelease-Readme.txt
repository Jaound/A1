Orbital Vanguard | Windows 64비트 배포본

1. ZIP 전체를 로컬 폴더에 압축 해제하세요.
2. 맨 위 폴더의 OrbitalVanguard.exe를 실행하세요. Engine과 OrbitalVanguard 폴더는 함께 두세요.
3. 타이틀에서 시스템 실습 또는 작전 개시 · 임무 선택을 누르세요. 일시정지한 전투는 Space로 재개합니다.

언리얼 에디터, 소스 프로젝트, 개발 도구 설치 없이 실행할 수 있습니다.
첫 실행에서 Microsoft Visual C++ 런타임이 필요하면 실행기의 설치 안내를 따르세요. 설치 파일은 Engine/Extras/Redist/en-us/vc_redist.x64.exe에 포함되어 있습니다.

기본 그래픽은 DirectX 12입니다. 새 사용자 설정에서는 최상 화질로 시작합니다. 이전 버전의 설정을 사용 중이라면 환경 설정에서 그래픽 품질을 ‘최상 · 시네마틱’으로 바꾼 뒤 적용하세요.
DirectX 12 실행이 어려운 기기에서는 같은 실행 파일에 -d3d11 옵션을 붙여 DirectX 11 호환 모드로 실행할 수 있습니다.

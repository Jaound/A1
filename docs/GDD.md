## 정체성과 핵심 경험

싱글플레이 중심의 지속형 우주 세력 RTS다. 플레이어는 AI 세력과 경쟁하며 자원을 확보하고 기지·함대·영웅을 성장시킨다. 전투·경영·전략·캐릭터 성장이 연결되며, 일시정지/1/2/3배속을 지원한다.

핵심은 **XYZ 입체 함대전과 목표 지향형 선내 자동 전투의 상호작용**이다. 함대는 3D로 지휘하고, 영웅과 병력은 2D 애니메이션의 ‘움직이는 설계도’에서 목표에 따라 이동·교전한다.

## 기본 플레이 순환

성계·항로 파악 → 기지에서 함선/시설/영웅 준비 → 채굴·탐사·호위·약탈·방어·거점 공격 → 함대전과 선내 작전 → 자원/전리품 회수 → 수리·충원·연구·성장.

## 3D와 2D의 상호작용

| 사건 | 다른 전장에 반영되는 결과 |
| --- | --- |
| 적 쉴드제어실을 모두 점령/파괴해 가동 불가 | 적함 쉴드 소멸, 함대 집중 포격 기회 |
| 적 엔진을 모두 무력화 | 이동·선회/회피 및 FTL 제한 |
| 특정 외벽 구획에 포격 | 대응 시설·인원 피해와 화재/감압 위험. 발생 조건·환경 피해 수치는 미정 |
| 함교 점령 | 소유권 이전과 기존 명령 취소. 잔존 적에 의한 재탈환 가능 |
| 영웅 지원/보직 변경 | 함대의 버프·방어·수리 능력과 선내 전투 편제 변화 |

## 긴장감과 손실

함선은 전체 체력 0 또는 코어 파괴 시 완파되며 내부 인원은 사망한다. 영웅 사망과 기체 완파는 영구 손실이다. 비행 중 포드가 격추된 영웅은 구조 또는 적의 납치 대상이 될 수 있다. 시설 수리와 승무원 충원은 별도 자원 행위다.

## 제작 방향

UE5의 단일 시뮬레이션에 3D 전투와 2D/3D 표시를 연결한다. 장기 검증 목표는 ‘강습→쉴드실 무력화→집중 포격→탈출’이며 현재 단계 완료 조건과 혼동하지 않는다. 실제 진행은 [구현 상태](IMPLEMENTATION_STATUS.md), 다음 외부 전투 범위는 [2단계 계획](PHASE2_PLAN.md)을 따른다. 미정 정책은 [한곳에서 관리](OPEN_QUESTIONS.md)한다.

입체 기지의 연결/생산 규칙은 [기지 명세](BASE_SYSTEMS.md), 새 수치·기술/무장 해금 경로 제안은 [밸런스 초안](BASE_BALANCE_DRAFT.md)에서 구분해 관리한다.

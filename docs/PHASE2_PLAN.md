## 2B의 실행 순서

### 2B-1 기본 공격 연결

무장 계열/종류/티어/위치/사거리/주기/피해/탄속을 분리한다. 빔 한 종류로 표적 지정→발사 요청→조건 판정→실제 공격→기존 쉴드/장갑/시설/선체→완파를 연결한다. 탐지 단순화가 필요하면 DEV 설정으로 격리하고 2B 최종 완료 전에 정식 규칙으로 바꾼다.

### 2B-2 탐지·포탑·발사 조건

보장 근거리·자체/공유 레이더·최선 유효 보정·레이더함 지원, 로컬 상하 사각/±15도·포탑 회전·발사각을 구현한다. 선체 자세를 포탑 추적으로 덮어쓰지 않는다. 탐지 상실 후 신규 발사와 이미 발사된 공격을 구분한다. R20/R22 및 시설 가동 조건을 확인한다.

### 2B-3 함포·미사일 확장

포탄/일반 미사일 고정 경로와 유도 미사일 추적, 종류/티어별 탄속/주기/살보를 추가한다. 일반 미사일 VLS·잔여 살보는 R10, 명중률과 물리 판정 결합은 R21이다. 미사일 요격은 2C다.

### 2B-4 상호 교전·UI·회귀

플레이어 수동 발사와 자동 교전, 최소 적 교전 AI를 연결한다. 표적/발사/모드를 분리하고 이동/자세/Hold/FTL 제약을 지킨다. 자동 사선 확보와 아군 충돌 정책은 R12/R21을 확인한다. 복잡한 세력 전략 AI·완성 편대 UI는 이번 범위가 아니다.

HUD에 표적·탐지 출처·발사 차단 이유·쿨타임·공격/피해 결과를 표시한다. 프리뷰/효과가 발사나 피해를 재실행하지 않는다. 기존 조작/창 제스처를 보존한다.

## 피해·상태 경계

개별 무장 HP, 무기제어실, 계열 공급, 점령/인원을 독립 검사한다. 외장 무장 피격의 선체 전달은 R14이며 DEV 직접 피해를 확정 전달식으로 승격하지 않는다. 이미 발사한 공격은 발사 당시 소속/무장 정보를 보존한다. 공격자/목표 완파·목표FTL 이탈·유도 만료와 취소를 구분하며 피해·유폭·완파는 한 번만 처리한다.

## 검증과 인수

- Win64 Editor 빌드 및 기존17자동/57API의 회귀, 이번 기능의 의미 있는 추가 검사.
- 사거리·탐지·사각·포탑 정렬·시설 정지별 발사 차단, 실제 공격→기존 피해→완파.
- 탐지 상실 후 공격 수명, 발사자/목표 완파·이탈·중복 명중, 고속 투사체 저FPS/배속 판정.
- 난수 시드 등 재현성을 갖추고 같은 게임 시간의 1/2/3배속 발사 수·피해·투사체 결과 비교.
- 실제 마우스의 표적 지정·수동 발사·자동 전환. 도구 실패 시 API 성공과 분리해 미검증 기록.
- 단계별 GUIDE/VALIDATION·진행/재개 기록과 체크포인트. 소스·설정·자산이 바뀐 뒤 관련 검증 근거를 갱신한다.

2B 완료는 실제 교전이며 DEV 피해 버튼만으로 대체하지 않는다. 선내 강습·생명유지 사망·정식 나포·PD·격납고·전략경제 전체를 2B에 포함하지 않는다. R11/R14 등 임시 선택이 남으면 적용값과 미완료 범위를 명시한다.

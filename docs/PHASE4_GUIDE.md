# 개발 현황과 보유 영웅 운용 안내

이 문서는 개발 중인 카탈로그·영웅 확장의 사용법이다. 검증 완료 범위는 `PHASE4_PROGRESS.md`와 `PHASE4_VALIDATION.md`를 먼저 확인한다. 이전 F5/F6/F7 및 최소 통합 임무는 보존한다.

## 시작과 화면

`Unreal/OrbitalVanguard/Tools/RunMission.ps1 -Mode Attack` 또는 `RunEditor.ps1`로 실행한다. 에디터는 Play를 누른다. 기본 임무의 영웅은 회귀용 예시 인원이다. 실제 보유 영웅과 같은 개체로 간주하지 않는다.

- **Insert**: 개발 메뉴. 통합 현황·함선/초소형함·영웅·무장 탭과 검색/분류/스크롤을 사용한다.
- **영웅 명단**: 일반 플레이 HUD에서 보유 명단과 실제 인원의 위치를 확인한다. 창 자체 닫기와 다시 열기를 지원한다.
- 기존 카메라/XYZ 이동·이동 자동화/사격 자동화·Hold·시간 제어는 기존 조작 가이드를 따른다.
- 검사 상태는 기획 정의 / 데이터 / 생성 / 역할 / 자동 검사 / 직접 입력을 별도로 표시한다. 과거 코드의 성공은 해당 SHA의 근거이며 현재 코드 직접 플레이 완료를 의미하지 않는다.

## 보유 영웅으로 플레이하기

1. **비전투 편성실**로 들어간다. 작전 중이거나 이탈 함선에 남은 영웅을 이 버튼으로 무료 회수할 수 없다.
2. 개발 메뉴의 영웅 탭에서 **시험 대표 4명 생성** 또는 유형별 생성을 사용한다. 이는 이번 샌드박스의 명시적 DEV 공급이며 정상 캠페인 영입/부활이 아니다.
3. 원하는 보유 영웅을 **편성 예약**한다. 동시에 배치하는 영웅은 세력 전체 15명까지이며 현재 소규모 보유 임무는 1~4명을 사용한다.
4. 플레이 영웅 창에서 **보유 편제로 공격 임무 시작**을 누른다. 준비 상태에서는 F1로 진행한다. 같은 HeroId가 실제 UnitId·PersonId에 연결된다.
5. 실제 함대 공격으로 쉴드를 제거한 다음 기존 포드/강습선 명령을 사용한다. 선내 창에서 인원을 선택하고 시설 점령·공작·수호·철수를 지시한다. 원 진입점까지 이동한 뒤 원 운송수단으로 회수한다.
6. 실제 결과와 참여/시설 기여에 따른 경험치·레벨을 확인한다. 임무 종료 후에도 외부 전투는 계속될 수 있다. 회수 후 편성실에서 성장/스킬 투자를 하고 저장한다.

시험 XP 지급은 DEV 기능이다. 정상 XP와 출처가 다르다. 후보 성장식·L1/5/10/15 해금·랭크·유한 촉매/증폭기는 담당 `HERO_SYSTEMS.md`를 따른다. 재선택·귀환·레벨업·UI 갱신으로 HP나 소모품을 채우지 않는다. 스킬은 현재 자동 사용 정책이며 상세 설명에서 조건/효과/해금을 확인한다.

보직은 아군 함선의 지정 시설까지 실제 이동한 뒤 3초 인계를 거친다. 운영 인원0·시설 파괴·적 점령을 무시하지 않는다. 공격/이동/강습 전환은 기존 효과를 해제하고 재사용 대기는 유지한다. 보유 영웅 배치에서는 별도 D114 조준 프로필을 적용한다. 빔 상한98%, 비빔은 최상 레이더+영웅 보정으로 조준 오차를 줄인다. 과거 영웅 없는 회귀 장면은 기존 조준 프로필을 유지한다.

## 함선과 무장 시험

1. F6 후보 장면 또는 F7/통합 임무에서 Insert를 연다. 기존 조작 시험장을 생성 명령이 몰래 초기화하지 않는다.
2. 함선 정의를 고르고 소속0/1, 수량, XYZ·간격(**cm**), 격납고당 초기 재고0~20기와 병력0~12명을 입력한다. 이동/사격 자동화는 독립이다.
3. 겹침이나 이동 범위 밖이면 실패 이유가 표시된다. 실제 실행 함선 목록에서 선택·추적·선내 지도로 이동한다.
4. 무장 탭에서 실제 장착점을 고르고 허용된 계열/티어의 프로필을 선택한다. 표적 지정과 발사 요청은 별개이며 시설·사거리·탐지·상하부 사각·포탑 조준을 우회하지 않는다.
5. 함재기는 선택 모함의 실제 격납 재고를 출격/회수한다. 포드는 실제 승객과 발사 시설을 사용한다. 프로필 선택이 무료 기체나 승객 생성은 아니다.

시험 함선 삭제는 이 개발 창에서 만든 함선에만 허용한다. 미귀환 함재기·생존 승객·원 포드 연결이 있으면 거부한다. 삭제할 때 격납된 **시험 재고도 명시적으로 폐기**하며 캠페인 재고로 반환하지 않는다. 이미 발사된 공격의 발사 당시 소속과 무장 정보는 유지한다.

초대형 2종의 T3 일반 무장/T4 전용 주포와 유폭을 유지한다. 함선 화력을 낮추거나 모든 장착점을 같은 티어로 바꾸지 않았다. 외형과 선내 구조는 임시 형상이다.

## 지원함과 저장의 경계

지원함 창의 자원 노드/재료/원가 견적은 **유한 DEV 공급**이다. 채굴은 노드 잔량과 화물 용량, 수송은 실제 양측 재고/거리, 시간 기반 선체 수리는 준비 시간·거리·시설·소유·실제 재료 소비를 검사한다. 일반 피격이나 발사만으로 수리를 끊지 않는다. 시설/장갑/무장 전체 수리와 기지 견적 자동 계산·경제 UI는 현재 지원 범위가 아니다.

명단 저장은 비전투 상태에서만 지원한다. HeroId·성장·스킬·HP·소모품·쿨타임·배치/손실 상태를 저장하며 전장 Actor를 저장하지 않는다. 전투 장면 재시작과 보유 명단 초기화는 같은 명령이 아니다. 구조 대기·포로/실종·사망을 무료 복귀나 부활로 바꾸지 않는다.

## 5~10분 직접 확인 목록

- 개발 메뉴 열기/검색/탭 전환/닫기. 작은 창에서도 스크롤하여 버튼을 찾을 수 있는가?
- 텍스트 입력 중 WASD·R·숫자가 전장 명령으로 새지 않는가? 창 뒤 우클릭 이동/회전이 발생하지 않는가?
- F6에서 함선1척을 겹치지 않게 생성하고 선택·추적·실제 장착점/차단 이유를 확인한다.
- 편성실에서 시험 영웅4명을 만들고 편성한다. 보유 임무에서 위치와 역할이 보이는가?
- 실제 쉴드 제거→강습→선내 시설 목표→원 진입점 철수→손실/성장을 확인한다.
- 일시정지/1·2·3배속, 포커스 상실·복귀와 창을 닫은 후 카메라 조작을 확인한다.

이 목록은 사용자 확인 절차다. API 검사나 화면 캡처만 수행한 항목을 직접 입력 성공으로 간주하지 않는다.

# 미결정 정책과 시험값

> 2026-11-16. 미결정 상세를 관리하는 단일 목록이다. 기존 R09~R19를 유지하고 새로 드러난 항목은 R20~R28로 확장했다. 항목에 대안이 적혀 있어도 채택된 규칙이 아니다.

## 사용 원칙과 우선순위

현행 명세는 결정된 부분을 실행하고, 미결정 의존 부분만 임시 프로필/시험 모드로 분리한다. 최종 완료를 선언하기 전에 해당 정책을 결정하거나 미완료 범위를 명시한다. 미정 수치 하나 때문에 관련 없는 시스템 전체를 멈추지 않는다.

| 적용 전 | 먼저 볼 항목 |
| --- | --- |
| 2B 사격·탐지·포탑 | R10, R14, R20~R23, R11의 임시 정책 유지 |
| 2C 요격·모함·포드 | R09, R15, R18, R25~R26 |
| 최종 기동/충각 | R12, R16, R24 |
| UI 기능 확장 | R13, R19, R27 |
| 3단계 선내 작전 | R18, R23, R26 |
| 전략·성장 | R28 |

<a id="r09"></a>

## R09. 요격 확률

최신 명시식은 `기본 명중률−대상 회피율`이다. 레이저 72%/실탄 62%에서 함재기 62%를 빼면 10%/0%, 포드 40%는 32%/22%, 미사일 25%는 47%/37%다. 실탄의 함재기 완전 면역이 의도인지 결정해야 한다. 최소 명중 보장 또는 `명중×(1−회피)`는 대안이며 자동 채택하지 않는다. 회피를 두 번 판정하지 않는다. 담당: 함대, 2C 전.

<a id="r10"></a>

## R10. 일반 미사일 곡선·살보

발사 후 표적 유도 금지와 VLS 곡선을 연결해야 한다. 발사 순간 고정한 곡선/탄도와 실시간 유도를 나누는 것이 추천안이다. 살보 중 표적 상실·시설 파괴·취소·완파 시 미발사 잔여탄 처리, 쿨타임 기산점·탄간 간격은 미정이다. 담당: 함대, 2B 전.

<a id="r11"></a>

## R11. 쉴드 완충 상태 전이

확정: 활성 전투 회복 금지, 파괴 후 회복·50% 재가동, 비피격 15초 후 완충 예외, 기준 3%/게임 초. 미정: 15초 후 즉시 100%인지 점진 회복인지, 수동 충전 시 소등·피격 중단 여부. 딜레이 6.5초는 프로토타입 값이다. 2A는 **Gradual 임시·수동 전환 비활성**이며 확정으로 승격하지 않는다. 담당: 함선.

<a id="r12"></a>

## R12. 자세·진형·Hold·접촉·FTL 우선순위

정리된 부분: 명시적 수동 자세의 모든 축 보존, Hold는 새 이동 전까지 유지, FTL 중 추진/자동 사선 재배치 금지. 남은 부분: 자동 교전과 편대 정렬 전환, Hold 중 사선 확보 허용 조건, 이동 불가/FTL 고정 함선끼리 겹친 경우 접촉 해소, 관성 중 FTL 시작 경계. 2A가 양쪽 이동 불가일 때 분리하지 않는 것은 임시 구현 한계다. 담당: 함대.

<a id="r13"></a>

## R13. 최종 키·핀·창 수명

PlayGame3/P 비교·RMB release/V 정밀·그룹 1~9·F1~F4 시간 제어는 현재 구현 기준이다. 미정: 무장 그룹 기본키(숫자 1~3과 충돌 금지), 추가 발사 입력·키 재매핑, Q/E·고도/센서·ESC 최종 배치. 미선택 시 **비고정** 상세창 숨김은 정리됐으나 핀 창 예외·닫기/선택 유지·재선택/소유 변경/파괴 시 수명은 미정이다. 담당: UI.

<a id="r14"></a>

## R14. 외장 무장 HP의 피해 전달

개별 무장 HP와 파괴 시 발사 금지는 확정이다. 외장 포탑 피격이 쉴드·장갑·시설·선체에 어떤 순서/비율로 전달되는지 미정이다. 동일 피해를 여러 곳에 원래 값으로 중복 적용하지 않는다. 2A 직접 무장 시험 피해는 선체에 전달하지 않는 임시 정책이다. 담당: 함선+함대, 무장 피격 연결 전.

<a id="r15"></a>

## R15. 격납고 수용량

확정: 소형함 1 : 함재기 20 공간 환산, 일반 대형/초대형의 수납 소형함 최대 5척, 항모의 해당 일반 제한 예외. 미정: 격납고 하나의 용량·중형 설치 허용 범위·혼합 수납·‘최대 100대’의 시설/모함/시험 예산 구분·초대형 항공순양함의 항모 예외 여부. 항모 무한 공간으로 해석하지 않는다. 담당: 모함.

<a id="r16"></a>

## R16. 상대 밸런스의 기준

1:5는 평균 전투 결과 목표이며 HP/DPS/슬롯을 각각 5배 하지 않는다. 이동/선회 50% 하향, 무장 HP/수리 속도 2배, 크기 1/1.10/1.21/1.33은 프로토타입 비교 방향이다. 원형 버전·절대값·단위와 최종 함체 형상을 정해야 한다. 선회 rad/s, 기체 hull 160/shield 75 같은 참조값도 UE 최종 밸런스로 자동 사용하지 않는다. 최소 장갑 마모의 적용 위치/수치·중복 피해 방지도 미정이다. 담당: 함대+함선+모함.

<a id="r17"></a>

## R17. 층·장갑·코어 세부

확정: 실제 층별 14/26/38, 3층 코어 2F, 전/후 단일 면 예외, 사보타주 장갑 보존. 미정: 2층 단일 코어의 다층 점유 형상, 함체별 그리드 경계/모서리 귀속, 1/2층 시설 파괴의 다중 외면 연결. 3층 전용 관통을 1/2층으로 확대하지 않는다. 담당: 함선.

<a id="r18"></a>

## R18. 나포·완파·운용 동시 사건

확정: 완파 판정은 연출 전에 적용, 나포 시 기존 명령 취소·발사 당시 공격 보존, 외부 함재기 새 소속/관제 복구 분리. 미정: 함교 상주 유예 만료의 결과·재탈환 경합·나포 직후 적 자동 표적 우선 완화 시간·강습 웨이브 선도 실패/방 파괴 재선정·동일 시점 도킹/포획/완파·외부 독립 소형함 귀속. 담당: 선내 작전+모함.

<a id="r19"></a>

## R19. 뷰어 기술 선택

확정: 하나의 시뮬레이션을 읽는 프리뷰, UI 입력 격리·숨김 갱신 중단·정보 비공개. 미정: UE 런타임 표시 프록시/SceneCapture 구성과 성능 예산. Godot API는 UE 실행 지시가 아니다. 담당: UI/UE 기술.

<a id="r20"></a>

## R20. 포탑 추적 유지 타이머

‘발사 후 3.5초 추적’과 ‘목표 상실 후 3.5초 유지’가 공존한다. 마지막 발사/유효 관측/상실 중 기산점, 재발사 갱신·상실 후 조준 위치를 결정해야 한다. 시각적 유지가 신규 발사 허가를 유지하는 것은 아니다. 담당: 함대, 2B.

<a id="r21"></a>

## R21. 명중·투사체·아군 사선

명중률 판정과 실제 투사체 충돌의 결합, 표적 기동 회피 반영 방식, 빗나간 탄의 타 함선 피격·아군 피해/발사 차단·일반 무장의 함재기 우발/범위 피해가 미정이다. 자동 사선 회피 지침만으로 아군 투과/무적을 확정하지 않는다. 담당: 함대, 2B.

<a id="r22"></a>

## R22. 탐지 수치·유효성

보장 근거리, 티어별 탐지 거리·명중 보정, 일반 공유율, 레이더함 약 80%의 최종 계수·혼합 티어/중복 계산·외부 기지 탐지·정보 지연/차폐 여부가 미정이다. 최선 정보원은 ‘사격 함선에 적용된 유효 보정’ 기준이며 중복 제어실이 거리 스택을 만들지 않는다. 담당: 함대, 2B.

<a id="r23"></a>

## R23. 시설·피해·수리 수치

쉴드 초과분 비율, 장갑 경감/마모, 시설→선체/빈 슬롯 배율, 혼합 무장 티어의 유폭 합산·범위/계수, 사보타주 유폭의 원인 전파, 중복 시설별 화력/연사/정비 배율·상한, 복구/충원 속도·비용·거리·접근/수리 우선 동률 처리 등이 미정이다. 공급 시설이 버프하는 세부 스탯을 일반 중복 효율 하나로 전부 곱하지 않는다. 선택 시설 경고와 탑재 운용 필수 검증의 상세도 필요하다. 담당: 함선/경제.

<a id="r24"></a>

## R24. 충각·가속

충각 피해의 상대 속도/질량 계수·자해 경감·1초 쿨타임의 최종값, 빠른 충돌의 Sweep/연속 판정, 과부하 열/손상·지속/해제 조건이 미정이다. 안전거리 8m·충각 1초는 프로토타입 참조값이다. 담당: 함대.

<a id="r25"></a>

## R25. FTL·함재기 귀환·정지

체급별 충전 시간, 동시 도약 실패·대기·취소, 함재기 긴급 회수 완료 전 도약 여부, 비전투 5초 판정 기준, 실시간 재무장과 출격 지속 한계의 관계, 다중 격납고 대체 도킹, 모함 이탈/완파 후 정지 기체의 표류·회수/재귀속은 미정이다. 담당: 함대+모함.

<a id="r26"></a>

## R26. 선내 생존·진입·작전

진입 고도는 대상 로컬 기준이나 상/하 반구와 측면 중앙 중층 예외의 경계·우선순위가 미정이다. 첫 포드 슬롯 공개 범위/유지, 방어 상주가 초기 편제인지 전투 중 강제인지·중복 시설 적용·영웅 상주 인정, ‘내부 인원 전멸’의 승무원/영웅/분대 집계, 무인 보안 시설만 남았을 때 상태, 생명유지 사망 시간·우주복 완전 면역/저항, 방 제어점 방해·체크포인트 단축 환산·공작 완료 방식·점령 중단, 강습선/비상 탈출/구조/포로 판정이 미정이다. 영웅 구조/납치/사망 동시 확정은 하나만 적용한다. 담당: 선내 작전+함선.

<a id="r27"></a>

## R27. 자동 일시정지 옵션과 중복 알림

중요 사건 자동 일시정지는 최신 결정으로 유지한다. 1배속 강제 감속은 기본 대체 규칙으로 사용하지 않는다. 이벤트 묶음·중복 억제·옵션/해제·재개 배속·타 성계 교전 지침이 미정이다. 담당: 전략+UI.

<a id="r28"></a>

## R28. 전략·경제·AI·성장 상세

성계/항로 수·이동/보급 비용·차단/우회·전초 전문화 변경/점령·자원 채굴/정제/생산/유지비·상위 대체 비율·함종 장비 교체 자유도·세력/외교/난이도/정보·저장 상세가 미정이다. 영웅 획득/성장/장비/임무 제한·최대 분대/체급별 방어 영웅 수·보직 전환 비용/시간·스킬/버프 범위도 미정이다. 담당: 전략·경제/영웅.

## 임시값 기록 요건

각 임시 프로필은 값·단위·원형/코드 커밋·적용 기능·미결정 R번호를 기록한다. 기획 확정과 사용자 승인을 대신하지 않는다. 2A Gradual·무장 직접 피해 선체 미전달·1/2층 연동은 [구현 상태](IMPLEMENTATION_STATUS.md)에서 현재 적용 여부를 확인한다.

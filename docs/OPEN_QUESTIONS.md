# 정책 결정 상태·미결정·시험값

> 2026-11-16. 정책의 결정 상태와 남은 미결정을 관리하는 단일 목록이다. 2026-11-16 사용자 확정으로 해결된 부분은 완료 표시하고 R번호를 유지한다. 기존 R09~R19를 유지하고 새로 드러난 항목은 R20~R31로 확장했다. 항목에 대안이 적혀 있어도 채택된 규칙이 아니다.

## 사용 원칙과 우선순위

현행 명세는 결정된 부분을 실행하고, 미결정 의존 부분만 임시 프로필/시험 모드로 분리한다. 최종 완료를 선언하기 전에 해당 정책을 결정하거나 미완료 범위를 명시한다. 미정 수치 하나 때문에 관련 없는 시스템 전체를 멈추지 않는다.

## R09. 요격 확률 — 결정 완료

**확정(D091):** `clamp(명중률×(1−회피율),0,1)`. 뺄셈식은 폐기하고 추가 회피 주사위는 굴리지 않는다. 현 시험값에서 레이저/실탄의 명중은 함재기27.36/23.56%, 포드43.2/37.2%, 미사일54/46.5%다. 기본 스탯 밸런스는 계속 프로필로 조정한다. 담당: 함대, 2C.

## R10. 일반 미사일 곡선·살보 — 원칙 결정, 수치 잔여

**확정(D087/D088):** 일반 미사일은 발사 시 고정한 VLS 곡선이며 움직이는 표적을 따라 수정하지 않는다. 살보 각 탄 직전 발사 조건을 재검사하고 조건 상실 시 미발사 잔여탄 취소, 발사된 탄 유지. **남은 결정:** 쿨타임 기산점·탄간 간격·자원 소모 기산점. 담당: 함대, 2B.

## R11. 쉴드 회복 — 원칙 결정, 속도 잔여

**확정(D083):** 전투/비전투 모두 **파괴되어 비활성일 때만 점진 회복**하고 펼쳐져 있으면 회복하지 않는다. 전투/비전투 회복 속도를 차등 설정한다. 50% 자동 재가동은 유지하므로 재가동 후 회복이 멈추며 자연 완충하지 않는다. 기존 비피격15초 후 활성 완충 예외와 2A의 활성 Gradual은 대체됐다. **이전 시험(D111):** [전투 수치v0.2](COMBAT_BALANCE.md)은 전투3%/비전투6%·피격마다6.5초 지연 초기화를 시험 가정으로 사용한다. 이는 딜레이 갱신 정책의 최종 확정이 아니다. **남은 결정:** 두 속도·전투 판정/전환 시점·딜레이의 최종값과 비활성 중 재피격의 지연 초기화 여부. 전투3%/s·비피격15초·딜레이6.5초는 기존 출발값이며 비전투 속도는 미정. 수동 소등을 파괴로 간주하는 우회/새 완충 기능을 임의 추가하지 않는다. 후속D112의[v0.3](FLEET_ENDURANCE_BALANCE.md)는 파괴 시 한 번6.5초 지연·전투0.6%/s를 새 시험 후보로 사용한다. 최종 정책 확정과 실제 비전투 회복 검증은 별도다. 담당: 함선.

## R12. 자세·진형·Hold·접촉·FTL 우선순위 — 일부 결정

**확정:** 수동 자세 모든 축 보존·Hold 유지·FTL 추진/재배치 금지. **추가 확정(D093/D101):** 이동/공격 자동화 독립, 정상 접근에서 겹침 예방·이동 가능한 쪽 회피, 고정 함선 강제 밀기 대신 이미 발생한 비정상 겹침은 별도 복구. **남은 결정:** 자동 교전/편대 전환·Hold와 정렬 우선·비정상 복구의 위치/순서·관성 중 FTL 시작 경계. 2A의 양쪽 고정 시 미분리는 최종 해결이 아니다. 담당: 함대.

## R14. 외장 무장 피해 — 결정 완료

**확정(D089):** 쉴드 처리 후 해당 개별 무장 HP에만 피해를 적용하고 장갑·시설·선체에는 전달하지 않는다. 초과 피해도 선체로 넘기지 않으며 같은 한 발을 함체 피해로 중복 처리하지 않는다. 개별 무장 파괴 시 수리 전 발사 불가. 2A DEV의 무장 HP 단독 피해와 같은 결과 방향이 확정됐지만 실제 사격 피격 경로 연결은 아직 구현 과제다. 담당: 함선+함대.

## R15. 격납고 수용량 — 시설당 용량 결정, 함체 상한 확인 필요

**확정(D094):** 격납고1개당 소형함1척 또는 함재기20대. 격납고별 용도를 배분하고 함재기용 N개면 총20N대다. 100대를 전체 공통 상한으로 사용하지 않는다. 일반 대형/초대형 소형함 최대5척·항모의 해당 일반 제한 예외는 유지한다. **확인 결과:** 제공된 Play_Game_3는 항모120/항공순양함160/구축전함100의 독립 용량 값을 사용하며 ‘최종 티어 항모 최대5격납고’ 근거가 아니다. [원형 조사](../reference/PlayGame3Hangar/README.md) 참조. **남은 결정:** 함체/티어별 격납고 설치 상한(최종항모5개 여부 포함), 중형 설치·항공순양함 예외·한 격납고의 소형함/함재기 혼합 허용 여부. 담당: 모함.

## R16. 상대 밸런스의 기준

1:5는 평균 전투 결과 목표이며 HP/DPS/슬롯을 각각 5배 하지 않는다. 이동/선회 50% 하향, 무장 HP/수리 속도 2배, 크기 1/1.10/1.21/1.33은 프로토타입 비교 방향이다. 원형 버전·절대값·단위와 최종 함체 형상을 정해야 한다. 선회 rad/s, 기체 hull 160/shield 75 같은 참조값도 UE 최종 밸런스로 자동 사용하지 않는다. 최소 장갑 마모의 적용 위치/수치·중복 피해 방지도 미정이다. 담당: 함대+함선+모함.

## R21. 명중·투사체·아군 사선 — 원칙 결정, 우발 피해 잔여

## R22. 탐지 보정 — 초기 공유율 결정, 거리/변환 잔여

**확정(D090):** 초기 공유 프로필 자체100%/일반공유0%/레이더함공유80%. 레이더가 추가하는 조준 보정량에 적용하며 최종 명중률80%라는 뜻이 아니다. 일반 공유도 탐지/사격 자격은 제공한다. 적용 후 가장 유리한 유효 정보원을 선택한다. **남은 결정:** 보장 근거리·티어별 탐지/기본 보정량·빔확률/포탄오차 변환·혼합티어·외부기지·지연/차폐. 담당: 함대, 2B.

## R23. 시설·피해·수리 수치

쉴드 초과분 비율, 장갑 경감/마모, 시설→선체/빈 슬롯 배율, 혼합 무장 티어의 유폭 합산·범위/계수, 사보타주 유폭의 원인 전파, 중복 시설별 화력/연사/정비 배율·상한, 복구/충원 속도·비용·거리·접근/수리 우선 동률 처리 등이 미정이다. 공급 시설이 버프하는 세부 스탯을 일반 중복 효율 하나로 전부 곱하지 않는다. 선택 시설 경고와 탑재 운용 필수 검증의 상세도 필요하다. 담당: 함선/경제.

## R25. FTL·함재기 귀환·정지 — 귀환 정책 결정, 세부 잔여

**확정(D095/D096):** 모함 명시적 복귀 명령으로 수리한다. 전투 중 정기 귀환/유한 탄약/출격시간을 필수 요소로 두지 않으며 비전투5초 강제 귀환 기본안은 폐기한다. FTL 시작 시 긴급 회수, 기본 회수 대기, 명시적 잔여기체 포기 후 도약 허용(충전 완료는 필요). **남은 결정:** 충전 시간·동시도약 취소/실패·회수 대기와 충전 완료 순서·다중 격납고 대체 도킹·포기/관제 상실 기체 회수/재귀속·수리 후 재출격 절차. 담당: 함대+모함.

## R26. 선내 생존·진입·작전 — 주요 원칙 결정, 세부 잔여

**확정(D092/D097/D099/D100):** 승무원0만으로 영웅/아군 병력이 남은 함선을 중립화하지 않는다. 유인 인원 전멸은 중립화하되 무인 보안 시설만 남을 때 세부 가동은 미정이다. 진입은 대상 로컬 상/하/측면 구역을 분류하고 상면최상층/하면1F/측면높이별 층. 경비 필수 배치는 출격 초기 편제이며 전투 중 이동 허용. 공작 체크포인트는 진행률1/3·2/3로 시간 단축에도 동일 비율이다. **남은 결정:** 경계 모서리 귀속·구조 공개 유지·중복시설 초기경비 배분·보안시설만 잔존 시 기능·생명유지 사망/우주복저항·제어점 방해·공작 완료/점령 중단·강습선/비상탈출/구조/포로/동시 사건. 담당: 선내 작전+함선.

<a id="r27"></a>

## R27. 자동 일시정지 옵션과 중복 알림

중요 사건 자동 일시정지는 최신 결정으로 유지한다. 1배속 강제 감속은 기본 대체 규칙으로 사용하지 않는다. 이벤트 묶음·중복 억제·옵션/해제·재개 배속·타 성계 교전 지침이 미정이다. 담당: 전략+UI.

## R28. 전략·경제·AI·성장 상세

## R30. 후속 프로토타입의 장착·스케일 채택 — 구축함 분리 외 보류

D109에서 보고를 보관했고 **D110에서는 백터급/바스티온급을 현행 함체로 채택**했다. 백터1F·공격3/PD2, 바스티온2F·공격5/PD4는 함대 본문으로 옮겼으며 일반중형PD3으로 덮어쓰지 않는다. 모델 도입은 계속 보류다. 나머지 방공 사거리+75%, 전함14문 구성, 새무장 실제 계열/특수효과·측면사각·스케일/맵/카메라는 확인 후 채택한다. 최신WebZIP은 첨부됐으나 전송 도구32MiB상한으로 내부를 열지 못했다. 앞선422검사/ZIP크기 보고를 최신파일 분석/UE검증으로 승격하지 않는다. [보고와 접근 상태](PROTOTYPE_FBX_UPDATE_RECORD.md) 참조. 담당: 함대/함선/UI/기지/UE기술.

## R31. 두 구축함의 세부 성능·가격·연구 및 재계산

**확정(D110):** 단일 구축함을 삭제하고 백터급(Vector DD)·바스티온급(Bastion DD)으로 대체한다. 백터는 중형1F/고기동·저방어/공격3+PD2, 바스티온은 중형2F/중장갑 거점형/공격5+PD4·백터 대비 크기+30% 기준이다. 둘 모두T2상한/중형 작업칸, 초대형 조선의 중형 제외는 유지한다. **진행(D111):** [전투 수치v0.2](COMBAT_BALANCE.md)에 두 함체의 개별 성능/표준 장비와 백터1600/180/0·210초, 바스티온2600/420/0·330초를 제안하고 전투 모형으로 비교했다. 이는 최신ZIP 추출값이 아니다. **남은 결정/분석:** 최신원본 대조·UE 실교전, 연구 해금/선행·무장 단품/교체 비용·경제 캠페인 재계산. 구 단일1800/200/0·4분은 현행표에서 제거했으며 두 함체에 복제하지 않는다. 캠페인 모형은 구입력 재현용으로 고정했고 새 함체 기준결과가 아니다. 원본 확보/수치 확정 후 새 버전으로 다시 계산한다. 담당: 함대/함선/기지·경제.

## R32. 전투 수치v0.2의 실게임 검증과 남은 위험

D111의 [수치 제안](COMBAT_BALANCE.md)과 [반복 결과](COMBAT_SIMULATION.md)는 자체 축소 모형이다. **우선 검증:** 거리 측정 기준(중심/경계/포구) 통일, 유폭의 체급별 피해·공급량·선체 전달 예산, 쉴드 비활성 중 피격마다 지연을 다시 주는지(R11), 시설 파괴/영웅 잔류 시 사격 보류 및 탈출 예상시간, 레이더실/무기실/함교 파괴로 끝나지 않는 무력화 교착과 승리 조건. **미시험:** 외장 포탑 저격, 1/2층 장갑 연동, 중복/승무원/생명유지·화재, 실제 문/경로/전열·강습선/재탈환/포로·구조 회수, 모함/함재기/수리함·FTL, 영웅 성장/장비/난이도·5시간 경제. **경제 주의:** 같은 비율 선체 수리에 동일 고정비를 초대형까지 적용하지 않는다. 신규 무장 단품 가격을 정하기 전 함체 패키지 비용만으로 개조 편대의 공정 예산을 주장하지 않는다. 잠정 수치를 교체 가능한 데이터로 적용하고 실제2B→2C→3단계에서 동일 시드/편성·시간·부위/소실 로그로 다시 조정한다. 담당: 함대/함선/영웅/강습/경제/UE.

## R33. 장기전·혼성 함대·강습 운송의 후속 균형

**확정(D112):** 일반전1배속10~15분, 편성 코스트1/5/25/125와100/200/300 시험, 체급별 역할·영웅의 전투 단축 기여를 지향한다. **현행 후보:** [v0.3 수치](FLEET_ENDURANCE_BALANCE.md)·[전 함종 결과](FLEET_ENDURANCE_RESULTS.md). **남은 사항:** 소형 물량/항모 집중/방공 투자 효용,300코스트 초대형의 과도한 지속 화력, 강습의 일관된 승전 시간 단축, 포드160HP/강습선 운용·국소PD 근사의 실제 공간 검증, 관통 후보의 채택/무장별 환산, 시설·승무원·유폭·장갑까지 포함한 생존 시간, 실제 경비/재탈환·영웅 후송·코스트/함재기/임무 함선 패키지·단품 가격·나포 후 한도 초과/증원 정책.10~15분에 모든 편성을 강제하거나 초대형/소형 물량을 코스트 계산에서 예외 처리하지 않는다. 모형에서만 쓰는 표적 선호/분산·PD 국소 그룹을 게임의 하드 제한으로 도입하지 않는다.

## 임시값 기록 요건

각 임시 프로필은 값·단위·원형/코드 커밋·적용 기능·미결정 R번호를 기록한다. 기획 확정과 사용자 승인을 대신하지 않는다. 2A의 활성 Gradual은 최신 제약과 달라 수정 필요하다. 무장 HP 단독 피해는 이제 확정 규칙이며 실제 사격 연결은 후속 과제다. 1/2층 연동 등 남은 임시는 [구현 상태](IMPLEMENTATION_STATUS.md)에서 확인한다.

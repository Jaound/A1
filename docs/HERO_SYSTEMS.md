# 영웅·강습 시스템

> 상태: 영웅의 임무·유형, 진입·요격·탈출의 기본 결과는 확정된 방향이다. [선내 자동 전투·점령](BOARDING_COMBAT.md)은 설계 요청에 따른 첫 검증용 제안이다. 유형별 능력·성장·상성은 미정이다.

## 임무

영웅이 수행하는 **임무**와 영웅의 **유형**을 구분한다. 특정 유형만 특정 임무를 맡을 수 있다는 제한은 아직 정하지 않았다.

| 임무 | 내용 |
| --- | --- |
| 강습 | 강습선 또는 강습 포드를 타고 다른 함선으로 이동해 적 영웅·병력과 교전 |
| 점령 | 지정된 목표에 따라 시설을 점령하거나 물리적으로 파괴하는 사보타주 수행 |
| 수호 | 적 함선에서 침투한 영웅·병력을 상대해 아군 함선을 방어. 함교가 점령되어 나포된 경우 명령에 따라 재점령 또는 후퇴 |
| 지원 | 영웅 고유 특성에 따라 다른 함선 직접 공격, 탑승 함선의 방어, 버프 또는 수리 제공 |

지원 임무가 반드시 지원형 영웅에게만 허용되는지 등 유형별 임무 제한은 미정이다. 영웅 특성이 구체적인 지원 방식과 효과를 결정한다.

## 영웅 유형

- **근거리형**
- **원거리형**
- **지원형**
- **지휘형**

유형별 스탯·무장·스킬·사거리·전투 상성은 아직 정하지 않았다. 초기 요약의 폭격 영웅 등은 유형 확정 이전의 능력 예시이며, 별도의 확정 유형으로 취급하지 않는다.

## 조작과 표현

- 선내 전투는 2D 애니메이션으로 표시하는 움직이는 설계도 방식이다.
- 플레이어가 목표를 지정하면 영웅과 병력이 이동·교전을 자동 수행한다. 우회·방어 대기·퇴각 등의 상위 명령으로 개입한다.
- 함선 보직에서 함대를 지원하던 영웅을 침투·수호 임무로 전환할 수 있다. 구체적인 전환 시간과 보직 공백 효과는 미정이다.

## 강습 이동 수단과 내부 배치

- **강습 포드:** 강습 포드 발사 시설에서 함선의 기본 사거리(보장 근거리) 안의 목표 함선으로 발사한다. 비행 중 요격 시스템에 격추될 수 있어 위험을 감수해야 한다.
- **강습선:** 포드에 비해 비교적 안전한 이동 수단이다. 구체적인 내구도·방어 능력과 접근·진입 방식은 미정이다.
- **쉴드:** 강습 포드·강습선 모두 통과할 수 없다. 포드는 충돌 시 파괴되고, 강습선은 자체 쉴드가 깎이며 접근할 수 없다. 발사 후 적 쉴드가 재작동하는 경우에도 접촉 시 이 규칙을 적용한다.
- **장갑:** 두 수단 모두 고출력 레이저 드릴로 구멍을 뚫으므로 진입을 막는 조건으로 사용하지 않는다. 쉴드 없이 도달한 뒤 진입 자체에는 실패 확률이 없다.
- **내부 정보:** 진입 전 적함 내부 배치는 알 수 없고, 진입한 뒤에야 구조를 공개한다. 진입 위치는 확률적으로 정해져 함교 근처일 수도 멀리 떨어질 수도 있다. 진입 실패 확률과 위치 추첨은 별개다. 세부 분포는 미정이다.
- 기지에서는 고정 복도를 편집하지 않고 미리 정해진 슬롯에 시설을 배치한다. 코어는 중앙 고정이며 시설·복도 크기와 경로 길이는 함체 형태·체급에 따른다. [함선 내부 시설](SHIP_SYSTEMS.md)을 참조한다.

## 작전 단계별 결과

| 단계·사건 | 결과 |
| --- | --- |
| 출발 준비 실패 | 강습 취소 |
| 비행 중 포드 요격 | 일반 병력 즉시 사망. 영웅은 우주 공간에 구조 가능한 상태로 남음 |
| 구조 대기 중인 영웅 | 아군이 구조할 수 있고 적이 접근해 납치할 수도 있음 |
| 비행 중 목표 완파·초광속 이탈 | 포드는 복귀 |
| 쉴드 없는 목표에 정상 도달 | 진입 성공. 위치는 확률적으로 결정 |
| 내부 작전·탈출 실패 | 영웅·일반 병력은 사망하거나 포로가 됨. 구체적인 포로 판정은 미정 |
| 인원이 적함 안에 있는 상태에서 적함 완파 | 내부 영웅·병력 전원 사망. 비행 중 요격의 영웅 구조 규칙을 적용하지 않음 |
| 정상 탈출 | 최초 진입 지점으로 돌아가 사용했던 포드를 재사용해 후퇴 |
| 발사 시설 파괴 후 귀환 | 이미 진입한 포드의 복귀에는 지장 없음 |
| 귀환 비행 중 포드 요격 | 출발 비행 때와 동일. 일반 병력 사망, 영웅 구조·납치 가능 |

포드의 쉴드 충돌로 파괴될 때 탑승자 결과와 강습선 자체 파괴 시 결과는 아직 정하지 않았다. 포드가 복귀할 원래 함선까지 사라졌을 때의 대체 목적지, 구조 유효 시간·접근 거리도 미정이다.

## 함선 시설과 지배권 연결

- 일반 시설 점령은 기존 소유 측의 시설 기능을 마비시키며, 물리적 파괴와 별개로 관리한다. 파괴 사보타주는 [시설별 파괴 효과](SHIP_SYSTEMS.md)를 적용한다.
- **함교 점령은 즉시 함선 소유권·조종권을 이전**한다. 함교 장치로 일반 승무원을 통제하지만 적 영웅의 소속은 바뀌지 않는다.
- 일반 경비병과 강습 병력도 소속이 바뀌지 않으며 기존 소유 측의 재탈환에 참여할 수 있다. 시설 운영 승무원과 이 전투 병력은 구분한다.
- 함교를 빼앗겨도 내부에 남은 기존 소유 측 영웅이 재점령할 수 있다. 후퇴·강습 포드 탈출, 포로 또는 사망도 가능하다. 플레이어와 AI에 같은 규칙을 적용한다.
- 시설 사보타주는 쉴드 해제, 엔진·레이더·무기·요격 기능 중단 등으로 3D 함대전에 영향을 준다. 외부 포격에 의한 선내 위험도 영웅에게 영향을 줄 수 있다.
- 죽은 영웅은 시설 수리나 승무원 보충으로 복구하지 않는다. 포드 요격의 구조 대기와 선내 전투 사망·적함 완파를 서로 다른 결과로 처리한다.

## 이후 구체화할 사항

1. 유형별 능력과 고유 특성, 획득·성장·장비·편성 규칙.
2. 함선당 영웅 수, 강습 분대 구성과 일반 병력의 역할.
3. 진입 위치 확률 분포와 강습선 세부 운용, 포드 쉴드 충돌·강습선 파괴 시 탑승자 결과.
4. [선내 전투 기본안](BOARDING_COMBAT.md)의 경로·교전·점령·파괴 시간과 중단 조건 검증.
5. 구조·납치의 접근 조건·시간 제한, 포로 판정과 복귀 목적지 상실 시 처리.
6. 함선 지원 능력의 대상·범위·비용·재사용 시간.
7. 요격 우선순위에 강습 포드를 포함하는 방식, 발사 시설 수용량·발사 간격, 재사용 포드까지 경로가 차단될 때의 대응.

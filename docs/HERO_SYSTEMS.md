# 영웅 시스템

> 현행 명세: 2026-11-16. 임무·유형·보직·성장 범위를 관리한다. 강습 운송·점령·탈출은 [강습·선내 작전](BOARDING_COMBAT.md)의 단일 규칙을 따른다.

## 임무와 유형

| 임무 | 역할 |
| --- | --- |
| 강습 | 다른 함선으로 이동해 적과 교전 |
| 점령 | 시설 제어 지점 점령 또는 파괴 사보타주 |
| 수호 | 아군 선내 방어, 나포 후 재탈환 또는 후퇴 |
| 지원 | 특성에 따른 타 함선 공격, 탑승 함선 방어, 버프·수리 |

유형은 근거리형·원거리형·지원형·지휘형이다. 유형과 임무는 서로 다른 분류이며 특정 유형만 특정 임무를 할 수 있다는 제한은 아직 없다. 세부 스탯·스킬·상성은 미정이다.

## 보직과 전투 투입

영웅은 함선 시설 보직에 배치해 함대 성능을 지원하거나 강습/수호 전투에 투입할 수 있다. 상황에 따라 실시간 보직 전환이 가능하다. 포드 자동 편성에서 보직 수행 영웅과 구역 수호 유닛은 제외하며 명시적 전환/선택을 사용한다. 이동/인계 시간·버프 중복/해제 시점은 R28이다.

지휘·지원·공격 보직의 초기 아이디어는 능력 설계 후보로 유지한다. 구체 스킬 수치나 영웅 한 명이 동시에 여러 보직을 수행하는 규칙으로 확정하지 않는다.

## 표현·조작

2D 애니메이션으로 움직이는 설계도 위에 영웅을 표시한다. 목표 지정 후 경로·교전을 자동 수행하고 플레이어는 우회·방어 대기·후퇴 등 상위 명령으로 개입한다. 층 전환/경고/로스터는 [UI](UI_SYSTEMS.md), 전투 단위와 구역은 선내 작전을 따른다.

## 생존과 성장

영웅 사망은 영구 손실이다. 포드 비행 격추 시의 구조 대기와 함선 내부 완파 사망은 다른 결과다. 포로·구조·비상 탈출 절차는 선내 작전을 따른다. 일반 승무원 자원 충원으로 죽은 영웅을 복원하지 않는다.

방어 영웅은 함선 체급별 1~3명 배치 방향이 있으나 체급별 상세·플레이어 최소 보유 영웅 보장·3~4인 강습 편성의 최종 인원은 미정이다. 획득·성장·장비·편성·지원 능력의 대상/비용/쿨타임은 [R28](OPEN_QUESTIONS.md#r28)에서 관리한다.

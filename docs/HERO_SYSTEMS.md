# 영웅·강습 시스템

> 상태: 1~4차 기획 검토 및 확정 사항 반영 최신본. 영웅의 임무·유형, 가변 층수 진입·요격·탈출·나포 규칙이 반영되었다. 유형별 능력·성장·상성은 미정이다.

## 임무와 유형

- **임무:** `강습`(적함 이동 및 교전), `점령`(시설 점령 및 파괴 사보타주), `수호`(아군 함선 방어 및 나포 시 재탈환/후퇴), `지원`(고유 특성에 따른 타 함선 공격, 탑승 함선 방어, 버프·수리).
- **유형:** `근거리형`, `원거리형`, `지원형`, `지휘형`.
- 특정 유형만 특정 임무를 맡을 수 있는지 등의 임무 제한과 세부 스탯·스킬·상성은 추후 결정한다.

## 조작과 표현

- 선내 전투는 2D 애니메이션으로 표시하는 움직이는 설계도 방식이다.
- 체급별 가변 1~3층 구조에 맞춰 측면 UI에서 **1F / 2F / 3F 버튼**으로 층 단면도를 전환해 확인하며, 교전이나 위기가 발생한 층은 버튼에 강조 테두리가 점등된다.
- 플레이어가 목표를 지정하면 영웅과 병력이 이동·교전을 자동 수행한다. 우회·방어 대기·퇴각 등의 상위 명령으로 개입한다.
- 함선 보직에서 함대를 지원하던 영웅을 침투·수호 임무로 실시간 전환할 수 있다.
- **방어 상주 편제:** 함교·코어·생명유지장치에는 기본 경비 분대 1개가 반드시 상주하며, 함선 체급에 따라 **방어 영웅 1~3명**이 배치된다. 기지 개조를 통해 **선내 보안 시설(터렛·전투 로봇)**을 아군·적함 모두 장착할 수 있다.

## 강습 이동 수단과 내부 배치

- **강습 포드:** 강습 포드 발사 시설에서 보장 근거리 안의 목표 함선으로 발사한다. 비행·귀환 중 요격 시스템에 격추될 수 있으나 **비행 중 수동 회항(발사 취소)** 명령이 가능하다.
- **강습선:** 포드에 비해 비교적 안전한 이동 수단이다. 구체적인 내구도·방어 능력은 미정이다.
- **쉴드:** 강습 포드·강습선 모두 통과할 수 없다. 포드는 충돌 시 파괴되며(요격과 동일하게 **일반 병력 즉시 사망, 영웅은 우주 공간 구조 대기 상태**로 통일), 강습선은 자체 쉴드가 깎이며 접근할 수 없다.
- **장갑:** 고출력 레이저 드릴로 구멍을 뚫으므로 진입을 막지 않으며, 쉴드 없이 도달한 뒤 진입 자체에는 실패 확률이 없다.
- **진입 층 및 내부 정보:** 진입 전 적함 내부 배치는 알 수 없고 진입 후 공개된다. 모함 또는 포드가 적함의 **상부 반구(`Z >= 0`)에서 도달하면 최상층(2F/3F) 외곽 슬롯**, **하부 반구(`Z < 0`)에서 도달하면 최하층(1F) 외곽 슬롯**(측면 중앙 도달 시 중층 외곽)으로 진입하며, 구체적인 방 위치는 확률적으로 결정된다.
- **우주복 착용(생명유지 면역):** 강습 포드/강습선으로 진입한 영웅과 강습 병력은 우주복을 착용하고 있어 적함 생명유지시스템 파괴 피해에 면역(또는 높은 저항)을 가진다.

## 작전 단계별 결과

| 단계·사건 | 결과 |
| --- | --- |
| 출발 준비 실패 | 강습 취소 |
| 비행 중 수동 회항 명령 | 포드가 발사 모함으로 회항(회항 중에도 요격 대상) |
| 비행 중 포드 요격 또는 쉴드 충돌 | 일반 병력 즉시 사망. 영웅은 우주 공간에 구조 가능한 상태로 남음 |
| 구조 대기 중인 영웅 | 아군이 구조할 수 있고 적이 접근해 납치할 수도 있음 |
| 비행 중 목표 완파·초광속 이탈 | 포드는 복귀 |
| 귀환 중 모함 완파·초광속 이탈 | **전장 내 가장 가까운 아군 함선**(발사 시설 유무 무관, 도킹만 수행)으로 목적지 변경. 아군 함선이 전무하면 그 자리에서 정지해 구조 대기 상태로 전환 |
| 쉴드 없는 목표에 정상 도달 | 진입 성공. 도달 고도에 따른 층의 외곽 슬롯 중 확률적 위치에 배치 |
| 내부 작전·탈출 실패 | 영웅·일반 병력은 사망하거나 포로가 됨(포로 판정 미정) |
| 퇴각 경로 완전 차단 시 후퇴 | 외곽 슬롯의 방에서 일정 시간을 소모해 **우주 공간으로 직접 비상 탈출(표류/구조 대기 상태)** 가능 |
| 인원이 적함 안에 있는 상태에서 적함 완파 | 내부 영웅·병력 전원 사망(구조 규칙 미적용) |
| 정상 탈출 | 최초 진입 지점으로 돌아가 사용했던 포드를 재사용해 후퇴(발사 시설 파괴는 귀환에 지장 없음) |

## 함선 시설과 지배권 연결

- 일반 시설 점령은 기존 소유 측의 시설 기능을 마비시킨다. 선내 영웅의 **정밀 파괴 사보타주로 시설이 파괴될 때는 외장 장갑이 보존**된다.
- **함교 점령·상주 및 파괴 규칙:**
  * **파괴된 함교는 점령 불가**하며 수리 후에만 점령할 수 있다.
  * 함교 점령 완료 순간 함선 소유권·조종권이 즉시 이전되나, **선내 적 세력을 모두 소탕하기 전까지는 함교에 인원(강습 병력 또는 아군화된 터렛/로봇 등)을 남겨두거나 유예 시간 조건을 충족**해야 소유권이 유지된다(적 소탕 후에는 함교를 비워도 영구 유지).
  * **점령된 상태에서 함교가 외부 포격으로 파괴**되면 **함교 방 안에 있던** 일반 병력은 즉시 사망하고 영웅은 큰 피해 후 인접 방으로 튕겨나며(체력 0이면 사망), 함선은 **중립 정지 상태**가 된다.
- 일반 경비병·강습 병력·영웅은 함교 점령으로 소속이 바뀌지 않는다. 선내 보안 시설(터렛·전투 로봇)은 함교 나포 후 긴 재부팅 시간을 거쳐 새 소유주 소속으로 전환된다.

## 이후 구체화할 사항

1. 유형별 능력과 고유 특성, 획득·성장·장비·편성 규칙.
2. 강습 분대 최대 인원, 방어 영웅(1~3명) 배치 기준 및 강습선 세부 운용.
3. 강습선 파괴 시 탑승자 결과, 구조 유효 시간·접근 거리, 포로 판정 조건.
4. 외곽 방 비상 탈출 소요 시간 및 함교 점령 유지 유예 시간(30~60초) 세부 수치.
5. 함선 지원 능력의 대상·범위·비용·재사용 시간.

# 플레이 임무 6종 개편 · 첫 체크포인트

기준 코드는 `37c181f`, 원격 기획 `work` 기준은 `f0ac7fbd51f1888e1d74552e6ff302e8a464acfa`다. 공통 전투·방공·항공대·선내 시스템과 기존 함체, 무장, 쉴드 데이터를 재사용한다.

## 실행과 수동 확인

에디터에서 `ControlRange`를 플레이하고 상단 **장면** 메뉴를 연다. 100·200·300코스트 함대전은 F5·F6·F7로도 열 수 있다. 개발 모드에서 함수키를 누르거나 기존 검증 API를 명시적으로 호출하면 기존 시험장에 접근할 수 있다.

- **시작 ▷** 또는 F1로 진행한다. 양측의 초기 접근·교전과 항모의 첫 출격이 자동으로 동작한다. 아군 함선을 선택해 기존 조작과 상세창을 사용한다.
- **재시작**으로 새 편성을 생성한다. **목록 복귀**로 전투를 내려놓고 다시 장면을 선택한다.
- 자유 전투 시험장은 빈 공간에서 시작한다. 개발 도구의 기존 함선 생성 경로를 사용할 수 있다. 중립 배치·미리보기·시험 영웅과 교전 토글은 후속이다.
- 4번 채굴·수송 엄호와 5번 공습 생존·퇴각은 메뉴에서 준비 중으로 표시한다.

UE 5.8 실행 시 `-OVPlayScene=Fleet100`, `Fleet200`, `Fleet300`, `Sandbox`를 명시할 수도 있다.

## 기본 편성

양측 동일 편성이다. 공통 전력은 초계함 3·호위함 1·보급수리함 1(소형 5)과 백터·바스티온·방공함·레이더함 각 1(중형 20)이다.

| 임무 | 공통 전력 외 추가 편성 | 한쪽 코스트 | 실제 격납고 / 실제 기체¹ |
| --- | --- | ---: | ---: |
| 100코스트 | 전함 2, 항공모함 1 | 25 + 75 = 100 | 2 / 20 |
| 200코스트 | 구축전함 1, 전함 1, 항공모함 1 | 25 + 125 + 50 = 200 | 2 / 20 |
| 300코스트 | 구축전함 1, 항공순양함 1, 항공모함 1 | 25 + 250 + 25 = 300 | 4 / 40 |

¹ 해당 항모의 설치 격납고당 10기. 함재기 코스트는 함선 합계에 포함하지 않는다. 이 체크포인트 함대전의 영웅과 승객은 한쪽 0명이며 캠페인 명단을 소모하지 않는다. 보급수리함은 편성에 포함되며 임무 내 수리 자원과 지시는 후속이다.

## 판정

- 한쪽에 살아 있는 대함 무장·지원 시설이나 작전을 계속할 수 있는 모함 전력이 남지 않으면 상대가 승리한다. 사거리, 탐지, 승무원 효율의 일시 저하는 물리적 무력화로 보지 않는다.
- 양측 전력이 동시에 소멸하거나 무력화되면 별도로 표시한다. 이탈한 함선은 완파와 구분한다. 포드와 관제 없는 잔여 기체만으로 함대를 유지할 수 없다.
- 영구 피해 상태 변화가 120 게임 초간 없으면 교착, 900 게임 초를 넘기면 시간 초과다. 두 값은 임무 설정에서 조정할 수 있는 시험 후보이며 전투 시간을 맞추기 위해 화력을 변경하지 않았다.

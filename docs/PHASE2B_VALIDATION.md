## 기능과 회귀 범위

- 기존 17개 자동 검사와 57개 2A API 검사를 유지했다. `ShieldStateAndTime`은 최신 D083에 따라 활성 회복 금지·비활성 3%/6% 회복·50%에서 정지로 기대 동작을 갱신했으며 테스트를 삭제하지 않았다.
- 사거리·보장 근거리·자체/공유/지원 레이더·최선 정보 선택, 로컬 상하 사각·포탑 선회·수동 자세, 무기제어실/탄약고/축전/미사일 적재실/레이더/개별 무장 HP/FTL 발사 차단을 검사했다.
- 실제 발사 요청으로 빔·포탄·미사일을 생성하고 쉴드→장갑→시설→선체/유폭/완파와, 외장 무장 충돌→쉴드→해당 무장 HP 단독 경로를 검사했다. DEV 피해 API는 시험 초기 조건 설정용이며 실제 공격을 대체하지 않았다.
- 발사 시 소속·무장 스냅샷, 공격자 완파·소유 변경 후 비행, 탐지 상실 후 신규 발사 차단과 기존 공격 지속, 목표 완파·이탈·추적 만료, 같은 공격 ID의 피해 재적용 방지를 검사했다.
- D084 상실 시점의 3.5초 기억과 숨은 위치 읽기 차단, D085 연속 분산, D088 고정 VLS, D089 포탑 피해, D090 일반 공유 보정 0, D101 네 자동화 조합을 추가 검사했다. 이동만 자동인 경우에도 탐지 상실 표적의 현재 위치로 선체를 돌리거나 사선을 확보하지 않는다.
- 시드 고정 및 1/120 게임 초 공통 스텝으로 일시정지와 1/2/3배속의 동일 게임 시간에 발사 수·피해·투사체 결과를 비교했다. 2A API 회귀는 카메라 배속 독립성과 프레임률별 회전 감도, XYZ 입력·회전 소유권을 포함한다.
- 실제 PIE 프레임의 약 4.967게임 초에서 아군 9발/적 11발을 확인했다. 일시정지 중 HUD가 사격을 추가하지 않으며, 전면 상세 창이 뒤쪽 FIRE 버튼의 클릭 영역을 소비하는 API 검사도 통과했다.

자동/PIE API 성공은 OS 입력 전달·실제 조작감 성공을 뜻하지 않는다. 현재 실행 중인 에디터의 2B PIE는 Atlas·빔 선택, 적 표적 지정, 일시정지 상태로 남겼다. 기존 DEV 표시를 유지하며 DEV 버튼으로 숨길 수 있다. 사용자는 [짧은 직접 입력 확인](PHASE2B_GUIDE.md#짧은-직접-입력-확인)을 수행하면 된다.

## 남은 한계와 분리된 오류

한국어 엔진 시작 자체 검사 `Condition failed` **15건**은 이번 실행에서도 발생했다. 기존 `FUnifiedErrorTest_CreateErrorMessage` 7건, `WithContext` 4건, `FStructuredLogFormatTest` 4건과 같은 계열이며 프로젝트 자동 테스트 31개 실패로 합산하지 않는다. 원인·이전 증거는 [2A 검증](PHASE2A_VALIDATION.md)에 보존했다.

유도 추적 8초와 만료 처리, 쉴드 회복률/지연/비전투 전환, 분산 분포·수치, VLS 곡선·속도 분포, 18cm 무장 충돌 구와 파괴 후 제외는 시험값이다. 확정 정책과 구분해 [가이드](PHASE2B_GUIDE.md#임시-프로필과-미결정-정책)에 기록했다. 혼합 티어 유폭은 미결정 R23에 따라 구현하지 않았고 동일 티어 레이아웃만 사용한다. 정밀 모델/접촉, 2C 요격·함재기·포드, 3단계 강습, 전략 AI·경제는 이번 완료 범위가 아니다.

중간 실패도 보존한다: 11월 13일 2B PIE는 39개 통과 후 읽기 전용 `WindowPosition`을 쓰려던 검사 스크립트 때문에 중단했다. 실제 창 드래그 API로 고친 뒤 이번 전면 차단 검사를 포함한 50개가 통과했다. 이전 HUD 히트박스 오프셋 접근 컴파일 오류는 공개 `Contains` 경로 사용으로 해결했고 이번 빌드에서 재발하지 않았다.

## 검사 의미와 잔여 확인

자동 검사는 실제 Actor·Systems·CombatSubsystem을 임시 월드에 구성하고 발사 요청부터 실행한다. DEV 피해는 초기 상황 준비에만 사용하고 공격의 피해를 대신하지 않는다. 탐지 최댓값, 로컬 사각/회전, 공급·제어·무장 HP·FTL 차단, 복제 공격 ID 재처리 방지, 소속/공격자 상실 후 비행, 목표 완파·이탈·추적 만료, 살보 잔여탄 취소, 동일 시드/게임 시간 결과를 검사했다.

PIE는 실제 에디터 월드에서 Controller와 HUD API를 호출했다. 정지·배속·기존 조작·공격/피해와 실제 프레임의 양방향 발사를 포함한다. **OS 마우스·키보드 입력은 아직 미검증**이다. 이 결과는 실제 클릭·포커스 전달·조작감 성공을 뜻하지 않는다.

한국어 엔진 시작 자체 검사 `Condition failed` **15건**은 이전과 동일하게 별도다. 프로젝트 27개 테스트의 실패로 합산하지 않는다. 원본 오류 이름과 이전 설명은 [2A 검증](PHASE2A_VALIDATION.md)에 보존했다.

당시 후속 검토였던 AUTO FREE 사용자 진입, 대형/초대형 티어 상한, 이탈 후 선택·표시, 같은 장착 티어 프로필 제한은 최신 구현에 반영하고 위 검사로 재검증했다. 직접 입력은 여전히 미검증이다.

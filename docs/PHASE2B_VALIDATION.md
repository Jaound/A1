## 검사 의미와 잔여 확인

자동 검사는 실제 Actor·Systems·CombatSubsystem을 임시 월드에 구성하고 발사 요청부터 실행한다. DEV 피해는 초기 상황 준비에만 사용하고 공격의 피해를 대신하지 않는다. 탐지 최댓값, 로컬 사각/회전, 공급·제어·무장 HP·FTL 차단, 복제 공격 ID 재처리 방지, 소속/공격자 상실 후 비행, 목표 완파·이탈·추적 만료, 살보 잔여탄 취소, 동일 시드/게임 시간 결과를 검사했다.

PIE는 실제 에디터 월드에서 Controller와 HUD API를 호출했다. 정지·배속·기존 조작·공격/피해와 실제 프레임의 양방향 발사를 포함한다. **OS 마우스·키보드 입력은 아직 미검증**이다. 이 결과는 실제 클릭·포커스 전달·조작감 성공을 뜻하지 않는다.

한국어 엔진 시작 자체 검사 `Condition failed` **15건**은 이전과 동일하게 별도다. 프로젝트 27개 테스트의 실패로 합산하지 않는다. 원본 오류 이름과 이전 설명은 [2A 검증](PHASE2A_VALIDATION.md)에 보존했다.

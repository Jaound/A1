# 영웅 전투 시험장

최신 Windows 빌드의 임무 목록에서 **영웅 전투 시험장**을 연다. 양측 구축전함은 대함 무장·요격·쉴드 없이 시작한다. 아군 구축전함의 격납고 두 칸에는 별개의 강습선이 한 척씩 정박해 있다.

1. **영웅 → 편성·보직 설정**에서 원하는 후보를 선택해 배치하거나 임무 창에서 후보와 생성 레벨을 고른다. 아군은 고유 30종·일반형 4종·편성 가능한 보유 인원에서 고른다. 시험 편성은 퇴장 시 원래 명단으로 돌아간다.
2. **팀 편성**을 열면 A팀·B팀·예비가 보인다. 영웅 한 명 또는 **보병 4인 분대**를 클릭한 뒤 보낼 열 상단의 **← 배치** 버튼을 누른다. 자리가 꽉 찼으면 먼저 한 명이나 한 분대를 예비로 옮긴다. 화살표로 다음 명단을 본다. 각 출발팀의 정원은 12명, 그중 영웅은 최대 4명이다. 빈자리를 둔 채 출발할 수도 있다. 예비 인원은 모함에 남는다.
3. **선내 지휘**를 연다. **A팀 → 모두 선택**으로 편성한 팀을 선택하거나 아래 카드에서 원하는 영웅·일반병을 고른다. **강습**을 누르고 개인 포드 또는 사용할 강습선을 고른다. 전장에 함선만 보이면 적 선체를 클릭한다. Esc로 취소하면 원래 선내 화면으로 돌아간다.
4. 준비 중에는 대원들이 실제로 포드 발사실이나 격납고까지 걸어간다. 시험장 시작 시 시간이 정지돼 있으므로 상단의 **시작 ▷**으로 진행한다. 명령창 위의 인원수가 찬 뒤 **발사 확인** 또는 **출격 확인**을 누른다. B팀도 같은 순서로 지시해 포드만·강습선만·혼합 경로를 비교할 수 있다. 동일 목표에는 한 번에 두 팀까지, 출발 간격은 게임 시간 30초다. 도착 후 **지휘 → A 진입층 / B 진입층**으로 실제 진입 지점을 본다.
5. **철수**를 누르면 각 인원이 원래 진입점으로 이동해 자기 포드 또는 원래 강습선으로 복귀한다. 전투 알림에서 진입은 팀별 누계로, 전사·구조 대기는 개인별로 확인한다. 결산에서 **진입 전 / 선내 교전 / 철수 중**의 전사와 구조 대기를 두 팀별로 비교한다. 함교 점령 또는 출발한 생존자의 복귀로 임무가 끝난다.
6. 정박 중인 함선으로 옮길 때는 출발 함선의 **선내 작전 → 대원 선택 → 옮겨 타기**에서 목적 함선을 고른다. 모함으로 돌아올 때는 정박 함선의 선내에서 같은 명령을 쓴다. 승하선 중에는 해당 함선의 출격이 잠긴다.
7. 같은 편성과 레벨로 재시작해 수송 방식을 비교할 수 있다. 보병 기본안은 팀당 일반병 12명이다. 방어측은 일반형 영웅 10명과 코어·함교·생명유지실의 일반병 각 4명이다.

**선내 전투 지도와 카드**

지도는 창의 윗부분 전체를 사용한다. 창을 최대화하면 방과 복도 사이의 간격도 넓어진다. 왼쪽 아래는 현재 선택의 상세정보다. 명령줄 아래의 카드는 이 함선에 있는 아군을 개인별로 표시한다.

- **전체 / A팀 / B팀 / 예비**로 명단을 좁힌다. 가로 막대의 손잡이를 끌거나 화살표·마우스 휠로 두 줄의 카드를 좌우로 넘긴다.
- 카드를 클릭하면 해당 인원 한 명과 그 층을 선택한다. Shift를 누르고 클릭하면 복수 선택한다. **모두 선택**은 현재 필터에 속한 생존 인원을 선택한다.
- 같은 방에 있는 같은 일반병 분대는 지도에 한 표식으로 나타난다. 표식의 숫자는 그 방에서 관측되는 생존 인원 수다. 아군 분대 표식을 누르면 그 방의 분대원을 선택한다. 명령줄 아래에서는 부상병 한 명만 따로 선택할 수 있다.
- 영웅 카드는 각 인물의 얼굴을, 선내 지도는 해당 영웅의 SD를 표시한다. 일반병은 기존 병과 표식과 분대 표시로 구별한다.

**상주와 출발 정원**

| 대상 | 상주 또는 수송 영웅 | 동시 시설 보직 |
| --- | ---: | ---: |
| 일반 소형함 | 1 | 1 |
| 중형함 | 2 | 2 |
| 대형함 | 4 | 3 |
| 초대형함 | 6 | 4 |
| 강습선 | 최대 4명, 병력 포함 총 12명 | 수송 중 0 |
| 영웅 시험장 구축전함 | 시험 특례 10 | 4 |

세력 전체의 지휘 한도는 별도로 적용한다. 적함 진입자를 적함의 출격 편제 정원으로 잘라내지 않는다. 시험장에서 10명을 채워도 영웅 4명씩 두 팀이 나가면 2명은 예비로 남는다. 두 팀 제한과 출발 간격은 **목표 함선별**로 계산한다. 일반병은 각자 체력·승객 ID·생사 상태를 가지며 포드 경로에서는 1인당 1기를 사용한다.

**점령·공작·포로**. 기획 기준은 일반 시설 점령 18초, 함교 36초, 파괴 공작 30초, 인원·능력에 따른 최대 시간 단축 50%다. 공작 중단은 1/3과 2/3 진행 지점을 보존한다. 함교 소유권이 바뀌어도 개별 영웅과 병력의 소속은 유지된다. 잔류 인원의 실제 제압·확보와 포로 교환·구조 캠페인은 이번 수송 비교의 승리 조건에 포함하지 않는다. [강습·점령·공작·포로 명세](https://github.com/Jaound/A1/blob/6fb4ae948ff5a828047b94963d9cf66a05b588f8/docs/01_design/boarding/BOARDING_COMBAT.md) · [영웅 정원과 일반 분대](https://github.com/Jaound/A1/blob/6fb4ae948ff5a828047b94963d9cf66a05b588f8/docs/01_design/boarding/HERO_SYSTEMS.md)

**아트**. 고유 30명과 일반형 영웅 4명 모두 전신 원화와 SD가 있다. **영웅**에서 얼굴 카드를 선택하면 해당 인물의 전신을 볼 수 있다. 선내 지도에서는 투명 배경의 SD 위에 기존 이동·공격 상태를 표시한다. [34명 원화 대조표](validation/HeroRosterArt/Roster.jpg)

**전투 시험값**. 이리스의 역장 종료 공격은 2.5m, 전방 120도, 기본 공격의 1.4배로 설정했다. 같은 층의 시야에 들어온 적 개인만 피해를 받는다. 실제 사망·포드 수송·시설 작동은 공통 선내전 시스템을 사용한다. 고유 효과의 세부 기획은 work의 HERO_ROSTER_30_DETAIL.md가 기준이다.

**개발 재현**. Win64 Development Editor 빌드 후 ControlRange에서 `-OVPlayScene=HeroArena`로 바로 들어간다. 수송 비교는 `Tools/ValidateBoardingWaves.py`를 실행한다. 에디터 자동 검사 필터는 `OrbitalVanguard`다. 에디터에서 `Tools/ValidateHeroArena.py`를 실행하면 시험 편성·진입과 화면을 Saved/Validation에 기록한 뒤 종료한다.

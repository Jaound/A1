# 영웅 전투 시험장

이 PC에서는 `D:\OrbitalVanguardTests\HeroArena_Final\Windows\영웅 시험장.cmd`를 열면 바로 시작한다. 다른 Windows PC에서 시험하려면 같은 폴더의 `Engine`, `OrbitalVanguard`, 실행 파일과 바로가기를 포함한 **Windows 폴더 전체**를 복사한다. 검증 환경은 이 PC의 DX11이다.

임무 목록에서 **영웅 전투 시험장**을 선택한다. 양측 구축전함 한 척씩이 등장한다. 시험장에서는 두 함선의 대함 무장·요격·쉴드를 끈다. 선택할 수 있는 후보는 고유 영웅 30종, 일반형 4종과 편성 가능한 기존 보유 영웅이다.

1. 후보를 넘겨 **1명 배치**를 누른다. 긴 목록에서는 **영웅 → 편성·보직 설정**의 이름 목록으로 후보를 골라 **선택한 후보를 시험장에 배치**할 수도 있다. 생성 레벨은 새 시험 인원에 적용된다. 빈자리를 채워 10명을 편성한다. 상대편에는 수호대 10명이 있다.
2. **영웅**을 열고 이름을 검색하거나 유형·임무·위치·상태 필터로 좁힌다. 이리스 베인을 선택하면 얼굴 카드와 전신 그림이 나온다. 다른 인원은 역할과 이름으로 구별한다.
3. **강습 시작**을 누른다. 각자 자신의 포드에 탑승하며 도착한 인원부터 적함 선내에서 명령을 받는다. 적함의 선내 지도를 열고 진입층에서 영웅을 선택한다.
4. 시설을 선택한 뒤 점령·공작·수호 명령을 내려 이동과 교전을 본다. 함교를 점령하면 승리한다. 철수를 택하면 원래 진입점까지 이동해 포드를 회수한다. 작전 가능한 생존자가 모두 모함으로 돌아오면 부분 성공 결과가 뜬다. 선내 지도에서 확대하면 이리스의 SD, 체력, 선택 표식을 볼 수 있다.
5. 임무를 나간 뒤 일반 함대전을 열어 원래 무장과 보유 명단을 확인한다. 시험장 전투에서 만든 인원과 기존 명단은 분리된다.

**아트**. 이리스의 원본 두 장을 보존했다. 얼굴은 스탠딩에서 추출했고 SD 배경에는 투명 마스크를 적용했다. 그림은 정지 원화이며 현재 모습과 이동·공격 표식을 조합한다. 남은 33종은 공통 역할 표시를 사용한다.

**전투 시험값**. 이리스의 역장 종료 공격은 2.5m, 전방 120도, 기본 공격의 1.4배로 설정했다. 같은 층의 시야에 들어온 적 개인만 피해를 받는다. 실제 사망·포드 수송·시설 작동은 공통 선내전 시스템을 사용한다. 고유 효과의 세부 기획은 work의 HERO_ROSTER_30_DETAIL.md가 기준이다.

**개발 재현**. Win64 Development Editor 빌드 후 ControlRange에서 `-OVPlayScene=HeroArena`로 바로 들어간다. 에디터 자동 검사 필터는 `OrbitalVanguard`다. 에디터에서 `Tools/ValidateHeroArena.py`를 실행하면 시험 편성·진입과 화면을 Saved/Validation에 기록한 뒤 종료한다.

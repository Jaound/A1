# 기지 건설 시험장

**실행**　타이틀의 **작전 개시 · 임무 선택 → 기지 건설 시험장 → 작전 출격**을 누른다. 일시정지 상태에서 코어 I, 일반 자원 1,200, 아군 초계함 1척으로 시작한다. 재시작과 목록 복귀는 오른쪽 위에 있다. 자동 교전과 종료 조건은 없다.

## 처음 창고를 짓는 순서

1. **일자 통로**를 고른다. 고도 0m에서 코어의 청록색 연결구 바로 바깥 칸에 포인터를 둔다. 초록색 윤곽이 뜨면 클릭한다. 빨간색이면 하단의 사유를 확인하고 Q/E로 90° 돌린다.
2. **창고 I**를 골라 통로 끝에 예약한다. 일반 자원은 1,200 → 1,160 → 860이다. 창고의 **연결 대기**는 정상이다. 왼쪽 아래 **재개**를 누르면 통로가 15게임초 뒤 완공되고 창고의 60게임초가 시작된다.
3. **함대 화면**에서 초계함을 움직이거나 배속을 바꾸고 **기지**로 돌아온다. 각 화면의 시점, 함선 명령, 현장 재고와 대기열이 이어진다. 일시정지 중에는 배치와 예약만 할 수 있다.
4. **분기 허브**를 다른 코어 포트에 예약한다. 진행 중인 허브를 선택한 뒤 **공사 취소 · 전액 환불**을 누르면 40이 돌아온다. 통로를 지웠을 때 창고가 고립된다면 먼저 창고 예약을 취소해야 한다.
5. **재시작**하면 함선·코어·재고와 배치 높이·회전·예약이 초기화된다. **목록 복귀**는 시험장 카메라와 모듈을 정리한다.

| 조작 | 기능 |
| --- | --- |
| Q / E | 배치 방향을 좌우 90° 회전 |
| R / F | 배치 평면을 위아래 25m 이동 |
| 방향키 / 휠 | 기지 시점 회전 / 확대·축소 |
| Space / 1·2·3 | 시간 정지·재개 / 1·2·3배속 |
| 시설 선택 → 격자 클릭 | 해당 층의 공사 상태와 취소 확인 |
| Esc | 함대 화면 복귀 |

## 소형 조선소와 표준 접안 모듈

왼쪽 카드에서 시설을 선택한 뒤 통로 끝의 다음 칸을 가리킨다. 흰색 모델 사진은 선택 중인 시설, 격자의 테두리는 회전한 본체, 청록색 전방선은 함선 출입 방향이다. R로 25m 올리고 F로 내린다. Q/E로 연결면이 통로 쪽을 향하게 돌린 뒤 초록색일 때 클릭한다. 기지에서 숫자 1·2·3은 배속, Space는 정지·재개다. 함대 화면의 부대키는 기존 조작을 유지한다.

| 시설 | 본체 | 일반 자원 | 건설 시간 | 함선 진입면 (기본 방향) |
| --- | --- | ---: | ---: | --- |
| 소형 조선소 | 4×3×3칸 | 650 | 120게임초 | 짧은 끝면 −X |
| 표준 접안 모듈 | 4×3×2칸 | 350 | 75게임초 | 긴 측면 +Y |

입구 앞으로 2칸(50m)은 개구 앞 전체 폭을 확보한다. 이어지는 중앙 비행선은 시험 공간 경계까지 비어 있어야 한다. 나중에 통로를 배치해 이미 예약한 출입로를 막는 것도 차단한다. 양쪽을 한 세션에서 확인하려면 첫 시설을 완공하고 다른 코어 연결구에 두 번째 통로와 시설을 짓는다. 통로 2개와 시설 2개를 예약하면 일반 자원이 120 남는다.

원본 후보 중 **소형 접안 모듈**의 측면 베이가 실제로 관통되어 표준 도크로 사용했다. 포트 번호와 좌표, 렌더·출입로·패키지 검증은 [2단계 기록](validation/BaseTrial2/README.md)에 있다.

## 기획 · 원본 · 공간

기획 `40bba6e`의 [기지 통합 명세](https://github.com/Jaound/A1/blob/40bba6e/docs/01_design/strategy/BASE_MASTER_GDD.md)와 [인터페이스 v0.2](https://github.com/Jaound/A1/blob/40bba6e/docs/01_design/interface/BASE_INTERFACE_DRAFT.md)를 기준으로 초기 구현 `175ecb4`를 통합했다. 격자 한 칸은 25m다. 코어 I는 기능 모듈 8개, 연결 모듈 24개, 동시 기능 공사 1개를 허용한다. 통로와 허브는 별도로 공사한다. 시험 재고는 이 임무에서만 존재한다.

| 원본 모듈 | 점유 | UE 메시 이름 (`/Game/Presentation/Base` 아래) | 연결면 |
| --- | --- | --- | --- |
| 기지 코어 모듈 | 5×5×5 | SM_OV_Base_CoreHub_5x5x5 | 수평 4면. 꼭대기 안테나 제외 |
| 일자 통로 모듈 | 1×1×1 | SM_OV_Base_CorridorStraight_1x1x1 | 앞·뒤 |
| 사거리 통로 모듈 | 1×1×1 | SM_OV_Base_CorridorHub_1x1x1 | 수평 4면과 위·아래 |
| 자원 저장소 | 2×2×2 | SM_OV_Base_StorageVault | 돌출된 단일 출입구 |

원본 FBX의 세 방향 투영과 끝단 단면에서 접합면 중심을 추정했다. 축 방향 이름(XP·XN 등)은 모델 로컬 기준이다. 사용자 표시 P1/P2 도면은 제공되지 않았다. 원본을 보존하고 전장용 메시를 약 8만 삼각형, 색·노멀·거칠기·금속 맵을 각각 1024²로 준비했다. 모델별 측정값과 해시는 [소켓 기록](validation/BaseTrial/Ports.json)에 있다. 논리 격자로 점유와 접근을 검사한 뒤 실제 소켓 중심을 맞댄다. 기존 연결망의 양쪽과 동시에 접합해야 할 때는 5cm 허용 오차를 검사한다. 수직 연결은 허브를 사용한다.

**검증과 범위**　[실행 기록](validation/BaseTrial/README.md). 저장·철거·자동 배선, 조선·접안·연구·기지전·캠페인 재고는 후속이다.

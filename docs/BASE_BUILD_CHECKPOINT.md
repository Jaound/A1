# 기지 건설 시험장 체크포인트

기획 기준은 [기지 통합 명세 v1.0](https://github.com/Jaound/A1/blob/bd66dea/docs/01_design/strategy/BASE_MASTER_GDD.md)이다. 캠페인·튜토리얼과 분리한 개발용 진입점으로 코어 I와 일반 자원 1,200만 준비한다.

일반 전장의 상단 **기지**로 전환한다. 기지 상단의 **함대 화면** 또는 Esc로 복귀한다. 기존 함대와 시간은 이어지며, 건설은 동일 게임 시간과 배속을 사용한다. 기지에서는 방향키와 휠로 시점을 조정하고, Q/E로 배치를 90도 회전하고 PageUp/PageDown으로 높이를 25m씩 바꾼다. F1과 F2~F4는 시간 제어다. 기지 화면 전환과 조작은 로컬 UE 빌드 후 확인해야 한다.

25m 격자의 코어 중앙 높이에서 통로→창고를 배치한다. 완성된 연결이 생길 때 창고 공사가 진행된다. 시험 범위는 점유 격자, 마주보는 포트, 예약, 건설 슬롯, 취소 전액 환불, 기지와 함대 화면 전환이다. 임시 자원은 캠페인 재고와 분리했다. 자동 배선, 철거, 저장, 피해·수리, 나머지 모듈, 코어 성장, 연구·조선·접안과 쉴드 기능은 후속이다.

## 모델 연결

현재는 기본 박스가 노출된다. 모델이 준비되면 네 정적 메시를 아래 이름으로 `/Game/Presentation/Base`에 반입한다. 원본 FBX 기준은 하단 중앙 피벗, +X 전방, cm, Z-up이다. 논리 포트와 실제 소켓 좌표, 표시 범위, 방향과 패키징 포함을 UE에서 점검한다. 현재 메시 표시 경로는 지정 경로의 자산을 로드하는 수준이다. 소켓 검사와 충돌 자산 생성은 후속이다.

| 모듈 | 자산 이름 |
| --- | --- |
| 코어 | `SM_OV_Base_CoreHub_5x5x5` |
| 통로 | `SM_OV_Base_CorridorStraight_1x1x1` |
| 분기 허브 | `SM_OV_Base_CorridorHub_1x1x1` |
| 창고 | `SM_OV_Base_StorageVault` |

독립 C++17 검사에서 예약 순서, 겹침, 연결, 높이와 회전, 취소 환불을 확인했다. UE 빌드, PIE, 실제 입력·렌더링은 Windows 작업 환경에서 확인한다.

## 1. 3D 물리 · 함선 기동 · 자세 정렬 · 충돌/충각

### 1.1. 함선 간 겹침 방지(2단계 분리) 및 충각(Ramming)
* **발견된 문제:** 단순 좌표 이동(`position += dir * step`)만 구현되어 함선끼리 서로 통과하며 포개지는 현상이 발생함.
* **해결 설계:**
  1. **소프트 회피(Separation Steering):** 두 함선 간 거리가 `(A 반경 + B 반경 + 안전거리 8m)` 이내면 밀어내는 회피 벡터 적용. **체급 우선순위(`ship_scale`)**를 두어 대형·초대형함은 진형을 유지하고 소형·중형함이 더 많이 비켜나도록 가중치 배분.
  2. **하드 충돌 분리(Hard Pushback):** 실제 바운딩 반경(`half_extents`)이 겹치면 침투 깊이만큼 즉시 좌표를 강제 분리해 **절대 겹치지 않게** 보장.
  3. **충돌/충각 피해:** 아군 접촉은 대미지 없이 감속만 적용. 적함 충돌 시 `상대 속도 × 체급(질량) 계수`로 대미지를 산정해 `전방향 쉴드 → 충돌 층 장갑 → 선체 체력` 순으로 적용(충돌 쿨타임 1.0초). 충각 특화 함선 확장을 위해 `ram_damage_mult` 및 `ram_self_mitigation` 속성 분리.

### 1.2. 가속·감속 관성 커브 및 `[이동 정지(X)]` 버튼
* **발견된 문제:** 출발 시 즉시 최고 속도, 정지 시 즉시 속도 `0`이 되어 우주 거함의 무게감이 없고, 이동 중 제자리에 멈추는 정지 명령 버튼이 없었음.
* **해결 설계:**
  * 함선 체급별 `accel_rate` / `decel_rate` 관성 커브 적용(대형함일수록 제동 거리가 길어짐).
  * 하단 HUD **`[이동 정지(X)]`** 버튼 추가: 누르면 이동/호위/방향 명령을 취소하되 속도를 즉시 `0`으로 깎지 않고 감속 관성에 따라 미끄러지며 자연스럽게 정지.
  * **주의할 오류 방지:** 정지 버튼을 눌렀는데 `AUTO` 모드 함선이 다음 틱에 적을 향해 다시 이동하지 않도록 **`hold_position = true`** 플래그를 켜서 새 이동 명령 전까지 제자리 고정 사격만 수행.

### 1.3. 이동·선회 속도 일괄 50% 너프 + 체급별 선회 격차 확대
* **발견된 문제:** 모든 함선이 지나치게 빠르고 선회력 차이가 적어 소형함과 대형함의 기동 전술 차이가 부족함.
* **세부 수치 및 해결 설계:**
  * 이동 속도(`max_speed`): 전 함종(함재기 제외) 기존 대비 **50% 하향**.
  * 선회 속도(`turn_rate`): 50% 이상 하향하되 체급별 격차를 극대화 — **소형 `0.85~1.05` / 중형 `0.36~0.48` / 대형 `0.16~0.18` / 초대형 `0.09~0.10 rad/s`**.
  * **주의할 오류 방지 (대형함 오빗 버그):** 선회가 느려진 대형함이 가까운 목적지를 찍었을 때 목적지 주변을 빙빙 도는 무한 선회 버그를 막기 위해, 근거리에서는 전진 속도를 줄여 선회 정렬 후 전진하고 도착 판정 반경을 `half_extents.z`에 비례해 확대.

### 1.4. 이동 후 선체 방향 유지(측면 포격) ↔ 정지 자세 정렬 보정 분리
* **발견된 문제:** ① 이동 완료 후 적이 사거리 안에 있으면 정면(`forward`)을 적에게 강제 회전시켜 측면 포격(좌현/우현)이 불가능했음. ② 반대로 함선들이 마구잡이로 돌다 멈춰서 위/아래/옆을 보며 제각각 서 있는 문제도 발생.
* **해결 설계:**
  * **Pitch/Roll 수평 복원**과 **Yaw 전방 정렬**을 명확히 분리한다.
  * 정지 시 위아래로 코를 박거나 뒤집히지 않도록 **`Pitch ≈ 0°` 수평 복원(`up_vec` = World UP)**은 기본 적용.
  * `Yaw` 방향은 **일반 자동 편대 이동 완료 시에만** 편대 공통 전방 벡터로 나란히 정렬하고, **유저가 `[선체 방향 지정]`을 했거나 `MANUAL` 모드에서 측면 포격 자세를 잡아둔 경우에는 `Yaw` 각도를 유지**한 채 사각이 나오는 포탑으로 사격.

### 1.5. 편대 속도 동기화(Match Speed) 및 전술 열(Tier) 배치
* **해결 설계:** 편대 이동 시 편대 내 **가장 느린 함선의 속도에 맞춰** 진형을 유지하며 전진(교전 돌입 시 해제). 오프셋은 **전열(전함·구축전함·순양함) — 측면(초계·호위함) — 중열(방공·레이더함) — 후열(항모·전략미사일·보급수리함)** 역할에 맞춰 자동 배정.

### 1.6. 함선 체급별 3D 크기 10%씩 확대 차등
* **세부 수치:** `half_extents`를 소형 **`1.00배`** 기준 → 중형 **`1.10배`** → 대형 **`1.21배`** → 초대형 **`1.33배`**로 확대.
* **주의할 오류 방지:** 모든 충돌·피격·도킹 반경과 카메라 최소 줌 거리(`zoom_min`)는 고정 상수가 아닌 `half_extents`를 동적 참조하도록 구현.

## 2. 무장 · 포탑 추적 · 쉴드 · 체급 1:5 밸런스

### 2.1. 포탑 물리 회전(Turret Traverse) 및 관성 추적 유지
* **발견된 문제:** 발사 순간에만 적을 향했다가 즉시 정면으로 스냅백(Snap-back)되는 어색함이 있었고, 포탑 회전 속도 차이가 없어 소형함이 대형함 주포를 선회로 회피할 수 없었음.
* **해결 설계:** `WeaponMount`에 **함선 로컬 좌표 기준** `turret_local_yaw`, `turret_angular_vel`, `turret_turn_rate`(대형 주포 느림 / 소형 속사포 빠름), **`target_hold_timer = 3.5초`** 도입. 발사 후 3.5초간 목표 방향을 관성 유지하다가 목표 상실 시 서서히 대기 각도로 복귀(로컬 좌표 보간으로 선체 선회 간섭 방지). 포탑이 목표와 `12°` 이내 정렬 시 발사.

### 2.2. 무기 공속 서열(`빔 > 함포 > 미사일`) 및 VLS 곡선 살보(Salvo)
* **세부 수치:**
  * **빔(가장 빠름):** 연발 `0.9s`, 거대 `2.2s`
  * **함포(중간):** 속사 `1.8s`, 대구경 `3.8s`
  * **미사일(가장 느림):** 일반 **`6.5s`**, 유도 **`8.0s`**
* **주의할 오류 방지:** 미사일 쿨타임이 긴 만큼 단 1발만 쏘면 요격에 막혀 무력화되므로, **1회 발사 시 2~3발을 `0.22s` 간격으로 연속 사출(Salvo)**하고 초기 수직/측면 편향 후 목표를 향해 곡선 비행(VLS 연출)하도록 구현.

### 2.3. 일반 무장의 함재기 조준 금지 & 요격(PD) 밸런스 하향
* **발견된 문제:** ① 일반 주포/미사일이 함재기를 조준해 화력을 낭비함. ② 요격 사거리가 길고 포탑이 너무 많으며 100% 명중해서 미사일·함재기가 전멸함.
* **해결 설계 및 세부 수치:**
  * **표적 분리:** 일반 무장(빔/함포/미사일/특수)은 함재기(`is_fighter`)를 절대 조준하지 않음. 오직 **요격 시스템(PD)**과 **적 함재기**만 함재기를 조준(모함/`함재기 운용 시설` 무력화 시 남은 함재기 작동 정지로 전투 종료 보장).
  * **요격 사거리를 기존의 60%로 조정(40% 감소):** `PD_LASER` `185m → 111m`, `PD_FLAK` `210m → 126m`.
  * **중형 이상 요격 수 50% 축소:** 소형 `2` 유지 / 일반 중형 `3` / 레이더함 `1` / 방공함 `11` / 대형 `5` / 초대형 `8` / 전투기지 `6`.
  * **요격 명중률 판정 도입:** `PD_LASER` 기본 `72%`, `PD_FLAK` 기본 `62%`에서 **대상별 회피율 차감**(함재기 `0.62`, 강습 포드 `0.40`, 미사일 `0.25`).

### 2.4. 쉴드 활성화 중 회복 금지 & 회복 속도 50% 감소
* **발견된 문제:** 쉴드가 켜져 있는(활성화) 상태에서도 실시간 회복되고 있었으며 회복 속도가 너무 빨랐음.
* **세부 수치 및 보완:**
  * `shield_broken == false`(활성화) 상태에서는 **회복 전면 금지**. 오직 비활성화 상태에서만 **초당 최대 쉴드의 `3.0%`**(기존 대비 50% 속도 감소, 딜레이 `6.5초`)로 회복 후 `50%` 도달 시 자동 활성화.
  * **주의할 오류 방지:** 50%에서 켜진 뒤 전투가 끝나도 영구히 50%에 고정되는 문제를 막기 위해 **비피격 15초 이상 경과(비전투 상태) 시 완충 회복** 또는 HUD **`[쉴드 재충전]`** 버튼 제공.

### 2.5. 개별 무장 내구도(Weapon HP 2배) 및 체급별 1:5 계단식 밸런스
* **무장 내구도:** 모든 `WeaponMount`에 고유 `hp / max_hp`(기존 대비 **2배** 상향, 파괴 시 수리 전까지 발사 불가) 부여 및 보급·수리함 무장 수리 속도 2배 연동.
* **체급별 1:5 밸런스 & 티어 상한:** 평균 전투력 **소형 5 ≈ 중형 1, 중형 5 ≈ 대형 1, 대형 5 ≈ 초대형 1** 격차 적용. 장착 무장 티어 상한: **소형 T1 / 중형 T2 / 대형 T3 / 초대형 T3~T4**.
* **주의할 오류 방지 (0대미지 방지):** 소형함 저티어 무장이 대형함 장갑에 완전히 막히지 않도록 최소 관통/마모 피해 보장 + 느린 대형 포탑 추적 상성으로 균형 유지.

## 3. 함재기 · 격납고 · 강습 포드 · 보급수리

### 3.1. 함재기 생존성 버프, `1:20` 격납고 비율, 일제 출격·귀환·도그파이팅
* **세부 수치:** 함재기 **`hull 160 / shield 75 / evasion 0.62`**로 대폭 버프, 기본 무장 + 업그레이드/개조 확장 필드(`fighter_tier`) 추가. 격납고 수용 비율 **`소형함 1 : 함재기 20`** 확정(최대 100대).
* **기동 및 출격/귀환:**
  * **일제 출격 & 재고 차감:** 교전 시 가용 함재기를 3D 부채꼴 오프셋으로 **한 번에 동시 출격**하며, 완파 시 `remaining_fighter_reserve`에서 영구 차감(무한 재생성 금지).
  * **입체 도그파이팅:** 기체별 고유 고도·선회 방향과 **돌진 사격(Attack Pass) → 이탈 선회(Break-off, 55~85m) → 재돌입**으로 기차 놀이 방지.
  * **자동 귀환·수리:** 비전투 `5초` 경과 시 모함 격납고로 귀환해 수리·재무장. 모함 FTL 충전 시 외부 함재기에 **즉시 긴급 귀환(1.5배속)** 명령.

### 3.2. 병력당 초소형 강습 포드 1기 개별 발사 & 탑승 필터링
* **세부 수치:** 유닛(영웅/분대) 1개당 포드 1기를 `0.25s` 간격으로 개별 발사. 크기 **`반지름 0.55 / 길이 1.8`**(함재기보다 작음), 속도 **`165 m/s`**, 회피 **`0.40`**.
* **오류 방지:**
  * 같은 Wave 포드들은 선도 포드가 뚫은 진입 슬롯(또는 인접 슬롯)으로 합류해 각개격파 방지.
  * 발사 시 `[보직배치]` 영웅 및 `[구역 수호]` 분대는 자동 차출에서 제외. 귀환/구조 시에는 모함의 `강습포드실` 또는 `격납고`로 정확히 복귀.

### 3.3. 보급·수리함 수동 `[수리 대상 지정(R)]` 버튼
* `repair_target_id` 추가 및 HUD 전용 버튼 제공: 아군 또는 노획 함선을 좌클릭하면 자동 수리보다 우선하여 해당 함선의 선체·장갑·시설·무장·승무원을 집중 수리.

## 4. 3D 조작 · UI/UX · 플로팅 윈도우 · 전술 센서 · 연출

### 4.1. 수동 모드 조작성 및 3D 이동 원근 시차(코앞 찍힘) 해결
* **표적·방향 지정:** HUD에 **`[공격 대상 지정(T)]`**, **`[표적 해제]`**, **`[선체 방향 지정]`**, **`[초광속(FTL) 이동]`** 버튼 명시적 배치. 적함 우클릭 판정 임계값 `25px` 완화.
* **원근 시차 해결(홈월드 방식):** 우클릭 즉시 함선 고도($Y$) 평면에 **반투명 전술 이동 디스크**와 커서 교차점 링을 시각화하고, `8px` 이상 실제 드래그 시에만 고도 기둥/툴팁 표시. 카메라 근접 클리핑(최소 35m) 및 얕은 피치 각도 보정 적용.
* **빈 공간 클릭 시 선택 해제 & `F` 키 카메라 추적 토글** (`WASD` 시 해제).

### 4.2. 함선 UI 플로팅 윈도우화 & 독립 3D 함선/무장/격납고 뷰어
* **플로팅 윈도우:** 함선 미선택 시 숨김(`visible = false`). 선택 시 3D 뷰포트 위에 인터넷 창처럼 **드래그 이동, 모서리 리사이즈, 최소화(하단 작업 바 칩), 최대화, 닫기(`X`)** 가능한 창으로 표시(`MOUSE_FILTER_STOP`으로 뒤쪽 3D 클릭 투과 차단).
* **독립 3D 뷰어(`own_world_3d = true`):** 함선 클릭 시 1차 화면으로 3D 모델이 뜨며 휠 드래그로 360도 회전 가능. 각 층 갑판과 실제 위치의 3D 무장을 내구도 색상(**초록 → 노랑 → 빨강 → 회색**)으로 표시. 무장 클릭 시 상세 스펙(이름/종류/티어/내구도/사거리/현재 목표) 표시. 상단 `1F/2F/3F` 버튼으로 2D 단면도 전환, `[격납고]` 클릭 시 내부 소형함/함재기 목록 및 출격 제어(노획 전투함은 출격 잠금). 아군 강습 중일 때 `[강습 중인 적함 보기]` 바로가기 제공.

### 4.3. 3D 사거리 동시 시각화, 전술 센서 오버레이, 연출 및 디버그
* **3가지 사거리 동시 표기:** 대표 함선 1척 기준으로 **보장 근거리(얇은 점선)** + **무장 사거리/선택 사각(실선+부채꼴/수직 아치)** + **실제 레이더 탐지 사거리(보라 대시 원 + 거리 라벨)**를 동시 표시.
* **전술 센서 오버레이:** `Tab` 또는 줌아웃(`distance >= 420m`) 시 배경을 눌러주고 함선 전술 심볼 + $Y=0$ 수직 고도선 + 레이더 범위 + 이동 궤적 강조.
* **전투 연출:** 대형함 이상 완파 시 2.5~3.5초 기울어지며 연쇄 폭발 후 소멸(**Death Throe**), 주요 전황 함대 무전 토스트 출력.
* **기지 개조 검증 & 디버그 패널:** `ShipyardModal`에서 필수 4대 시설 및 무장 연동 필수 시설 삭제 차단. `F9` 디버그 패널(세력/함종 선택 소환, `[AI 동결]` 토글, `[전장 초기화]`) 제공.

## 5. 6면 세분화 장갑 시스템 (전1/후1/좌·우·상·하 3×3) 추가 반영

* **세부 구조:** 전면 장갑(단일 1구획, 최상위 내구도), 후면 장갑(단일 1구획), 좌·우·상·하 장갑은 함선 층수 연동(`3층=3×3`, `2층=2×3/3×2`, `1층=1×3`).
* **내구도 정책:** 게임 템포를 늦추고 장갑 회전 전술을 살리기 위해 각 세분화 칸마다 **기존 면 장갑 내구도 그대로(100%)** 부여.
* **충돌 방지:**
  * 6면 정규화 좌표로 피격 면/칸 확정, 전면 관통 시 실제 탄착 높이($Y$)의 전방 슬롯으로 피해 전달.
  * 단일 전·후면 장갑은 내부 시설 파괴 시 즉시 증발하지 않도록 예외 처리.
  * 보급·수리함은 `전면/핵심 인접 구획 → 최저 내구도 비율 구획` 순으로 스마트 수리.
  * 우측 3D 함선 뷰어 외피 위에 구획별 색상(초록→노랑→빨강→회색) 직접 렌더링.

# 플레이 화면·영웅·무장 조작 안내

이 안내는 현재 화면의 사용법이다. 빌드·자동 검사·렌더·성능 결과는 [최신 진행 기록](PLAY_UI_PROGRESS.md)과 해당 검증 기록에서 따로 확인한다. 아래 조작 순서를 작성했다는 사실이 직접 플레이 검증 성공을 뜻하지 않는다.

기본 화면은 **함선, 영웅, 표적, 지금 할 행동**을 중심으로 구성한다. 코드명·개체 ID·해시·검증 문단은 기본 플레이 화면에 나열하지 않는다. 상세 설명은 툴팁에, 시험 수치와 직접 상태 조작은 개발창의 **고급 진단**에 둔다.

## 시작

PowerShell에서 다음 명령으로 별도 플레이 창을 연다.

```powershell
Set-Location -LiteralPath 'C:\Users\user\source\repos\A1'
.\Unreal\OrbitalVanguard\Tools\RunMission.ps1 -Mode Attack
```

- 엔진: `E:\UE_5.8`의 UE 5.8.4.
- 프로젝트: `C:\Users\user\source\repos\A1\Unreal\OrbitalVanguard\OrbitalVanguard.uproject`.
- 공격 임무는 일시정지 상태로 준비된다. 상단 **시작 ▷**를 누른다.
- 방어 임무는 `-Mode Defense`, 함대만 비교하는 임무는 `-Mode FleetOnly`로 연다.
- 에디터에서 실행하려면 `Unreal\OrbitalVanguard\Tools\RunEditor.ps1`을 사용하고 Play를 누른다. `Esc`는 PIE 종료, `Shift+F1`은 에디터로 마우스 제어 반환이다.

상단 **장면**에서 기본 전투, 함대 교전, 모함·운송, 강습 임무, 방어 임무, 함대만 비교를 고를 수 있다. F5/F6/F7의 기존 시험장도 유지한다. 장면 변경은 현재 시험 전투의 초기화이므로 진행 중 임무의 이어하기가 아니다.

## 기본 화면 읽기

| 위치 | 확인·조작 |
| --- | --- |
| 상단 | 장면, 시작/정지, 1·2·3배속, 전체 보기, 영웅, 개발 도구 |
| 왼쪽 함대 목록 | 아군/적군 기호, 이름, 선체·쉴드 게이지. 클릭하면 선택 |
| 전장 | 선택 테두리, 공격 표적, 고도, 이동 목적지, 실제 발사·피격 표현 |
| 아래 지휘부 | 선택 함선과 표적, 이동·사격 자동화, 이동/정지/발사, 추적·상세·선내 지도 |
| 임무 안내 | 현재 단계, 강습 투입, 시설 목표, 철수, 진입·회수 인원 |

영웅창과 개발창은 필요할 때 열고 닫는다. 개발창을 닫으면 생성 도구와 긴 진단 정보가 사라진다. 사격 차단은 선택 무장의 짧은 사유로 확인한다. **조준 중**, **사거리 밖**, **탐지 상실**, **공급 정지**, **내부 아군 보호**는 각각 다른 상태다.

### 선택·이동·사격

1. 왼쪽 함선 카드나 전장의 함선을 클릭한다. **추적** 또는 F로 선택 함선에 카메라를 맞춘다. **전체 보기** 또는 Home으로 교전 구도로 돌아간다.
2. 전장에서 중클릭 드래그 또는 Alt+왼쪽 드래그로 회전하고, 휠로 줌한다. WASD로 평면 이동한다.
3. 아군을 선택한 상태에서 목적지를 우클릭한 채 위아래로 드래그한다. 누른 위치의 평면 좌표를 유지하면서 고도를 조정하고, 놓을 때 이동을 확정한다. 휠은 카메라 줌이다.
4. 정밀 지정은 하단 **이동** 또는 V로 시작한다. 평면 위치를 고르고 **Shift를 누른 채 드래그**하여 고도를 조정한 뒤 클릭 또는 Enter로 확정한다. Backspace로 취소한다.
5. **표적 지정**을 누른 뒤 적을 클릭한다. 표적 지정과 발사는 별도다. **선택 발사** 또는 **전체 발사**를 눌러 요청한다.
6. 이동 자동화와 사격 자동화를 각각 켜고 끈다. **정지**는 이동을 멈추며, 사격 자동을 켰다고 수동 이동 목적지를 새로 지정하는 기능은 아니다.

F1/Space는 정지·진행, F2/F3/F4는 1/2/3배속이다. 일시정지 중에도 화면과 카메라를 조작할 수 있다. 게임 안 스킬·포탑·발사체 시간은 전투 시간에 따른다.

## 영웅을 찾고 지시하기

상단 **영웅**을 누른다. 초상화의 얼굴·장비와 역할 이름으로 근거리, 원거리, 지원, 지휘를 구분한다. 선택 테두리, HP 게이지, 상태 배지는 실제 인원 상태를 읽는다.

- **보유 영웅**은 현재 명단의 개인이다. **임무 전용 영웅**은 해당 시험 임무의 예시 인원이며 보유 명단에 지급되지 않는다.
- 카드 위 선택 요약과 **위치 찾기·선내 지도·철수**는 목록을 스크롤해도 상단에 남는다.
- **위치 찾기**는 현재 함선을 따라간다. 포드 비행 중에는 해당 개인의 실제 포드 위치로 이동하며, 없는 위치를 임의로 만들어 표시하지 않는다.
- **선내 지도**는 그 영웅의 실제 함선·층·선택 인원으로 열린다. 운송 중에는 선내 도착 전 위치로 연결하지 않는다.
- 명단이 비었다면 **영웅 시험 장면**에서 대표 예시 인원으로 시작할 수 있다. 기존 보유 명단을 매번 늘리는 기능이 아니다.

미배치 상태에서 최대 HP를 확인할 수 없는 카드는 빈 HP를 0으로 단정해 표시하지 않는다. 구조 대기·포로·실종·사망은 귀환과 다른 상태이며, 카드를 다시 선택한다고 회복하거나 부활하지 않는다.

### 선내 지도

1. 왼쪽 아군 인원 행 또는 지도 위 인물을 클릭해 선택한다. 여러 명을 차례로 클릭하거나 **아군 전체**를 사용한다.
2. 층을 고르고 시설을 클릭한다. **점령·공작·수호** 중 원하는 명령을 누른다. 시설 선택만으로 명령을 확정하지 않는다.
3. 선택 경로, 실제 이동, 교전, HP와 작업 진행을 본다. **취소**는 현재 명령을 취소한다.
4. **철수**를 누르면 원 진입점까지 이동한 뒤 원 포드 또는 생존 강습선으로 회수한다. 선내 이동을 생략하거나 새 운송수단을 무료로 만드는 명령이 아니다.

영웅은 역할 장비를 가진 큰 인물, 일반 병력은 작은 인물로 표시한다. 걷기·사격·피격·작업·사망의 임시 표현은 실제 상태를 따른다. 적 내부는 관측 권한에 따라 잠기며, 구조를 알게 된 뒤에도 보이지 않는 적 인원과 시설 상태를 모두 공개하지 않는다.

### 스킬·편성·보직

스킬은 현재 **조건에 따른 자동 사용**이다. 스킬 카드에는 이름·등급·잠금 또는 남은 시간이 표시된다. 비전투 상태에서 성장 포인트가 있고 투자 가능한 스킬을 클릭하면 등급을 올린다. 클릭을 수동 스킬 발동으로 해석하지 않는다. 상세 효과는 툴팁에서 확인한다.

**편성 · 보직 설정**을 펼치면 보유 영웅의 편성/해제, 선택 함선 배치, 강습 편성/해제, 시설 보직/해제를 사용할 수 있다. 보직은 해당 시설까지 실제 이동·인계를 거친다. 강습 편성은 함선 배치와 별도이며, 보직 중인 인원을 보내려면 먼저 보직을 해제한다.

보유 명단으로 임무를 시작하려면:

1. **편성실 이동**으로 비전투 상태에 들어간다.
2. 원하는 보유 영웅을 **편성**한다. 세력 전체 동시 배치 한도는 15명이며 현재 보유 편제 시험 임무는 1~4명으로 구성한다.
3. **보유 편제로 출전**을 누른다. 같은 개인의 HP·스킬·소모품·손실 상태를 사용한다.
4. 실제 전투로 쉴드를 제거하고 포드 또는 강습선을 투입한다. 시설 목표나 철수를 지시한다.
5. 생존자를 회수하고 임무 결과를 확인한 뒤 편성실에서 다시 출전한다.

보유 편제 임무에서는 **현재 장면 재시작**을 보류한다. 진행 중 인원을 예시 영웅으로 바꾸거나 무료 회수하지 않기 위한 경계다. 회수되지 않은 인원·미종료 작전 때문에 편성실에 들어갈 수 없으면 짧은 사유를 따른다. 예시 시험 임무의 재시작과 보유 명단 초기화는 서로 다르다.

## 함선 상세·실제 무장 보기

함선을 선택하고 하단 **함선 상세**를 누르면 **외부 / 무장**이 기본으로 열린다.

- 프리뷰 위 중클릭 드래그로 회전하고 휠로 확대한다. 외부 무장 표식을 클릭하면 해당 장착점을 선택한다.
- 선택 무장의 HP·티어·상태와 전장의 발사 차단 사유를 함께 확인한다. 프리뷰는 원 함선의 표시를 읽으며 별도 전투·피해·재고를 만들지 않는다.
- 층 버튼은 실제 층수만큼 표시한다. 층별 화면은 시설·내구 요약이고, 영웅의 실제 이동·교전 지시는 **선내 지도**에서 한다.
- **격납고**는 실제 장착된 공간의 용도와 보관 수를 보여준다. 출격과 귀환은 실제 기체를 이동시키며 귀환 자체로 무료 수리되지 않는다. 적 재고는 미확인으로 남긴다.
- 제목줄을 끌어 이동하고 오른쪽 아래 모서리로 크기를 조정한다. 제목줄의 최소화·크기 전환·닫기를 사용할 수 있다.
- **핀**은 최대 2척이다. 상세창과 영웅창을 닫으면 오른쪽에 고정 외부 요약이 보인다. 고정 카드를 클릭해 상세를 다시 열고 **핀**을 눌러 해제한다. 독립적인 전체 상세창을 무제한 만드는 기능은 아니다.

실제 전장에서 포탑 받침대와 회전부·포신이 구분되고, 포탑은 전투 판정의 조준각을 따른다. 포구·빔·미사일·요격 표현은 실제 발사 사건과 연결된다. 고정 수직 발사관은 포탑처럼 회전하지 않는다. 발사 조건이 막히면 효과만 재생하는 가짜 사격을 하지 않는다. 최종 메시·애니메이션 완성 여부와 이 기능은 별도다.

## Insert 개발 도구

Insert 또는 상단 **개발 도구**로 연다. 기본은 **함선·영웅·무장·시험**의 네 분류다. 이름 검색과 카드를 사용하고, 세부 수치가 필요할 때만 아래 **고급 진단**을 펼친다.

| 분류 | 기본 사용 순서 |
| --- | --- |
| 함선 | 함선 카드 → 아군/적군 → 수량·프리셋 → **생성 · 빈 공간에 배치** |
| 배치된 함선 | 목록에서 실제 개체 선택 → **선택·추적·선내·삭제** |
| 영웅 | 비전투 편성실 → 역할 초상·세력·이름·생성 위치 → **영웅 생성** |
| 무장 | 전장에서 함선 선택 → 무장 카드·장착점 → **장착 / 교체** → 표적 지정 → 발사 요청 |
| 시험 | 장면 선택·정지/진행·장면 재시작 |

생성은 명시적 시험 공급이다. 기본 함선은 기체·병력 0이며 항모·강습 프리셋을 고를 때 지정 수량을 공급한다. 격납고 설치 상한을 실제 장착 수나 무료 기체 지급 수로 해석하지 않는다. 함재기는 모함의 실제 재고에서 출격하고, 포드는 실제 승객을 운송한다.

생성 위치가 겹치거나 지원하지 않는 조합이면 사유를 확인한다. 무장 교체는 계열·티어·실제 장착 조건을 검사한다. 요격 무장의 직접 교체 등 미지원 기능은 활성화된 정상 기능으로 취급하지 않는다. 시험 함선 삭제는 미회수 기체·승객·원 포드 연결 때문에 거부될 수 있다.

**고급 진단**에는 직접 XYZ 배치, 시험 경험치·명단 저장, 유한 시험 자원, 직접 피해·시설 조작, 구현/검사 상세가 남아 있다. 이 도구로 만든 성공을 정상 임무의 성공으로 기록하지 않는다. 명단 저장은 비전투용이며 전투 월드 전체 저장이 아니다.

- 원본 해제본: `C:\Users\user\Documents\OrbitalVanguardAssets\Source`
- 수정본: `C:\Users\user\Documents\OrbitalVanguardAssets\Prepared`
- 원본 조사·변환 기록: `C:\Users\user\Documents\OrbitalVanguardAssets\Reports`

PC14 원본 기반 초계함은 **개발용 외형 확인 옵션**이며 기본 적용이 아니다. 엔진 콘솔에서 `ov.Presentation.ImportedHull 1`을 입력한 뒤 초계함이 생성되는 새 시험 장면에서 확인한다. `0`으로 돌리고 새 장면을 만들면 기본 임시 외형을 사용한다. 이 옵션은 무장 배치·충돌·화력을 바꾸지 않는다. 원본 선체 표면과 임시 장착점의 정합, 합쳐진 원본 무장의 안전한 가동 부품 분리는 후속 작업이다.

## 5~10분 직접 확인

다음은 사용자가 수행할 점검표다. 이번 OS 화면 제어 시도는 메모장 캡처 시간 초과로 막혀 **실제 마우스·키보드 조작은 미검증**이다. API 호출과 엔진 렌더 캡처를 직접 입력 성공으로 대신하지 않는다.

- [ ] **1분:** 공격 임무를 열고 아군·적군·선택 함선·표적을 구분한다. 개발 도구를 열지 않아도 현재 단계와 명령을 찾을 수 있다.
- [ ] **1~3분:** 아군 선택 → 짧은 이동 → 우클릭 드래그 고도 → 추적 → 전체 보기. 일시정지 중 카메라도 움직인다.
- [ ] **3~4분:** 적 표적 지정 → 발사 요청. 포탑 회전·포구·빔/발사체·명중을 함께 본다. 1/2/3배속을 바꿔 조작과 전투 시간을 구분한다.
- [ ] **4~6분:** 영웅 카드 선택 → 위치 찾기 → 선내 지도. 인원·층·시설을 골라 수호 또는 점령 명령을 주고 실제 이동과 선택 경로를 확인한다.
- [ ] **6~8분:** 실제 쉴드 제거 후 강습 투입 → 시설 목표 → 철수. 원 진입점까지 걸어가 원 운송수단으로 회수되는지, 구조 대기가 귀환으로 잘못 표시되지 않는지 확인한다.
- [ ] **8~9분:** 함선 상세에서 외부 회전·줌·무장 선택·층·격납고·핀을 확인한다. 최대 2핀과 닫기·다시 열기가 자연스럽다.
- [ ] **9~10분:** Insert에서 시험 함선 또는 영웅을 생성하고 결과를 찾는다. 고급 진단을 접으면 긴 코드·해시·설명 문단이 보이지 않는다.
- [ ] 창 위 클릭·우클릭·드래그가 뒤 전장 명령으로 새지 않는다. 회전 중 UI 경계를 넘거나 Alt를 먼저 놓거나 창 밖에서 버튼을 놓아도 회전이 남지 않는다.
- [ ] 다른 창으로 전환했다가 돌아와도 선택·카메라가 갑자기 움직이지 않는다. 작은 창에서 이름·핵심 버튼이 잘리지 않고 목록만 스크롤된다.

문제를 전달할 때는 **장면 이름, 선택 함선/영웅, 누른 버튼, 기대한 동작과 실제 동작**을 함께 적는다. 캠페인·경제·연구·최종 그래픽은 이번 화면 개편의 완료 범위에 포함하지 않는다.

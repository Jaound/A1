# 2B-R v1 / D118 교정 및 종합 검증

2026-11-16 KST. 기획 `035a4fba81d26f1d67daa1f44bded0f7e8d3a434`, 코드 `329518e`, 시작점 `1f02727`. 원격 work를 fetch한 직후 고정한 SHA 기준이며 변경분은 없었다. R1 쉴드·인원, 무장 목적 및 보호는 기존 경로를 사용한다.

## 실행과 직접 입력 확인

기존 UE 5.8.4에서 `Unreal/OrbitalVanguard/Tools/Build.ps1`, `RunEditor.ps1`을 실행한다. ControlRange Play에서 **F6** 또는 왼쪽 **D116 CANDIDATE**를 누르면 1대1 → 소수 편대 → 미사일 시험장을 순환한다. 각 전환은 시드 260112, 일시정지, 새 함정 상태로 시작한다. F5는 기존 2B 전투 배치와 공간 범위로 복귀한다. 기본 맵과 2A 검사는 기존 배치에서 시작한다.

1. F6으로 교정 진입 후 외부의 세 함정을 확인하려면 한 번 더 F6으로 WING을 연다. 휠 줌, F 추적, MMB 회전, WASD 이동을 확인한다. 상세 창이 가리면 DETAILS로 닫는다.
2. VECTOR를 선택하고 원거리 그리드에서 우클릭 드래그→해제 또는 V→Shift 드래그→Enter로 높이가 있는 이동을 주문한다. 휠은 PlayGame3 프로필에서 줌이다.
3. T 후 적 함선을 클릭하고 B를 누른 뒤 F1로 재개한다. 사격/명중과 실드 게이지를 확인한다. GUNS와 DEV INSIDE, FORCE GUN 사용법은 [R1 명령 안내](PHASE2BR_COMMANDS.md)를 따른다.
4. F5 후 기존 규모로 돌아오고 같은 마우스 제스처로 조작되는지 확인한다.

최종 에디터는 WING 일시정지 상태로 남겼다. 직접 OS 입력은 미검증이다. computer-use 스킬에서 창 캡처가 `window capture timed out: timed out waiting on channel`로 실패했고 창 재선택·활성화 후 1회 재시도도 같은 결과였다. 클릭과 키는 주입하지 않았다. [엔진 렌더 캡처](validation/Phase2BR-D116-Viewport.png)는 별도 증거다.

## 공간 범위

임시 큐브 외형과 선택 충돌은 레이아웃의 축별 반길이에 맞추고, 같은 액터 변환으로 장갑·시설·장착점과 탄도 OBB를 배치한다. 시설 구성·HP·연결은 기존 템플릿이며 엔진·레이더·쉴드 제어는 각각 한 실을 사용한다. 초계/백터/바스티온/미사일함의 형상 배율은 6/10/13/18이다. 근접 분리는 레이아웃을 감싸는 보수적 구를 사용한다. F5에서는 이전 캐릭터 메시·액세서리·스탯을 복원한다.

교정 시작 간격은 주 교전선 약 660m다. 평면 ±1800m, 고도 -450~600m, 그리드 간격 150m, 초기 카메라 1350m·최대 4200m, 투영/선택 광선 최대 15000m다. 선택 함정 크기에 따라 최소 줌을 제한하고 기존 카메라 투영 및 회전 게인을 사용한다. 지도 경계 기둥과 기본 렌더 클리핑 설정은 기존 맵 자산을 쓴다. 기존 F5는 ±60m/고도 -15~40m/그리드 5m로 돌아온다.

재실행은 [기존 가이드](PHASE2B_GUIDE.md)의 빌드·Automation·PIE 명령을 사용하고 2B Python 파일 대신 `Tools/ValidateD116Calibration.py`를 지정한다. 원본 로그는 `Saved/Logs/RevisionCalibration{FinalBuild,AutomationFinal,2APIE,PIEVerified}.log`. 한국어 엔진 자체 검사 Condition failed 15건은 자동 36건과 별도다. 기존 비권장 컴파일러/Visual Studio SDK 경고는 환경 기록에 보존했다.

## 남은 확인과 후속 제약

- 직접 입력 체크리스트로 키와 실제 클릭 판정, 창 경계, 축 확대 후 조작감을 확인한다.
- 현재 형상·배치·임시 시설 구성은 후보 실행 기반이다. 향후 형상/함급 확정 시 몸체·장착점·시야와 접촉을 다시 맞춘다.
- 혼합 티어 유폭과 초대형 전용 주포의 실제 배치는 규칙/데이터 지원 뒤 이어간다. 16종 모두의 실동작 비교, 최종 전투 시간 및 장기 밸런스는 별도 검증이다.

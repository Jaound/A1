# 기지 건설 3단계 검증

시작 코드 `85ff567`, 기획 `91a15dbdf5a4d75b4cf3e7be71bd6dafd1c92f8b`. 기존 2단계 자동 167/167 및 PIE 53/53은 [2단계 검증](../BaseTrial2/README.md)에 보존한다. 공유 전장 개정의 PIE 83개는 [별도 기록](../BaseSharedField/README.md)에 있다.

- 독립 MSVC C++ 실행으로 기존 기지 건설 테스트의 규칙과 신규 19종 카탈로그, 코어 I→IV, 개별 창고 II·III, 고급 자원 500 부족, 75% 철거, 순환 우회, 재연결, 공사 복원 검사를 통과했다.
- 격리된 D 경로에서 UE 5.8.4 Win64 Development Editor 빌드 성공. MSVC 14.51.36260, SDK 10.0.26100.0. 최초 빌드의 이름 충돌과 변수 가림 오류를 수정하고 빌드를 다시 실행했다.
- 자동 검사·신규 PIE는 별도 실행 중이다. Windows 새 패키지 및 실제 마우스 조작은 아직 확인하지 않았다.
- 기존 6종 모델은 게임 자산과 실측 소켓을 재사용한다. 추가 13종은 25m 규격과 비용·연구 조건을 등록했고 원본 외형과 포트를 별도로 검증하고 있다.
- 원래 A1 개발 저장소 11,003개는 C와 D 전체 SHA-256이 일치한 뒤 3단계 변경을 적용했다. 외부 원본 에셋 일부는 복사 중 손상 사실을 확인해 C 원본에서 복구하고 있다. 전체 C 정리는 복제본 검증 이후 진행한다.

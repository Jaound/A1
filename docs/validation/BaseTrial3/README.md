# 기지 건설 3단계 검증

시작 코드 `85ff567`, 기획 `91a15dbdf5a4d75b4cf3e7be71bd6dafd1c92f8b`. 기존 2단계 자동 167/167 및 PIE 53/53은 [2단계 검증](../BaseTrial2/README.md)에 보존한다. 공유 전장 개정의 PIE 83개는 [별도 기록](../BaseSharedField/README.md)에 있다.

- 독립 MSVC C++ 실행으로 기존 기지 건설 테스트의 규칙과 신규 19종 카탈로그, 코어 I→IV, 개별 창고 II·III, 고급 자원 500 부족, 75% 철거, 순환 우회, 재연결, 공사 복원 검사를 통과했다.
- 이전 C 경로를 제외한 D 프로젝트에서 UE 5.8.4 Win64 Development Editor 및 Win64 Development Game 빌드 성공. MSVC 14.51.36260, SDK 10.0.26100.0. 최초 빌드의 이름 충돌과 변수 가림 오류를 수정하고 빌드를 다시 실행했다.
- 전체 자동 검사 168/168 통과. 기존 167개와 신규 성장·연결망 1개가 포함된다. 첫 콜드 캐시 실행은 시간 제한에 걸려 중단했고, 웜 캐시 재실행에서 모두 통과했다. 한국어 엔진 자체 시작 검사 `Condition failed` 로그는 프로젝트 결과와 별도로 유지한다.
- 첫 신규 PIE에서 단절된 가지로의 재접합이 소켓 오차 검사에 막혔다. 코어에 연결된 쪽의 소켓으로 재접합하도록 수정하고, D 프로젝트에서 신규 PIE 41/41을 통과했다. [개별 검사](PIE.json)
- 기존 시험장 회귀를 같은 빌드에서 다시 실행해 83/83 통과했다. 수평·수직 접합, 90도 회전, 법선·롤, 초계함 상자 추적과 두 베이의 바닥 검출을 확인했다. 조선소와 표준 도크의 수평 소켓 중심 오차는 부동소수점 정밀도 내에서 0cm였다. [회귀 측정](Regression.json)
- 새 Windows 패키지와 실제 마우스 조작은 검증 대기 중이다.
- 기존 6종 모델과 실측 소켓을 재사용한다. 추가 13종 원본 외형은 25m 논리 점유 안에 균일 배율로 맞춰 UE에 반입했다. 반입 오류 0건, 스무딩·탄젠트 등을 포함한 경고 17건. 13종의 포트는 시험 배치용이며 물리 접합·베이 충돌 검증은 남아 있다. [외형별 SHA-256과 검증 상태](Models.json)
- 원래 A1 개발 저장소 11,003개는 C와 D 전체 SHA-256이 일치한 뒤 3단계 변경을 적용했다. 외부 원본 에셋 1,829개는 불일치 파일을 C 원본에서 복구한 뒤 모두 SHA-256 일치를 확인했다. 이전 A1·기준본 경로 없이 D 빌드 및 기존 패키지 실행을 확인했다.

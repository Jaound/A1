# 기지 모델과 출입로 검증

기획 `40bba6e`, 시작 코드 `08fbd9d`, 허브 크기·입력 교정 `3f6a15a`, 검증 구현 `89ee0e0`. 최초 4종의 [1단계 검증 기록](../BaseTrial/README.md)은 이전 빌드 증거로 보존한다.

## P1/P2 대조

사용자가 후속 답변에서 연결 위치 결정을 위임했다. 기획 브랜치와 원본 폴더에서 P1·P2가 적힌 이미지 파일은 발견하지 못했다. [포트 대응표](Sockets.md)의 번호는 이번에 부여한 이름이다. 소켓은 실제 UE 정적 메시의 축 이름을 유지한다. 모델이 회전하면 논리 칸, 출입 방향과 소켓도 함께 회전한다.

## 신규 모델 적용

- 소형 조선소 `SM_OV_Base_YardSmall`. 측면 후방의 두 돌출부에 통로를 연결하고 짧은 끝의 개방면을 선박용으로 확보했다. 비용 일반 650, 120게임초, 점유 4×3×3이다.
- 표준 접안 `SM_OV_Base_DockStandard`. 두 원본 후보의 탑뷰·측면·끝면을 비교했다. ‘소형 접안 모듈’은 긴 측면의 관통 베이가 명확하다. 양 끝의 돌출 팔각부에 통로를 붙이고 측면으로 함선을 들인다. 비용 일반 350, 75게임초, 점유 4×3×2다. ‘표준(소형) 접안 모듈’은 대체 후보로 보존했다.
- 네 원본 맵(색, 노멀, 금속, 거칠기)을 사용한다. 일자 통로의 외곽 끝면은 약 4.36×5.35m였다. 허브 수평 끝면의 약 11.45×19.60m를 약 4.35×5.29m로 줄였다. 25m 논리 점유는 한 칸이다. 수직면과 수평면은 원본의 다른 단면이다.
- 기능 모듈 원본의 큰 테두리와 통로 크기는 달랐다. 조선소·도크에는 원본 FBX를 보존하고 게임용 메시에만 속 빈 팔각형 연결부를 덧붙였다. 소켓은 좁아진 끝면 중앙에 있다. 원본 뒤쪽의 격벽은 보존했다. 통로를 따라 시설 내부로 사람이 이동하는 단계는 별도다.
- 원본이 있는 다음 후보는 물류 터미널, 보호·방어·레이더, 연구소·영웅 아카데미·인원 지원소, 중형·대형·초대형 조선소와 접안 모듈이다. 이들의 확정 포트 번호·UE 반입·출입로 검증은 남아 있다.

## 출입로 검증

25m 격자에서 본체와 입구 여유를 따로 검사한다. 전방 두 칸은 개구 앞 전체 폭·높이, 그 이후는 중앙선 한 칸 폭을 보존한다. 이미 건설 중인 시설도 같은 검사를 적용한다. 초계함 시험은 실제 `SM_PC14_FullMesh`의 실행 중 배율로 외곽을 구하고 그 상자를 함선 축에 맞춰 베이 안으로 스윕한다. 바닥 쪽으로 다시 스윕해 실제 충돌이 활성인지 대조한다. 둘 다 선체 외곽 표면을 충돌 형상으로 사용한다. 조선 주문·정박 동작·출격은 후속이다.

## 패키징과 직접 입력

Windows Development DX11(`HeroArtDX11`) 빌드·쿠킹·스테이징·아카이브 성공, 종료 코드 0. 패키지 포함 목록에서 6종 메시 모두를 확인하고, 생성한 패키지에서 직접 실행했다. 최초의 전체 그래픽 프로필 쿠킹은 연결부 수정으로 중단했다. Vulkan·DX12 패키지와 다른 PC는 미검증이다. [빌드·자동 검사·패키징 요약](RunResults.json)

실제 패키지 창은 1280×740, UI 100%였다. 타이틀 → 작전 개시 → 기지 건설 시험장 → 출격 후, 일자 통로와 표준 접안 모듈을 클릭해 일반 자원 810과 연결 대기 75초를 확인했다. R과 F로 0→25→0m, 숫자 2와 3으로 배속 변경, Space로 공사를 재개했다. 반대편에 분기 허브를 설치하자 770이 남았다. 도크 건설 중에는 조선소 예약이 건설 슬롯 안내와 함께 차단됐다. 함대 화면에서 초계함과 3배속을 확인하고 기지로 복귀했다. 도크 완공 후 같은 자리에 조선소를 예약하자 120이 남고 공사가 시작됐다. 숫자 1과 Space로 1배속·일시정지 상태를 확인한 뒤 목록으로 복귀했다.

패키지 재실행은 `OrbitalVanguard.exe /Game/Maps/ControlRange -dx11 -CustomConfig=HeroArtDX11`이다. 직접 입력에서 확인한 모델은 코어·일자 통로·분기 허브·표준 접안·소형 조선소다. 창고 배치와 환불은 이번 PIE 및 자동 회귀에서 검사했다.

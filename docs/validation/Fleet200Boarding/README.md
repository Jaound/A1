## 운송 내구도와 실패 원인

| 포드 내구도 | 방공함 호위 조건 진입 | 실제 요격 격추 |
|---|---:|---:|
| 80 | 19/24기 | 5기 |
| 120 | 21/24기 | 3기 |
| 160 (기본) | 23/24기 | 1기 |
| 200 | 23/24기 | 1기 |

- 235m에서 각 시드마다 8기를 발사했다. HP 160과 200의 진입 수가 같았다. 각 시드와 승객별 잔여 HP는 원시 결과에 있다. 175m에서 활성 쉴드를 향해 발사한 별도 시험에서는 요격 격추가 0기였는데도 포드가 8기 모두 소실됐다. 영웅 4명은 구조 대기, 일반병 4명은 사망했다.
- HP 120에서 영웅을 앞에 두면 세 시드 합계 영웅 3명이 구조 대기였다. 같은 조건에서 일반병을 앞에 두면 일반병 3명이 사망했다. 두 순서 모두 24명 중 21명이 진입했다. 이번 배치에서는 출발 순서가 손실을 부담하는 인원을 바꿨다.
- 강습선의 초기 선체는 10,560, 쉴드는 6,336이다. 표적의 쉴드가 내려가고 적 대함 사격이 없는 175m 시험에서 5초에 출격해 11.87초에 8명 모두 이송했다. 적이 집중사격한 두 시드에서는 110초까지 한 명도 진입하지 못했다. 상세 재현에서 출격 5초 뒤 엔진 효율 100%, 함교 효율 0%, 선체 4,541, 거리 160.5m였다. 함교 명령 불능 시 매 전투 단계에 정지시키는 기존 규칙과 일치한다. 수송 상태에는 계속 ‘접근 중’이 남았다.
- 적 쉴드를 켜 두고 대함 사격을 끈 조건에서는 110초 시점에도 선체 10,560, 탑승 8명, 진입 0명이었다. 강습선 쉴드의 관측 최저치는 2,290이었다. 실제 함대전에서 집결 직후인 5초에 조기 출격한 추가 사례에서도 195초까지 진입 0명, 선체 8,139, 탑승 8명이었다. 기체 생존율만 보면 이런 작전 실패가 가려진다.

## 밸런스 판단

현 단계에서는 포드와 강습선의 기본 내구도를 유지한다. 방공 호위의 억제력을 더 높이려는 경우 포드 HP 120을 다음 비교 후보로 삼을 수 있다. 세 시드의 단일 접근 경로만으로 정식 수치를 바꾸기에는 표본이 작다. 강습선은 ‘함교 무력화로 접근 중단’과 ‘쉴드 때문에 접안 대기’를 플레이어가 구별할 수 있게 하는 것이 우선이다. 강습 UI에는 개인 포드의 출발 순서와 쉴드 접촉 위험이 드러나면 좋겠다.

## 측정 방법

- 기준 코드 `87d014b`. UE 5.8.4 Win64 Development Editor의 실제 Fleet200 임무를 별도 PIE 월드에서 실행했다. 컨트롤러의 게임 시간을 1배속에서 0.1초씩 진행했다. 렌더링과 소리는 끄고 편성, 선내 집결, 출격 확인, 포탑·요격, 접안, 승객 진입, 선내 자동 교전, 함교 소유권과 임무 결과를 게임에서 읽었다. 마우스 조작과 렌더 성능 측정은 이번 검사에 포함하지 않았다.
- 기본 편성 시험은 양측 200코스트 원래 함대를 사용했다. 강습선 비교군은 아군 초계함 한 척을 동가의 강습선 한 척으로 교체해 아군 구축전함에 수납했다. 이 비교군에만 영웅 자동배치를 원래 편성과 같게 유지해 강습선은 빈 상태에서 출발한다. 양군 구축전함의 초기 영웅은 각 6명이다.
- 아군 모함에 같은 일반병 8명을 시험 편성했다. 일반병 8명과 돌격·사수·지원·지휘 영웅 각 1명 및 일반병 4명을 비교했다. 미투입 대조군에서도 영웅과 일반병은 함대에 남아 있다. 모든 이동 교전 표본에서 아군 구축전함에 같은 접근 명령을 주고, 표적 구축전함의 쉴드가 실제 교전으로 꺼지고 중심 거리가 245m 이내일 때 출발을 확인했다. 조기 출격 표본만 집결 직후 출발했다.
- 진입은 해당 개인 ID가 실제 표적에서 발생시킨 운송 진입 이벤트로 집계했다. 도착한 인원에게 개별적으로 함교 점령을 명령했다. 나포는 원래 적이던 구축전함의 소속이 실제로 바뀐 첫 시각이다. 출발과 나포는 1초마다 관찰했으며 첫 진입은 게임 이벤트 시각이다. 선내에서 사망한 인원과 비행 중 격추를 구별했다.
- 통제 시험은 같은 함대에서 함선 이동·사격 자동화를 끄고 시작 중심 거리 175m로 배치했다. 쉴드 해제 조건은 적 쉴드 제어실의 운영 인원을 시험용으로 0으로 설정했다. 요격과 영웅 방어는 그대로 작동했다. 집중사격 조건에서만 적 구축전함에 강습선을 지정해 실제 사격 요청을 반복했다.
- 요격 민감도 시험은 시작 거리 235m, 기존 적 방공함 한 척을 포드 경로에서 옆으로 55m 떨어진 곳에 배치하고 요격 우선순위를 포드로 설정했다. 같은 세 시드로 HP만 80·120·160·200으로 바꿔 비교한 뒤 복구했다. 포드의 기본 비행 속도 165m/s, 회피 40%, 개별 발사 간격 0.25초를 사용했다. 승객 순서 대조 외에는 혼성팀의 영웅을 먼저 발사했다.
- 전투·요격·선내 전투 난수에 지정 시드를 적용했다. 실제 함대전과 표적 정지 시험의 결과는 따로 집계한다. 동일 시드 반복 재현은 독립 표본으로 더하지 않는다. 영웅 성장 단계별 곡선, 강습 후 철수, 일반 플레이어의 클릭 지연은 측정하지 않았다.

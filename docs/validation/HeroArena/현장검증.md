## 이전 직접 플레이 확인 · e9f9934
별도 DX11 게임 창 1280×800에서 화면 제어로 확인했다. 아군 0명 상태에서 이리스 1명 배치 → 빈자리 채우기(10명) → 상단 영웅 → 이리스의 원본 전신·초상 확인 → 선내 지도 → 이리스 SD → 강습 시작 → 실제 포드 출발 → 다음 알려진 함선 → 아군 전체(10명) → 철수 → 원 진입점으로 철수 중 → 모함 10명 복귀를 확인했다. 당시 함선 카드가 10/4를 표시했고, 전원 회수 후에도 임무가 진행 중이었다. 정원 표시는 활성 시나리오 값을 사용하도록 고쳤고 철수 결과를 추가했다. 철수 결과는 별도 PIE 검사에도 포함했다.

## 자동·PIE
- Windows Development Editor, VS 14.51 도구와 Windows SDK 10.0.26100.0. 전체 C++ 결과는 자동검사.json에 기록한다. 일부 기존 시험은 월드 해제 관련 경고와 함께 성공한다.
- HeroArena.json에는 34종을 네 번에 나눠 생성하고 포드로 실제 진입시킨 결과가 있다. 한 판에서 실제 함교 목표를 주고 선내 명중을 관찰했다. 이리스 개인의 시그니처 발동·경감은 별도의 고정 조건 C++ 검사다.
- HeroCards.json 56항목, HeroRoster.json 70항목, HeroBoarding.json 33항목. 과거 강습 검사의 출발 함선은 강습 발사 시설이 없는 현행 백터급이었다. 출발 시험 함선을 실제 강습선으로 바꾸고 기존 33개 검사 ID와 발사·복귀·소속 판정을 유지했다.
- 정지에서는 시계가 정지한다. 1·2·3배속에서 같은 편성에 같은 시점에 함교 명령을 줬을 때 30게임초의 아군 명중 수와 생존자·총 HP를 비교한다. 상세 수치와 DX11 렌더 콜백 간격 평균·p95·최대는 HeroArena.json 참조. 짧은 표본으로 장기 성능이나 승률을 확정할 수 없다.
- Windows 독립 실행 검사용 프로필 HeroArtDX11을 분리했다. 첫 독립 실행은 함체가 동적 경로로 로드되고 쿠킹 목록에 누락되어 구축전함 크기 산정에 실패했다. 함체·배치·표시 자산을 쿠킹 대상으로 추가했다. 패키지를 갱신할 때 다른 PC의 방화벽 설정은 변경하지 않는다.

## 재현
에디터에서 Tools/ValidateHeroArena.py를 실행하거나 다음 PowerShell 명령을 사용한다. 자동 검사는 프로젝트 전체 필터를 사용해 상태를 확인한다.

```powershell
$project = 'C:/Users/user/source/repos/A1/Unreal/OrbitalVanguard'
$editor = 'E:/UE_5.8/Engine/Binaries/Win64/UnrealEditor-Cmd.exe'
& 'E:/UE_5.8/Engine/Build/BatchFiles/Build.bat' OrbitalVanguardEditor Win64 Development "-Project=$project/OrbitalVanguard.uproject" -WaitMutex
& $editor "$project/OrbitalVanguard.uproject" /Game/Maps/ControlRange -unattended -nullrhi '-ExecCmds=Automation RunTests OrbitalVanguard' '-TestExit=Automation Test Queue Empty' "-ReportExportPath=$project/Saved/Validation/HeroAcceptance"
& $editor "$project/OrbitalVanguard.uproject" /Game/Maps/ControlRange -d3d11 -unattended "-ExecCmds=py $project/Tools/ValidateHeroArena.py"
```

최종 원본 로그는 프로젝트 `Saved/Logs/HeroArenaBuild.log`, `HeroRelease_OrbitalVanguard.log`, `HeroReleaseValidated.log`, `ValidateHeroArena.log`, `FinalHeroCards.log`, `FinalHeroRoster.log`, `FinalHeroBoarding.log`, `HeroFinalPackaging.log`, `HeroFinalBoot.log`에 있다. 전체 자동 검사 보고서는 `Saved/Validation/HeroReleaseValidated/index.json`이다.

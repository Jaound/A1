# 시스템 실습과 함대전 출격 준비

현재 빌드의 실행 방법과 실습별 판정은 [실습·함대전 플레이테스트 수정 기록](../PracticeRevision/README.md)에서 확인할 수 있다. 아래는 당시 빌드를 재현하기 위한 기록이다.

## 실행

Windows 배포 폴더의 `Windows/OrbitalVanguard.exe`를 실행한다. SSD의 배포 위치는 `I:/2026_2/GDD/OrbitalVanguardTests/PracticeAndSortieRelease`다. 게임과 에셋이 들어 있는 Windows 폴더 전체가 필요하다.

- **시스템 실습** — 타이틀에서 장을 고르고 **실습 시작**을 누른다. 오른쪽 카드의 목표를 달성하면 **다음**이 열린다. 힌트를 접어도 전장 입력을 쓸 수 있다. 장별 완료 표시와 힌트 설정은 다음 실행에도 남는다. 전장 상단의 **가이드**는 현재 작전을 유지한 채 열 수 있다.
- **출격 준비** — **작전 개시 · 임무 선택 → 50·100·200·300코스트 함대전 → 작전 출격**을 선택한다. 환경, 함대, 함선 설계, 위치, 영웅 선택, 영웅 배치, 최종 브리핑 순서다. 오른쪽 아래 **전투 시작**에서 시간이 흐르기 시작한다. 추천 편성을 수정하거나 예산을 남겨도 된다.
- 배치도 왼쪽을 클릭해 선택함의 위치를 정한다. 고도는 25m, 방향은 45도씩 바꾼다. 블랙홀의 황색 경계는 중력권, 적색 경계는 즉시 완파 중심이다. 소행성을 부수면 함선과 탄을 가로막던 엄폐도 사라진다. **같은 편성 재시작**은 출격 때의 배치를 복원한다. **편성 수정**은 편집 창을 다시 연다.

## 실습별 확인

| 장 | 게임에서 확인하는 결과 |
|---|---|
| 1 기본 조작 | WASD 팬, 휠 클릭 드래그 회전, 휠 줌, 단일·Shift 다중 선택, 이동·고도 명령 수락 후 실제 표식 도착, 일시정지와 배속 |
| 2 인터페이스 | 항모 선택, 쉴드·선체 상세, 실제 시설 선택, 영웅 명단, 격납고, 해당 함선의 알림 |
| 3 명령 | 이동·정지·표적 지정, 수동 발사와 자동 사격, 선택함 공격 취소 |
| 4 기초 전투 | 실탐지, 포탑 발사 준비, 쉴드 명중·선체 손상, 방공함의 기체 요격. 무장 비교에서 사각과 탄착 특성 확인 |
| 5 함종과 역할 | 여섯 역할 카드, 방공함의 주력함 호위 위치 도착 |
| 6 내부 시설과 무장 | 코어·함교·엔진·무기 제어 선택, 실제 호환 장착과 부적합 티어 거부 |
| 7 함재기 | 출격, 귀환, 같은 ID의 원래 편대 전원 재격납과 수량 보존 |
| 8 영웅 | 실제 탑승자의 보직, 수호 전환과 기존 효과 해제, 같은 영웅의 보직 복귀 |
| 9 강습 | 시험함 대원의 탑승·진입, 적 시설 작전, 원래 수송수단 철수. PIE에서는 영웅 4명과 병사 8명이 개인 포드를 사용 |

일반 단계 재시도는 그 시점의 게임 상태에서 목표를 다시 측정한다. 강습 재시도와 시험함을 잃은 경우에는 장 편성을 초기화한다. 장 선택에서 다시 시작하면 처음부터 진행할 수 있다. 4장의 개별 무장별 탄착과 9장의 강습선 경로는 이번에 독립적인 직접 조작으로 전부 재연하지 않았다.

## 편성 규칙과 시험값

| 예산 | 소형·중형·대형·초대형 코스트 | 가능한 초대형 최대 | 시험 영웅 한도 |
|---|---|---:|---:|
| 50 | 1·5·25·125 | 0 | 3 |
| 100 | 1·5·25·125 | 0 | 5 |
| 200 | 1·5·25·125 | 1 | 10 |
| 300 | 1·5·25·125 | 2 | 15 |

영웅 수는 예산을 20으로 나누어 올림하고 최대 15명으로 제한하는 시나리오 시험값이다. 탑승 정원은 소·중·대·초대형 순으로 1·2·4·6명, 강습선은 4명이다. 시작 시설, 지원 보직, 강습 배정은 각각 지정한다. 내부 시설 위치는 호환 슬롯 사이에서 교환하고 외장 무장은 실제 공급·제어 시설과 티어에 맞춰 교체한다. 함선을 빼면 그 함선이 맡았던 영웅만 재배치한다. 적 함종·척수·공개 역할은 브리핑에서 확인할 수 있다.

소행성 내구도는 시험값으로 반경(cm)의 0.2배다. 배치도는 높이와 방향이 반영되는 사선 투영도다. 이동 경로와 피격은 실제 전장에서 판정한다. 일반 함대전과 기지 시험장의 재고는 독립적이다.

# 시스템 실습과 출격 준비

## 실습 체크포인트

기획 `d07deb5`, 시작 코드 `4ff7f56`. 타이틀에서 **시스템 실습 → 장 선택 → 실습 시작**을 누른다. 전장의 가이드 버튼은 기존 도움말을 연다. 힌트와 완료한 장은 사용자 설정에 저장한다. 시험 함선·영웅·기체는 장을 나가면 정리한다.

UE 5.8.4 Win64 Development Editor 빌드 성공. [실습 PIE 원본](PracticeCheckpoint.json) 56/56. 아홉 장의 타이틀 진입·재시작·목록 복귀, 1장의 목표 위치·고도 도착, 7장의 원래 기체 재격납 및 재고 보존을 검사했다. 첫 검사에서 시험용 보충 자원이 대기 기체 수를 늘려, 해당 실습의 초기 보충 적재를 0으로 분리했다.

1120×720 독립 게임 창에서 마우스로 타이틀의 실습을 열고 1장에 진입했다. [장 선택](chapter-menu.jpg) · [전장 도움말](practice-help.jpg). 실제 카메라 키는 WASD, 휠 클릭 드래그, 휠 회전이다. 이전 단계로 되돌리는 전체 세계 스냅샷은 제공하지 않으며 재시도하면 해당 장의 초기 편성으로 돌아간다.

# 플레이 UI 증거 읽기

최신 결과는 [검증 문서](../../PLAY_UI_VALIDATION.md)와 [진행 기록](../../PLAY_UI_PROGRESS.md)을 따른다. 모든 API 수를 합산한 종합 완료율은 만들지 않는다.

- `Manifest.json`: 시작/기능/표시 코드, 기획 SHA, 바이너리·Source 해시, 자동 검사 ID와 파일 해시.
- `N-*`, `UI1920_N`, `UI720_N`: 최종 한국어 문구 교정 후 영웅·개발 검사와 실제 렌더. 기본 화면/영웅 카드/외부 무장/격납고/선내/개발 탭을 포함한다.
- `M-PlayWindows.json`: 기존34 + 여러 위치의 동작 버튼21 + 실제 지도 인물 선택5 =60검사. 실제 OS 입력이 아니라 HitBox/명령 API 검사다.
- `O-Phase2AControls.json`, `L-Phase2BRCalibration.json`: 입력 변경 후 기존57/79검사. J/L의2A는 실제37성공/1실패이며 숨은 상세창을 드래그하던 검사 준비를 수정한 O가 최종 성공이다. 이전 실패 JSON도 보존한다.
- `PlayUI_M_Automation.log`: 최종 기능 구현85/85. 이후 N은 세 표시 문자열만 바꿨다. 엔진 자체 한국어 검사 오류15건은 별도다.
- `Interior`: 정상 공격·포드 진입 후 실제 영웅 이동/교전의16검사와 정지 렌더. API로 시간을 진행했다.
- `Video`: 가동 포탑128프레임·9.954초 MP4, 실제 시각별 기록, 대표2프레임. 원본 PNG 전체는 프로젝트 Saved에 있다. 성능·직접 조작감 판정 자료가 아니다.
- `Performance/PlayUIFinal*`: 최종 기본60초, 영웅18초, 프리뷰18초, 창 반복600초 실제 렌더 측정. 후반 전투 개체 감소를 함께 확인한다.
- `Performance/PlayUIFleet3x`: 앞선9척·320기·3배속 측정. 기능·편성 수치가 같은 상황이며 후속 변경은 입력/표시다.
- 이전 C/D/G/I/J 및 `PlayUICycle600`: 중간 통과/실패·중복 버튼 발견 이력을 보존했다. 최신 자료로 오인하지 않는다. 파일의 기존 기획 필드035a4f는 당시 검사/교정 규칙 출처이며 이번 UI 기획은 Manifest의ce06643이다.
- 모델 조사 JSON/`ImportedCorvette.json`: 원본 해시·실제 연결 성분·수정본/임포트12검사. 원본 무장 관절·장착점 정합 완료 증거가 아니다.

큰 원본 ZIP·FBX·텍스처, 빌드 생성물, 원시 영상 프레임, Trace 및 전체 성능 CSV는 Git에서 제외했다. 원본과 실패 기록은 로컬 경로에 보존했다. 텍스트 SHA는 Git의 LF 저장 정규형을 기준으로 하며 PNG/MP4는 원본 바이트다.

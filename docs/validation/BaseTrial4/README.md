## 실행 순서

1. 임무 목록에서 **기지 건설 시험장**을 시작한다. 기지의 **운영 → 시험 · 운영 편성 준비**를 한 번 누른다. 빈 시험장에서 코어 주위에 소형 조선소·표준 도크·연구소를 설치하고 시험 자원을 채운다.
2. **연구**에서 기술을 고르고 **연구 예약**을 누른다. 정상 연구는 연결된 적정 등급 연구소와 선행 조건을 검사한 뒤 자원을 지불한다. **시험 즉시 해금**으로 전환하면 준비된 기술을 비용·시간 없이 시험할 수 있다. 일반 소형 함체는 시작부터 건조할 수 있다.
3. **운영 → 다음 시설 보기** 또는 전장 모듈 선택으로 소형 조선소를 연다. **다음 함체**로 초계함을 선택해 **건조 주문**한다. 준공 후 **출격**을 누르고 함대 화면에서 조종한다.
4. 함대에서 해당 함선을 선택한 상태로 도크의 **선택함 복귀·접안**을 누른다. 입구가 막히면 앞의 함선을 이동한다. 정박 후 **시험 · 손상 부여**는 선체에 실제 손상을 준다. 견적을 보고 **견적 수리**, 이어서 **무장 교체**, **출격**을 누른다.
5. 기지의 **저장**에서 진행 중인 건조·수리·연구와 자원을 저장·복원한다. 시험 저장은 탑승 병력이나 함재기가 있는 운영 함선을 감지하면 사유를 표시한다. 일반 접안·출항은 기존 함선 개체를 그대로 사용한다.

- 무장 교체는 일반 장착점에 있는 무장과 같은 티어·계열의 호환 장비를 제안한다. 일반 40, 15게임초는 시험 수치다. 탈거 장비는 기지 재고에 남고 같은 장비를 나중에 장착하면 보관분부터 꺼낸다. 교체 후 무장의 현재 HP는 기존 장착 규칙을 따르므로 더 큰 최대 HP의 장비를 달면 별도 수리 여지가 생긴다. 시설 재배치는 슬롯 허용 조건을 만족하는 두 시설을 교환한다. 코어·엔진·함교는 고정하고, 시설 HP·재건 상태·운영 인원과 새 배치를 저장한다. 두 개조 모두 대응 체급의 조선소 작업칸을 작업 완료까지 차지한다.

# 기지 운영 시험장

기획 기준 `d07deb53a6288e4da092ca3c90742affad29e4af`, 개발 시작 `a384d9432b6d8e9797c9480a93d91fecaa1f353e`. 기존 공유 전장과 모듈 모델을 사용한다.

## 실행 순서

1. 임무 목록에서 **기지 건설 시험장**을 시작한다. 기지의 **운영 → 시험 · 운영 편성 준비**를 한 번 누른다. 빈 시험장에서 코어 주위에 소형 조선소·표준 도크·연구소를 설치하고 시험 자원을 채운다.
2. **연구**에서 기술을 고르고 **연구 예약**을 누른다. 정상 연구는 연결된 적정 등급 연구소와 선행 조건을 검사한 뒤 자원을 지불한다. **시험 즉시 해금**으로 전환하면 준비된 기술을 비용·시간 없이 시험할 수 있다. 일반 소형 함체는 시작부터 건조할 수 있다.
3. **운영 → 다음 시설 보기** 또는 전장 모듈 선택으로 소형 조선소를 연다. **다음 함체**로 초계함을 선택해 **건조 주문**한다. 준공 후 **출격**을 누르고 함대 화면에서 조종한다.
4. 함대에서 해당 함선을 선택한 상태로 도크의 **선택함 복귀·접안**을 누른다. 입구가 막히면 앞의 함선을 이동한다. 정박 후 **시험 · 손상 부여**는 선체에 실제 손상을 준다. 견적을 보고 **견적 수리**, 이어서 **무장 교체**, **출격**을 누른다.
5. 기지의 **저장**에서 진행 중인 건조·수리·연구와 자원을 저장·복원한다. 시험 저장은 탑승 병력이나 함재기가 있는 운영 함선을 감지하면 사유를 표시한다. 일반 접안·출항은 기존 함선 개체를 그대로 사용한다.

## 운영 수치와 적용 경계

- 함체 가격은 기존 물류 함가 데이터를 참조한다. 체급별 건조 45/120/240/480게임초와 출입 5/8/12/20초는 시험 수치다. 같은 주문이 작업칸을 여러 개 차지해도 건조 시간은 동일하다.
- 작은 조선소부터 작업칸 1/2/4개를 사용하며 초대형 조선소는 초대형 1척 또는 대형 2척을 받는다. 철거·단절 시 진행 중인 작업과 베이 예약을 확인한다.
- 수리 항목은 선체·장갑·시설·무장이다. 인원 지원소의 충원은 별도 주문으로 운영 승무원 1인당 일반 자원 10을 쓰는 시험 단가다. 아카데미는 기존 세력 영웅 명단으로 연결한다. 영입·훈련 경제는 후속이다.
- 무장 교체는 일반 장착점에 있는 무장과 같은 티어·계열의 호환 장비를 제안한다. 일반 40, 15게임초는 시험 수치다. 기존 함체의 손상과 탈거 장비를 유지한다.
- 연구소 등급 증설 비용·시간과 저장고/미사일 일부 연구 단가는 시험 수치다. 방어전, 도크 피격 시 비상 출항, 성계 간 수송은 후속이다.

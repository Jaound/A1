### 함종별 검사 해석

`ValidateHullRoles.py`는 매번 같은 전함 표적, 초기 중심거리60,000cm, 동일 후보 프로필을 사용한다. 각 함체의 선택·실제 이동과 공격 함체 대표 장착점 하나의 정상 발사 요청·실제 발사·동일 표적 피격을 확인한다. 시설 정지·코어 완파는 DEV 정밀 피해로 재현한다. 따라서 대표 무장의 실제 피격과 DEV 완파를 한 발의 연속 전투 결과라고 해석하지 않는다.

방공은 이 비교에서 비활성이다. 방공함 실제 요격·레이더함 공유 보정·모든 무장/살보는 별도 기존 검사와 구분한다. 수리/채굴/수송은 유한 노드 채굴→화물 이전→재료 소비·시간 기반 선체 수리를 확인한다. 항모/항공순양함은 같은 기체 ID의 출격·귀환을 확인한다. 강습선은 공격 무장0·PD1 및 수송 등록을 확인한다. 전체 경제·전체 함종 밸런스 검증이 아니다.

## 확인한 결함과 수정

1. 초대형2종 혼합 티어 등록 거부를 무장별 유폭 계수로 해결했다. 검증기를 우회하거나 무장 티어를 통일하지 않았다.
2. DEV 생성 함선의 역할별 등록과 안전 삭제를 연결했다. 생존 승객·원 포드·미귀환 기체가 남으면 삭제를 거부한다.
3. 명시 장면 전환 시 예전 수송/선내/자원·수리 배열이 되살아나던 경계를 정리했다. 영웅 영속 기록을 먼저 보존한다.
4. F6 원래 함선의 영웅 배치에 선내/수송 등록이 누락된 문제를 해당 함선만 추가하는 방식으로 수정했다.
5. 직접 배치 영웅의 명시 강습 편성 UI/API, 미발사 포드 취소, 실제 도착 적함의 검증된 선내 등록을 연결했다. 기본 배치를 자동 강습 편성으로 바꾸지 않았다.
6. 실제 UI 캡처의 과대 글꼴·낮은 버튼/입력 대비를 개선했다. 카탈로그별 상태와 과거 검사 SHA를 표시한다.

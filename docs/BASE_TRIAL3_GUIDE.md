# 기지 건설 시험장 · 3단계

조선소·도크·연구소를 운용하려면 [4단계 운영 시험](validation/BaseTrial4/README.md)을 참고한다.

기획 기준 `91a15dbdf5a4d75b4cf3e7be71bd6dafd1c92f8b`, 시작 코드 `85ff567`. 중앙 코어와 19종 카탈로그의 치수·비용·시간·한도를 [기지 통합 명세](https://github.com/Jaound/A1/blob/91a15dbdf5a4d75b4cf3e7be71bd6dafd1c92f8b/docs/01_design/strategy/BASE_MASTER_GDD.md)에 맞춘다. 건설 시험장은 코어 I와 아군 초계함 한 척으로 시작한다.

## 시험장 시작하기

현재 개발판을 에디터에서 플레이하고 **작전 개시 · 임무 선택 → 기지 건설 시험장 → 작전 출격**을 누른다. 시작은 일시정지이며 **Space**로 시간을 진행한다.

## 조작

- 처음에는 양쪽이 비어 있다. 아래의 **운영 · 건설 · 연구 · 저장**을 눌러 필요한 창을 함께 연다. 제목줄을 끌어 이동하고 오른쪽 아래 모서리를 끌어 크기를 바꾼다. **핀**으로 위치와 크기를 잠그고 **−**로 접거나 **×**로 닫는다. 아래 버튼을 다시 누르면 해당 창이 앞으로 나온다. 건설 목록은 이전·다음 버튼으로 19종을 확인한다. 중앙 코어는 운영의 **중앙 코어 보기**나 건설 첫 페이지에서 선택한다.
- 상단에는 시간 제어와 세 자원의 보유량/한도가 있다. **WASD**, 휠 버튼 드래그·휠, **R/F**, **Q/E**, **Space**, **1/2/3**과 **함대 화면**을 사용한다. 공사 구역의 함선은 함대 화면에서 옮긴다.
- 건설에서 **자동 연결**을 켜면 기존 포트와 새 시설 사이의 주황색 경로, 연결 수와 비용이 표시된다. 클릭해 경로를 고정하고 **연결과 건설 확정**을 누른다. 둘째 단계에서 사전 조건을 다시 검사한다.
- 연구 탭의 버튼은 시험용 기술 준비다. 선행 기술과 코어 등급이 모두 필요하다. 연구 큐는 후속 단계다. 운영에서 **비용 시험**을 켜고 저장 한도까지 시험 자원을 채워 비용·환불을 검증한다. 기본은 무료 건설이다.
- **시설 선택** 상태에서 창고나 통로를 클릭한다. 운영 창에서 가동 여부, 개별 증설, 공사 취소 또는 철거, 예상 환불과 단절 시설이 표시된다.
- **저장** 탭에는 저장과 불러오기가 있다. 재시작은 새 세션을 열고 저장 슬롯을 보존한다. 저장 파일은 프로젝트 저장 폴더의 `BaseTrial/BaseTrial.ovbase`다.

## 명세에 세부값이 없는 시험 정책

- 창고 증설 II·III는 독립 시험 기술 ID로 기록한다. 중·대·초대형 조선소의 함체 연구 게이트는 명세 연구 트리의 해당 함체 기술을 사용한다. 코어 증설과 창고 증설은 기능 공사 슬롯을 한 칸 사용한다.
- 저장고가 단절되면 저장 한도가 내려간다. 기존 재고는 그대로 기록하고, 철거로 발생한 새 환불 가운데 남은 저장 공간에 들어가는 부분만 수령한다. 초과 예상량을 철거 확인에 표시한다. 예약의 전액 취소 환불은 이미 보유했던 재고의 반환으로 취급한다. 무료 건설은 실제로 지불한 금액이 0이므로 환불도 0이다.
- 자동 연결의 시험 탐색 한도는 16칸이다. 25m 격자의 경로와 기성 소켓을 함께 검증한다. 여섯 기성 모델은 기존 실측 소켓과 어댑터를 유지한다. 추가 13종은 원본 외벽을 측정해 맞춘 팔각 어댑터를 사용한다. 모델·회전별 검사는 [소켓과 출입 공간 검증](validation/BasePorts/README.md)에서 확인할 수 있다. 원본 반입 도구는 저장소와 같은 상위 폴더의 `OrbitalVanguardAssets`를 기본 경로로 사용하며 `OV_BASE_ASSET_ROOT`로 바꿀 수 있다.
- 저장에는 건설 모델, ID, 회전, 티어, 잔여 시간, 선행 기술, 재고 및 비용 예약을 기록한다. 코어 연결·한도는 배치로 재계산한다. 함대·시간 재개 상태는 이 시험장 저장 범위 바깥이다.

조선 주문·접안·수리·출격·기지전·캠페인은 후속 단계다.

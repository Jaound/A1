- `OVShipSystemsComponent.*`, `OVSystemsTests.cpp`: 시설/장갑/무장 개체별 상태와 단일 피해 이벤트. 잘못된 레이아웃 거부, 쉴드 부분 용량 감소 재활성화, 3층 파괴의 층별 장갑 면 규칙 보완.
- `OVShip.*`: 가감속/도착/체급 선회, Hold/수동 자세, 기능 상실 이동 차단, 명시적 DEV Reset/FTL 경계 API. 기존 이동 테스트 3개 유지.
- `OVController.*`, `OVOrderInput.*`: 최신 입력, 공통 시간, 다중 선택 대표 교체 시 상세 인덱스 초기화, 완파 직후 속도/표적 제거.
- `OVHUD.*`: Canvas 수명과 독립적인 입력 영역 검사, 창 이동/리사이즈, 표시/클릭 영역 클리핑, 읽기 전용 도식. 게임 상태를 복제하거나 추가 함선을 생성하지 않음.
- `Config/DefaultGame.ini`의 Tuning은 실제 적용되는 임시 수치 프로필. `DefaultInput.ini`에 시간/명령/부대 액션.
- `Tools/CreateTestLayouts.py`: 기존 자산 보존 후 없을 때만 UE 직렬화 생성. `Tools/ValidatePhase2A.py`: 45개 실제 PIE API 검사. 이전 `ValidatePIE.py`와 1단계 증거는 역사 기록으로 보존.

## 남은 오류·미정 사항·다음 작업

1. 사용자가 [PHASE2A_GUIDE.md](PHASE2A_GUIDE.md)의 직접 조작 8단계 확인을 실행한다. 특히 창/프리뷰 위 입력 누출, Shift/RMB 고도, 부대키, 포커스 재진입을 실제 입력으로 확인한다. 실패하면 입력 순서·함선/장갑/시설 ID·F9 로그를 남긴다.
2. 한국어 엔진 시작 자체 검사 15조건 오류는 그대로 별도 유지. 프로젝트 15개 테스트 실패와 다르다. 도구/전역 언어/엔진을 임의 변경하지 않았다.
3. R11 비전투 쉴드 완충, R13 최종 키/핀 정책, R14 포탑 피해 전달은 미결정이다. 1/2층 시설 파괴의 중첩 연결 면 규칙도 임시값으로 명시했다.
4. 2B 시작 전 실제 사격/탐지/포탑 추적 요구를 최신 work와 비교한다. 기존 파일을 재작성하지 않고 이 2A 기반을 재사용한다. 2C/선내 작전/경제/저장은 이번 완료 범위가 아니다.

실행·시험 명령은 PHASE2A_GUIDE/VALIDATION에 있다. 다음 세션은 Git 상태와 이 문서의 소스 커밋을 먼저 비교하고, 이미 통과한 단계의 재구현 없이 직접 입력 잔여 확인 또는 승인된 다음 단계부터 이어간다.

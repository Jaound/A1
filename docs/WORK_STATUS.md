# 최신 작업 — 플레이 UI R2 진행 중

**선택 무장 확대 화면 1차:** 함선 상세의 외부 화면에 선택 장착점의 표시 부품을 별도 SceneCapture로 읽는 실시간 확대 화면을 추가했다. 함선·공격·피해를 복제하지 않으며 장착점 교체 시 표시를 전환하고 상세 닫기·최소화·함선 완파/이탈 시 자원을 해제한다. 원본 모델이 아닌 기존 임시 포탑 표시다. 현재 작은 외부 화면 안에 표시하며 별도 HP색·상태 아이콘·표적·실제 사격/피격 시각의 전 구간 검증과 확대 화면 성능 측정은 남았다. `PlayUI_R2_BK_Build.log` 성공, 1280 렌더/API 40/40 (`Saved/Validation/PlayUI/20261117_224300/report.json`), 1920 렌더/API 40/40 (`20261117_224440/report.json`), 창 API 136/136 (`Saved/Validation/PlayWindows.json`). 장착점 변경·표시 부품 분리·HP 불변·닫기 해제 검사 포함. [1280](validation/PlayUIR2/선택무장_실시간_1280.png) / [1920](validation/PlayUIR2/선택무장_실시간_1920.png). OS 직접 입력은 미검증이다.

**쉴드 재가동과 실제 전투 렌더:** 아군 쉴드가 자연 회복으로 재가동할 때 알림을 한 번 기록한다. 수동 전환이나 시설 용량 변화로 인한 재가동 알림은 아직 연결하지 않았다. 시설 파괴 집계는 실제 시설이 있는 슬롯만 대상으로 한다. `PlayUI_R2_BG_Build.log` 빌드 성공, `PlayUI_R2_BG_Automation.log` 자동 88/88(실제 회복·중복 방지 포함), `Saved/Validation/PlayUI/20261117_223446/report.json` 1280 렌더·API 35/35. [실제 전투 쉴드 고갈](validation/PlayUIR2/실제전투_쉴드고갈_1280.png)은 시험용으로 쉴드를 미리 낮춘 후 실제 적 공격으로 고갈시킨 장면이다. 직접 Windows 입력은 미검증이다. 이전 BF 캡처는 읽기 전용 Shield를 직접 설정하려 해 실패했으며 피해 API를 이용하는 시험 준비로 수정했다.

**대함 피해의 실제 상태 전이 알림:** 아군 대함 피격 전후 HP로 활성 쉴드 고갈·장갑 구획 파괴·시설 물리 파괴를 구별한다. 승무원 부족만으로 물리 파괴를 만들지 않는다. 엔진·무기제어·쉴드제어·함재기 관제·요격제어의 물리 파괴와 함선 완파는 3초간 절제된 붉은 외곽 표시를 유지하며 뒤이은 일반 피격이 경고를 지우지 않는다. 한 공격의 함선 완파는 하위 피해 대신 완파로 묶는다. 빌드 `PlayUI_R2_BE_Build.log`, 자동88/88 `PlayUI_R2_BE_Automation.log`: 실제 발사로 쉴드·장갑·시설 파괴와 승무원 부족 비오탐·핵심시설 경보 유지 확인. BD 시점 창 API136/136·2A57/57·2B-R79/79·2C77/77, 이후 변경은 경고 유지 표시시간이다. BB 검사 실패는 앞선 실제 공격이 이미 시설 파괴 알림을 발생시킨 이력을 무시한 테스트 기대값 문제였으며 BC/BE에서 기존 건수와 비교하도록 바로잡았다. 새 유형의 화면 렌더·실제 OS 입력·시간배속별 경보 및 대량 부하는 미검증이다.

전투 알림 전체는 미완료: 쉴드 재가동·선내/운송/함재기 피해·영웅·나포·적 관측·항공대 임계치·전체 기록/검색/경고 설정이 남는다. 원본 모델 실제 관절/기본 적용과 독립 핀·무장 라이브뷰도 계속 필요하다.

**전투 알림 1차:** 실제 `OVCombatSubsystem`의 확정된 대함 공격 결과를 단일 읽기 전용 알림 경로에 연결했다. 아군 실제 피격과 해당 공격으로 인한 함선 완파만 표시하며, 같은 아군 대상의 연속 피격은 게임시간 2초 이내에 횟수로 묶는다. 같은 공격 ID 중복을 막고 기록은64건, 중복 감시256건으로 제한하며 잘린 수를 센다. 전투 재시작 시 초기화한다. 최근3건/실시간 토스트, 기록 당시 피격 위치 이동, 아군 완파 시 짧은 붉은 테두리를 추가했다. 적 정보와 현재 위치를 새로 조회하지 않는다. **아군 함재기탄/선내/운송 피해, 쉴드·장갑·시설·영웅·적 관측·항공대 임계치·전체 로그/알림 설정은 미구현**이며 전투 알림 전체 완료가 아니다.

검증: `PlayUI_R2_AY_Build.log` 성공, 기존 AU 자동88/88(실제 발사·피격, 중복/집계/상한/리셋 포함), AX 창 API136/136 및 실제 공격으로 아군 피격 후 알림·저장 위치 이동을 포함한 1280 렌더31/31([화면](validation/PlayUIR2/실제전투_피격알림_1280.png)), AX 2A57/57·2B-R79/79, AY 창 API136/136. AX 후 변경은 생략 건수 표시 영역의 입력 소비 한 줄이다. 최초 AW 캡처는 Python에 없는 World.get_subsystem 호출로 실패해 AX에서 HUD 조회 API로 수정했다. 실제 OS 입력·장기 경고 폭주·다른 사건 유형은 미검증이다.

**시설 표시 정정:** 기존 표시 조회가 함선 완파만으로 격납고가 물리 파괴된 것처럼 표시하던 문제를 수정했다. 모함 완파는 `함선 완파`, 시설 HP 파괴는 `파괴`, 승무원/점령으로 가동 불능은 `정지`, 미확인은 별도로 표시한다. 기존 시뮬레이션 파괴 판정은 변경하지 않았다. 빌드 `PlayUI_R2_AT_Build.log`, 자동87/87 `PlayUI_R2_AT_Automation.log`; 모함 코어 파괴와 시설 물리 파괴의 구분 검사 포함. 새 UI 실렌더와 직접 입력은 미검증이다.

**개발창 접기/확대/초기화:** UMG 제목줄에 접기·펼치기, 확대·복원, 배치 초기화, 닫기를 추가했다. 접은 창 이동 후에도 원래 크기를 유지하고 화면 범위 안으로 보정한다. 빌드 `PlayUI_R2_AR_Build.log`, 자동87/87 `PlayUI_R2_AR_Automation.log`, 창 API136/136(합성 UMG 제스처·접기 이동·확대 복원·초기화 포함), 개발 API36/36, 1280 렌더27/27. [접기](validation/PlayUIR2/개발창_접기_1280.png)·[확대](validation/PlayUIR2/개발창_확대_1280.png). 새 메모장 실제 Windows 캡처1회가 `window capture timed out: timed out waiting on channel`로 실패하여 OS 직접 입력은 여전히 미검증이다. UMG 합성 이벤트는 실제 마우스의 대체 증거가 아니다. 독립 핀·무장뷰·알림·원본 가공/적용과 1920·성능·종합 회귀는 미완료다.

**개발창 UMG 이벤트:** 제목줄/모서리를 UMG의 실제 마우스 이벤트 처리와 캡처·해제·캡처 상실에 연결했다. 기존 HUD 포인터 경로도 유지한다. 빌드 `PlayUI_R2_AO_Build.log`, 창 API130/130(UMG 핸들러에 합성 이벤트를 직접 전달한 이동·크기와 불변 검사), 개발 API36/36. AJ는 Python Geometry 조회 오류, AK/AL/AM/AN은 보이지 않는 위젯의 캐시 Geometry가 0인 검사 준비 문제로 실패했으며 AO는 뷰포트 크기/DPI로 합성 Geometry를 만든 검사다. 실제 OS 마우스·슬레이트 이벤트 전달 성공을 뜻하지 않으며 사용자가 직접 확인해야 한다. 최소화/최대화·배치 초기화는 남았다. 기존 R2 원본·핀·무장뷰·알림과 전체 검증도 미완료다.

**개발창 프레임 일부:** Insert 개발창에 제목줄·우하단 조절 안내를 넣고 위치/크기를 뷰포트 범위로 제한했다. 제목줄 드래그·우하단 크기 조절을 HUD 포인터 경로에 연결했으며 입력칸과 탭은 별도 영역이다. 빌드 `PlayUI_R2_AH_Build.log` 성공, 창 API125/125(프레임 이동/조절/상태 불변), 간소 개발 API36/36. 1280 렌더23/23은 AG 빌드에서 안내를 확인했으며 AH는 제목줄 입력 범위를 34→28로 좁힌 변경이다([화면](validation/PlayUIR2/개발창_1280.png)). UMG가 실제 OS 마우스 이벤트를 소비하는 환경에서 드래그가 전달되는지는 아직 직접 검증하지 못했다. 개발창 최소화/최대화·배치 초기화·실제 포커스/창 밖 해제는 미완료 또는 미검증이다. 다음: 해당 실입력 경계, 독립 핀 상세·무장뷰·알림, 원본 정합/적용과 통합 회귀.

**선내 창 접기·확대:** 선내 제목줄에 접기/복원·확대/이전 크기 복원을 추가하고, 접힌 영역 바깥은 입력을 소비하지 않는다. 창 위치·크기는 뷰포트 안으로 보정한다. 빌드 `PlayUI_R2_AD_Build.log`, 창 API122/122(접기·복원·확대·크기 복원 포함), 2A API57/57, 1280 렌더23/23 성공([선내 화면](validation/PlayUIR2/선내창_1280.png)). 가장자리별 크기 조절, 배치 초기화, 실제 OS 마우스/포커스, 1920 후속 렌더는 미검증 또는 미구현이다. 개발창 프레임·완전한 독립 핀·무장뷰·알림·원본 적용은 계속 필요하다.

**선내 창 이동·크기:** 제목줄 드래그와 우하단 크기 조절을 추가하고 창 위치/크기를 화면 경계에 제한한다. 지도와 인물 표식은 변경된 창 좌표를 사용한다. 닫기·개발 모드 전환·포커스 상실 시 포인터 드래그를 취소한다. 빌드 `PlayUI_R2_AA_Build.log`, 자동87/87 `PlayUI_R2_AA_Automation.log`, 선내 표식 이동 후 실제 API hit/select를 포함한 창 API118/118 `PlayUI_R2_AB_ValidatePlayWindows.log`, 2A API57/57 통과. 닫기 중 드래그 취소도 API로 확인했다. 최소화/최대화·가장자리 조절·개발창 프레임·실제 OS 마우스/포커스·새 렌더는 미구현 또는 미검증이며 전체 창 요구 완료가 아니다.

**격납고 시설 상태:** 시설 보기에서 실제 모함 운용 판정과 같은 조회로 가동·정지·물리 파괴를 구분한다. 소형함 수납/출격은 현재 구현되지 않아 미지원으로 표시하며, 기존 데이터에 수납 개체가 있으면 이름과 선체 비율을 읽고 출격 미지원으로 표시한다. 소형함의 실제 수납/출격 구현 완료가 아니다. 빌드 `PlayUI_R2_X_Build.log`, 자동87/87 `PlayUI_R2_X_Automation.log`(정지/파괴 구분 추가), 2C API77/77, 창 API112/112(시설 보기 전환/불변 추가) 통과. 시설 보기의 새 화면 캡처·직접 마우스·소형함 실제 운송은 미검증. 다음: 창 프레임·독립 핀 상세·무장뷰·전투 알림, 원본 모델 정합/적용과 종합 회귀·성능.

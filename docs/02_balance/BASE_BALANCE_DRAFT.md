## 요새용 전용 무장 체계 (Fortress-Grade Armaments · 정식 5종 · 개별 Mk.I~III 강화)

> **설계 배경**: 기지 방어 플랫폼(본기지 기능 한도 제약) 및 전투 전초기지(고정 8슬롯 중 방어 최대 **6슬롯**)는 함대보다 설치 수량이 절대적으로 적으므로, 함선용 무장(14~76 DPS)을 그대로 장착하면 방어 성능을 낼 수 없습니다. 기지·전초기지는 코어 발전기에 직결되는 **전용 요새 무장 정식 5종(핵심 4종 + 특수 정식 초중 궤도 랜스포)**으로 설계합니다.
> **강화 방식 확정**: 개별 업그레이드 (전략 연구로 Mk.II/III 단계 해금 후 각 방어 플랫폼 로컬 큐에서 개별 강화 · 자원 창고 1~3단계와 동일)
> **FTL 안전 경계 정합 (1-2)**: 모든 요새 무장의 최대 사거리는 **`1,750m` 이하**로 상한을 고정해, FTL 강제 차단 시 적 함대가 스폰되는 외곽 안전 경계(`1,800~2,200m`)에서 스폰 즉사가 발생하지 않도록 보장합니다.

### 요새 무장 확정 밸런스 원칙
1. **개별 업그레이드 (Mk.I → Mk.II → Mk.III)**: 전략 연구로 상위 단계가 해금되어도 일괄 자동 적용되지 않으며, 각 방어 플랫폼의 포탑을 로컬 큐에서 개별 업그레이드합니다(자원 창고 1~3단계 개별 업그레이드와 일관된 규칙).
2. **특수 정식 무장 (초중 궤도 랜스포)**: 코어 III(Mk.II) 해금 · 전투 전초기지 최대 **1기** / 본기지 최대 **2기** 제한으로 후반 전함·구축전함 단독 돌입을 억제합니다.
3. **명확한 카운터 약점 유지**: 중레일포/궤도포는 소형 고속함 선회 회피에 취약, 중입자 빔은 중거리(1,350m)·표적 전환 시 열집중 초기화, VLS 미사일은 방공함/PD 밀집 시 요격 감쇄, 광역 PD는 대함 장갑 관통 불가.

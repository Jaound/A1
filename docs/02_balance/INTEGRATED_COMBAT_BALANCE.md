# 통합 전투 수치 기준안 v0.6 — D116

> 사용자 채택 규칙과 이를 시험하기 위한 설계자 절대값을 구분한다. [원본 프로필](../../reference/IntegratedCombat/profile.json) · [실행/재현](../../reference/IntegratedCombat/README.md) · [결과](../04_analysis/INTEGRATED_COMBAT_RESULTS.md). 실제 UE/최종3D 에셋의 밸런스 확정이 아니다.

> **후속D119:** 수송선은 현행 중형 임무선이다. 이 v0.6 프로필이 계승한 수송선 소형 입력과 관련 결과는 이전 시험 재현용이며 중형 수송선의 수치/검증으로 사용하지 않는다. 새 함체/가격/물류·전투 비교는 [R37](../00_overview/OPEN_QUESTIONS.md#r37)에서 재산정한다.

## 이번에 확정된 방향

- 일반 혼성전 목표는1배속10~15분. 승패·퇴각·나포/임무·교착/시간 초과와 개별 강습 대상의 생존 시간을 구분한다.
- 아군 영웅이 내부에 남은 적함은 자동 공격에서 제외한다. 계속 사격/목표 달성까지/내부 이탈까지 보류를 비교한다. 기본은 내부 이탈까지다. 이미 발사된 공격은 유지한다.
- 무장 무력화 목적 명령을 제공하되 명중 보장·선체 피해 면역은 없다. 실제 무장 적중은 개별HP만, 빗나가 선체에 적중하면 함체 피해다.
- 쉴드는 활성 회복0, 비활성만 회복, 전투/비전투 차등, 피격 지연/대기 초기화 없음. 실제 쉴드 운영 승무원 감소를 회복량에 적용한다.
- 함선/기지 내부는 임시 배치로 시작하고3D 에셋 도입 후 형상별로 다시 설계한다. 논리ID와 레이아웃 버전/표시 좌표를 분리한다.
- 격납 효율·함재기 전용 연구·기체별 개조를 추가한다. 용량 연구와 실제 기체 생산을 구분한다.
- 적 영웅 수/레벨·함재기 재고·수리 화물은 자동 공개하지 않는다. 드러난 정보만 사용하고 임무/난이도/시간에 따른 비대칭 편성이 가능하다.
- 소형1/중형5/대형25/초대형125, 전체 세력 영웅15명, 초대형의 현재 함체/전용 주포 성능을 유지한다.

## 기계 판독값과 기존 버전

함체HP/가격·영웅 성장/스킬/장비·수리는 [v0.5](../../reference/DesignBaseline/v05.json)를 계승한다. 일반 무장/탐지·체급별 시험 관통은 v0.3c, 강습선은 v0.4의 소형·공격0/PD1·HP10560/쉴드6336/장갑320/속도60을 계승한다. 모든 원 입력 해시를 새 프로필에 기록한다. 초대형 함체HP·무장 목록·전용 주포 수치는 원본과 동일함을 검사한다.

JSON의 `integration`과 `heroes`/`repair`/`ships`/`weapons`가 이번 모형의 적용값이다. 이전 입력을 계승한 `global`의 미사용 호환 필드(예: 옛 최대 시험시간/포드HP)를 최신 값으로 읽지 않는다. 이번 시험 종료/포드HP는 `integration.limit`/`integration.pod_hp`다. 실제UE 데이터 이식에서는 이 호환 필드를 가져오지 않는다.

기존 모형의 고정24HP/s·18000HP 수리 예산·시간 경과 자동 재탈환·기본 방어 영웅0/고정4포드 일괄 처리로 새 결과를 만들지 않는다. v0.3/v0.4 결과는 당시 비교이며 이번 프로필로 소급 재표기하지 않는다.

## 편성·영웅·정보 조건

동등 코스트 비교는100/200/300, 임무 사례는 플레이어100 대 적75/125/150으로 구분한다. 모든 함종16종을 포함하되 채굴/수송은 호위 임무 안에서 다루고 단독 전투 승률을 역할 성능으로 보지 않는다. 연구 단계와 적 예산이 언제 증가하는지의 최종 캠페인 곡선은 이번 실험에서 확정하지 않는다.

통합 영웅 시험은 최종 지휘 업그레이드 한도15를 양측 세력 전체에 적용한다. 레벨1 신입을 후기 세력에 배치하는 시험도 가능하므로 레벨과 지휘 단계가 자동으로 같은 값은 아니다. 강습 투입4명은 같은 세력의 배치 예산에서 빼며 함선별 상주/보직 좌석도 검사한다. 주 표적 방어 영웅 수와 다른 함선 보직/수비 분산을 개발용 입력에 기록한다. 적의 미관측 병력 수를 공격AI가 조회하지 않는다.

선내 시험은 공격1/2/4명 × 방어0/2/4/6명 × L1/10/20, 양측 일반 병력8명 기본이다. 방어6명은 초대형 함체 정원 내 조건이다. L5/15, 유형 집중, 장비, 레벨 격차도 별도 비교한다. 선내전의 교전 승리와 시설 작전/함대 승리를 혼동하지 않는다.

## 모형의 범위와 남은 위험

이것은 Python 설계 모형이다. 함선XYZ 위치·비행 시간·조준 오차·거리별 탐지/PD와 임시 다층 경로를 연결하지만, 실제3D 에셋의 광선/표면/충돌·회전 포탑/선체 롤·아군 사선/충각·문 폭/닫힌 문을 완성한 것이 아니다. 외부 피격 면/시설은 대표 표면 표본으로 근사하며1/2/3층의 실제 메시별 관통을 인증하지 않는다. 함재기 공중전과 피해는 그룹 집계 근사다.

비상 탈출 준비·완전 봉쇄·포로 확보·복수 강습팀/구조선의 이동 경쟁·기지전·5시간 경제/연속 교전 전체는 이 첫 통합 시험만으로 완료 판정하지 않는다. 에셋별 배치와UE 사격이 들어오면 동일 사례를 재검증한다. 반복 횟수를 늘려도 이런 구조적 생략이 사라지는 것은 아니다.

수정 후 함대/연동 재평가와 독립 선내 결과 재사용의 근거는 [검토 전 자료](../../reference/IntegratedCombat/archive/README.md)에 보존한다. 주 통합군은 최종15명·함당1명씩 분산 보직을 우선하는 시험 편제이며 최적 캠페인 배치가 아니다. 별도6/10/15명 배치 비교로 이 선택에 따른 손실을 구분한다. 주 무장 명령군은 양측 같은 의도 비교, 보조군은 좌측만 무장 무력화/우측은 선체 공격으로 구분한다. PD는 기본 처리 순서의 공유 예산 근사이며 모든 사용자 우선순위 조합을 인증하지 않는다.

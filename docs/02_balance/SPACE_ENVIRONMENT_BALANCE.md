# 우주 환경 수치 프로필 E1 v0.1

> D123/D124의 행동 규칙을 수치화한 **Python 설계 모형의 초기 구현 후보**다. 한 전투에 공간 환경은 하나만 활성화한다. UE 메시·실제 함선 시설/추력·플레이 입력 검증과 전체 메타의 최종 밸런스 확정을 뜻하지 않는다.

[행동 규칙](../01_design/strategy/SPACE_ENVIRONMENTS.md) · [평가 결과](../04_analysis/SPACE_ENVIRONMENT_RESULTS.md) · [기계 판독 프로필](../../reference/SpaceEnvironmentCalibration/selected_profiles.json)

## 단위와 입력

- 거리m, 속도m/s, 가속도m/s², 시간은1배속 게임초다. UE cm 단위로 옮길 때 거리·속도·가속도를 각각100배 한다.
- 기준 함체/무장/수리/영웅은 IntegratedCombat v0.6의 독립 입력을 사용한다. 현재 기획에 맞춰 항공순양함T4주포를2문으로 오버레이하고 항모/항공순양함 격납고 상한4/8과 실제장착2/4를 구분한다.
- 전용 강습선에 무료 상주 경비를 추가하지 않고 공격조는 영웅4+병력6명으로 맞춘다. 세력 전체 영웅15명 제한을 유지한다.
- 중형으로 변경됐으나 수치가 미정인 수송선은 이 평가 편성에서 제외한다. 예전 소형 데이터를 현행 중형 수치로 인용하지 않는다.
- 기준 쉴드량S0와 선체HP H0는 이번 입력의 원형값이다. 환경 입력 정규화에는B=max(S0,0.2H0)를 쓴다. 실제 UE에선 실시간 쉴드 잔량·승무원 변화로 환경 강도가 바뀌지 않게 기준값을 고정해야 한다. 이번 시험에는 쉴드 최대치 개조 변동을 포함하지 않았다.

## 1. 운석지대

| 항목 | 기준값 |
| --- | ---: |
| 시험장 판정 운석 수 | 5개 |
| 대표 반경 | 45 / 65 / 85m |
| 반경50m 기준HP | 1,800 |
| 크기별HP | 1,800×(반경/50)³ |
| 충돌 입력 피해 | 0.006×H0×min(2,충돌 속도/기본 최대속도)² |
| 동일 함선·운석의 재충돌 피해 간격 | 4초 |
| 자동 회피 여유 | 함체 크기와25m 우회 여유 사용 |

파괴된 운석은 이동·사선 장애물에서 즉시 제거한다. 명중한 공격은 운석에 소모되고, 먼저 파괴된 운석에 뒤늦게 도달한 발사체를 보이지 않는 충돌체가 흡수하지 않는다. 장식 파편은 임의 피해를 주지 않는다. 피해는 정상 방호 경로를 따른다.

반경45/65/85m의HP는 각각1,312.2 / 3,954.6 / 8,843.4다. 큰 함포로 통로를 빨리 여는 것은 의도된 전술이며 초대형 주포를 하향하지 않는다.

추가 지형 제거 시험에서 기준HP1,800의 마지막 운석 제거 중앙값은100코스트144.5초·300코스트34.25초였다(각2시드). 더 오래 유지할 지역용HP6,000 후보는179.25/63초였다. HP18,000은100코스트 두 사례가600초 내 전부 제거되지 않아 기본값으로 채택하지 않는다. 이12회는 완전 전투 승률 표본에 합산하지 않는다.

충돌 모델은 단순화한 함체 경계와 입력 속도 기반이다. 실제 질량·선체 변형·PhysX/Chaos 충격량을 최종 인증한 것이 아니다. 운석 채굴·드랍·레이더 차폐는 여전히 별도 결정이다.

## 2. 방사능 지대

| 항목 | 기준값 |
| --- | ---: |
| 구역 반경R | 850m |
| 중심 최대 입력 피해율 | 초당0.006×B |
| 거리 감쇠 | max(0,1−r/R)^1.5 |
| 실제 피해 | 노출된각표면샘플의거리별입력을전체샘플수로가중합산×(1−저항률)×시간 |
| 노출 상태 | 전투 판정 |
| 저항 비교 | 0 / 25 / 50% |

정확한모형계산은노출샘플j에대해Σ[B×0.006×max(0,1−r_j/850)^1.5/N×(1−저항률)×dt]다. N은전체표면샘플수이며r_j는해당샘플의구역중심거리다.

장갑/시설 피해는 실제 노출 판정에 해당하는 면·구획에만 배분한다. 모형은 임시 함체 표면 샘플로 이를 근사한다. 실제 에셋의 광선·면적 적분 결과가 아니다. 활성 쉴드가 먼저 흡수하고 비활성 회복 지연을 새로 만들지 않는다.

중심 강도 기준으로 회복/공격이 없을 때 완전한 기준 쉴드 한 개에 해당하는 입력은 약166.7초에 누적된다. 실제 소모 시간은 위치·노출·승무원·피격·재가동 조건에 따라 달라진다.

저항 연구는 피해 감소율로 연결한다. 연구 단계·가격·선행은 아직 환경 숫자만으로 확정하지 않는다. 50% 저항 비교는 면역 보장이 아니며 기존 화재 저항을 방사능 면역으로 확대하지 않는다.

## 3. 태양 플레어

| 항목 | 기준값 |
| --- | ---: |
| 첫 파동 전 예고 | 45초 |
| 후속 파동 발생 간격 | 210초 |
| 파동 속도 | 1,200m/s |
| 두께 | 60m |
| 완전 노출 파동 입력 | 0.35×B, 파동당1회 |
| 부분 엄폐 | 비엄폐 표면 샘플 비율로 가중 |
| 무쉴드 대상의 작동 중단 | 3초 |
| 레이더 임시 교란 | 6초 |
| 교란 중 탐지거리 배율 | 0.5 |

- 초기 경고 이후 국지전10~15분에는 대략3~5회 파동이 들어온다. 시험 파동 시작 평면은x=−1,600m이며 시드에 따라 진행방향을 뒤집는다.
- 두께/속도의 비로 한 지점 통과는0.05초지만, 큰 델타에서도 지나간 파동을 누락하지 않도록 연속 교차를 검사한다. UI 예고·교전 정지·파동의 시각 표현 시간을 같은 값으로 혼동하지 않는다.
- 이번 시험의 정지 기준은 **파동 처리 직후 활성 쉴드가 없으면 적용**하는 안이다. 파동으로 막 깨진 쉴드도 포함한다. 완전 엄폐 대상은 영향이 없다.
- 함재기는 모형의 자체 쉴드75, 포드는 무쉴드로 근사한다. 실제 기체/포드 방호 데이터·쉴드 회복·완전/부분 엄폐 정지의 최종 정책은 UE 이전에 상세 확인이 필요하다.
- 이동·무장·PD 등 작동 기능은 중단하되 쿨타임·명령·재고·물리 손상을 초기화하지 않는다. 생명유지/선내 인간은 일괄 사망·기절 처리하지 않는 시험안이다. EMP와FTL의 추가 상호작용은 별도 검증이다.
- 플레어는 비행 중 미사일/포탄을 소급 삭제하지 않는다. 정지된 포드는 같은ID로 재개한다.

엄폐물은 다른 공간 환경이 아니라 단독 플레어 시험용의 일반 고정 지형이다. 최종 기준 시험은 반경60m의 구조물4개를(-800,0,0),(-180,200,0),(180,200,0),(800,0,0)에 둔다. 초기 함선과 겹치지 않음을 검사한다. 동시 운석 피해·파괴/방사능/중력은 활성화하지 않는다. 플레어+운석 파괴의 복합 환경은 이번 검증 범위가 아니다.

### 엄폐 AI의 조건

초기120회 비교는 경고마다 엄폐하는 보수적 정책과120m엄폐물을 포함했다. 그 결과는 피해 수치만의 효과가 아니다. 최종E1은60m엄폐물과아래위험도기반정책으로새시드평가하고일반지형대조군과분리한다.

최종E1에서시험하는 위험도 기반 정책은 자신의 활성 쉴드가 예상 완전노출 입력의120%보다 클 때 교전을 유지하고, 그렇지 않을 때만 엄폐한다. 기준 입력에서는약42%S0가 판단 경계다. 숨은 적 상태는 읽지 않는다. 이 정책의 동일조건 재검사와 새 시드 검증은 별도 결과로 관리하고 기존 본평가에 합산하지 않는다. 수동/Hold를 자동 엄폐로 덮어쓰지 않는다.

예고·주기·속도·두께는 이 단순 모형에서 각각의 유일 최적값으로 식별된 것이 아니다. 재현 가능한 기준값을 정한 것이며 실제 메시·이동 조작성·세밀한 파동 노출로 다시 검증한다.

## 4. 소규모 블랙홀

| 항목 | 기준값 |
| --- | ---: |
| 영향권 반경 | 1,000m |
| 고위험 중심부 반경 | 45m |
| 최대 중력 가속도 | 0.8m/s² |
| 거리 감쇠 | [1−max(0,r−45)/955]², 영향권 밖0 |
| 최종 가속도 | 위 값×0.8, 중심 방향 |
| 모형의 추진 가속도 | 소형5 / 중형3 / 대형1.2 / 초대형0.6m/s² |
| 중심부 도달 | 완파, HP·쉴드 무관 |

중심부 접촉은 **시험상 함체의 구형 표면 접촉**으로 판정한다. 함체 중심 진입으로 확정한 것은 아니며 실제 에셋/판정 경계와 맞춰야 한다. 추진 수치는 이 모형의 제동·탈출 가정이며 UE의 실제 엔진 가속도 데이터로 교체할 때 중력도 재보정한다. 함재기·포드의 중력 적용과 탄도 휘어짐은 본편 함선 견인과 분리된 미검증 범위다.

- 자동 항로는 관성·현재 접근 속도·제동 여유를 고려한다. 엔진을 잃은 함선은 견인이 계속되며 중심부에 닿으면 완파다.
- FTL의 지정 충전 시간/조건을 바꾸지 않는다. 충전 중 외력 변위와 중심부 완파는 적용한다.
- 경계 시험은20초 충전을 입력했다. 이20초는 함급별 실제FTL의 새 확정값이 아니다.
- 기준 순양함을 무동력으로 놓으면 시작 거리100/200/400/600/900m에서 중심부 접촉은 각각8.25/20.75/42/72.5/232초였다. 처음부터 중심부에 겹친 다른 큰 함체 사례는 따로 표시한다.
- 20초FTL 시험에서100m 시작은 도약 전 완파,200m 이상 시작은 해당 조건에서 도약했다. 전투 중 엔진 파괴·함재기 회수·유효 출구까지 모두 보장하는 결과가 아니다.
- 인양은 후속 기획이다. 수리/인양이 없는 고립 조건의 손실을 무료 구조로 대체하지 않는다.

## 결과 사용 경계

- [원시 결과와 재현 안내](../../reference/SpaceEnvironmentCalibration/README.md)를 함께 읽는다.
- 대조군·탐색·본평가·추가 정책 검증·경계 에피소드를 구분한다. 같은 결과를 중복 합산하지 않는다.
- 시뮬레이션 시간 제한과 승패 결정 시간을 구분한다. 30분에 중단된 실행은30분에 전투가 끝났다는 뜻이 아니다.
- 모든 체급·영웅/스킬·최종 에셋·방호 연구·AI 성향을 확정한 결과가 아니다.
- 기존 전투 화력/HP를 목표 시간에 맞춰 일괄 변경하지 않는다. 여러 환경의 중첩은 아직 실험하지 않는다.

기계 판독용원본모형프로필의asteroid.avoid_margin=18은계산에연결되지않은이전후보키다. 실제우회여유25m는본문과구현용프로필을따르며이18을튜닝완료값으로이식하지않는다.

## 검증을 구분하는 법

[2A 가이드](https://github.com/Jaound/A1/blob/be544d7/docs/PHASE2A_GUIDE.md), [검증 기록](https://github.com/Jaound/A1/blob/be544d7/docs/PHASE2A_VALIDATION.md), [재개 기록](https://github.com/Jaound/A1/blob/be544d7/docs/WORK_STATUS.md)은 해당 커밋의 기록이다. 문서 뒤쪽 이전15/45·미푸시 문구는 역사 기록으로 읽으며 상단 조작 보완17/57 및 실제 원격 HEAD와 구분한다. 과거 구간을 새 검사 결과로 소급 수정하지 않는다.

- Win64 Editor 빌드 성공, MSVC14.51.36260 / SDK10.0.26100.0은 로컬 실행 기록이다.
- 30/60/144는 같은 이동량을 나눈 **API 샘플 개수**다. 실제 30/60/144 FPS 또는 OS 마우스 검사가 아니다.
- 로컬 도구의 Windows 화면 캡처 시간 초과 때문에 OS 자동 입력은 미검증이다.
- 사용자는 이 채팅에서 조작을 직접 확인하고 2B 진행을 요청했다. 사용자 확인과 자동화 입력 미검증은 양립한다.
- 한국어 엔진 시작 자체 검사 15건 오류는 게임 자동 테스트 실패와 합산하지 않는다.

## 임시 구현과 후속 과제

쉴드 R11 Gradual/수동 전환 비활성, R14 DEV 무장 피해의 선체 미전달, 1/2층 파괴의 임시 장갑 연결이 남아 있다. 구형 접촉 분리는 정밀 함체/충각 완료가 아니다. FTL 시험 고정은 실제 성계 여행 구현이 아니다. Canvas 도식은 최종 실시간 전장 캠/2핀 UI가 아니다. DEV 피해/복구는 실제 무장/보급수리 구현이 아니다.

[2A 검토](PHASE2A_REVIEW.md)와 [이식 참조](PLAY_GAME_3_CONTROLS.md)는 각각 당시 상태를 분석한 기록이다. 2B 재개 시 로컬 최신 소스/미커밋 변경을 우선 조회하고 이 표보다 새 결과가 있으면 커밋·검사 근거와 함께 갱신한다.

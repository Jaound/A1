## D110 — 현행 구축함 대체와 최신ZIP 접근 한계

사용자가 단일 구축함 기획의 제거/두 함체 반영을 요청해 함대 본문의 함종·1F/2F역할·공격3/5·PD2/4예외, 시설 레이아웃 참조, 생산/연구표를 직접 교체했다. 구 공통가격1800/200/0·4분은 현행표에서 삭제하고 두 가격은 미정으로 둔다. 산술 예시는 현행 순양함으로 교체했다. 캠페인 코드/결과는 기존 분석의 재현성을 위해 원입력 스냅샷에 고정하고 역사 분석으로 표시했다. archive/Git이력·원시측정결과를 지워 새함체를 검증한 것처럼 만들지 않는다.

최신WebZIP은 `download_file`이32MiB상한 초과로 거부했고 로컬에도 동일파일은 없었다. 압축목록/내장PCK/코드·데이터/실행/해시를 확인하지 못했으므로 분석완료를 선언하지 않는다. 소스 중심32MiB이하ZIP 또는 접근 가능한 원본 다운로드 경로를 확보하면 후속 실물 분석이 필요하다. 모델 도입 보류는 유지한다.

## 임시 구현과 후속 과제

2026-11-16 D083~D102는 **문서에 확정됐으며 코드 적용/검증은 별도 작업**이다. 2A의 활성 비전투 Gradual은 새 활성 회복금지와 달라 수정 필요하다. 이동/공격 독립 자동화도 현재 단일모드에서 확장해야 한다. R14 DEV 무장 단독 피해는 이제 확정 방향과 일치하나 실제 사격 연결은 별도다. 1/2층 파괴의 임시 장갑 연결은 여전히 미정이다. 구형 접촉 분리는 정밀 함체/충각 완료가 아니다. FTL 시험 고정은 실제 성계 여행 구현이 아니다. Canvas 도식은 최종 실시간 전장 캠/2핀 UI가 아니다. DEV 피해/복구는 실제 무장/보급수리 구현이 아니다.

[2A 검토](../archive/analysis/PHASE2A_REVIEW.md)와 [이식 참조](../05_references/PLAY_GAME_3_CONTROLS.md)는 각각 당시 상태를 분석한 기록이다. 2B 재개 시 로컬 최신 소스/미커밋 변경을 우선 조회하고 이 표보다 새 결과가 있으면 커밋·검사 근거와 함께 갱신한다.

기지 D103~D108의 구조/혼합건조가 추가 확정됐다. BASE_BALANCE_DRAFT v0.1은 비용/시간/연구의 제안이며 구현 또는 실측 결과가 아니다. 기존2B 작업 범위를 기지 구현으로 확대하지 않는다.

[후속 Godot FBX·포탑·함급·전장 보고](../05_references/PROTOTYPE_FBX_UPDATE_RECORD.md)를 접수했다. 422검사·Vulkan/OpenGL/WebGL 부팅·ZIP 크기는 사용자 보고이며, 후속 파일/로그 미제공으로 재검증하지 않았다. UE 검사 수/완료 단계에 합산하지 않으며 모델 도입과 UE 적용은 보류다.

D110에 따라 기획의 단일 구축함을 백터급/바스티온급으로 대체했다. UE 코드 변경/검증 완료는 아니며 새 가격/성능은R31에서 확인한다. 최신 `OrbitalVanguard_Web.zip`은32MiB전송상한으로 읽지 못했다. 이전5시간 분석은 구 단일 함체 입력의 과거 결과이고 현행 두 함체 기준검증이 아니다.

D111에서 [전투 수치](../archive/balance/COMBAT_BALANCE.md)와 [Python 전투 모형 결과](../archive/analysis/COMBAT_SIMULATION.md)를 추가했다. 기획 브랜치의 분석 도구이며 UE 전투/영웅/강습 구현 완료가 아니다. 이 모형의 테스트·시행 수를 UE 빌드/자동/API 검사 수에 합산하지 않는다.

# 함선 무장 위치 표시 방법

도면은 `C:/Users/user/Documents/OrbitalVanguardAssets/WeaponPlacementGuide_v1/도면` 폴더에 함선별 PNG로 있다. 각 도면은 같은 원본 선체를 위·아래·왼쪽·오른쪽에서 본 그림이다. 화살표가 가리키는 쪽이 함선의 앞이다. 왼쪽과 오른쪽은 **함선이 앞을 향할 때의 기준**이다.

1. 원하는 함선의 PNG를 그림판 등에서 열고 무장을 놓을 위치에 동그라미와 번호를 적는다.
2. 높이나 좌우 위치가 애매하면 위·아래 그림과 측면 그림에서 같은 지점에 같은 번호를 적는다. 한 면에서 분명하면 한 군데만 표시해도 된다.
3. 번호마다 무장 종류와 티어를 적는다. 발사 방향이나 고정 방향을 원하는 경우 화살표 또는 글로 표시한다.
4. 좌우 대칭으로 놓을 무장은 `1번과 좌우 대칭 1개`처럼 적는다. 서로 다르게 놓을 때는 번호를 구분한다.
5. 표시한 이미지를 이 대화에 첨부하고 아래 형식으로 설명한다. 한 번에 한 함선씩 보내도 된다.

```text
함선: 초계함
1번: 함포 T1 1문, 위쪽, 기본 방향은 앞
2번: 요격포 T1 1문, 왼쪽 측면
3번: 2번과 좌우 대칭, 오른쪽 측면
```

도면은 위치를 소통하기 위한 참고 이미지이며 실제 게임에서 설치 가능하거나 회전·충돌 검증이 끝났다는 뜻은 아니다. 이미지의 번호는 새 배치 지시를 위한 표식이다. 기존 장착점 ID와 다를 수 있다. 무장 수량·종류가 기존 함체 구성과 다르거나 서로 겹치면 차이를 알려 드리고 기획과 실제 발사·피격 경로를 함께 확인한다. 측면 장착은 사용자가 허용했으며, 사각·회전축·포구·피격 위치를 함께 구현해야 한다.

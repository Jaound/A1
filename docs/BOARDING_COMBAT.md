# 강습 운송·선내 작전·점령

> 현행 명세: 2026-11-16. 강습 수단부터 진입·선내 교전·나포·탈출까지 관리한다. 시설 기능은 [함선](SHIP_SYSTEMS.md), 함재기/모함 귀속은 [모함 운용](CARRIER_OPERATIONS.md), 영웅 유형은 [영웅](HERO_SYSTEMS.md)이 담당한다.

## 강습 수단과 탑승

포드는 발사 시설에서 보장 근거리 내 목표로 발사한다. 영웅 또는 **분대 유닛 1개당 포드 1기**이며 병사 개개인당 한 기가 아니다. 비행 중 수동 회항 가능, 회항 중에도 요격된다. 포드 발사 시설은 새 출격에 필요하지만 이미 출발한 포드의 귀환에는 필요하지 않다.

강습선은 포드보다 안전한 수단이라는 방향만 확정됐다. 내구도·세부 운용·파괴 시 탑승자 결과는 R26이다. 포드와 같은 시설로 발사한다고 임의 가정하지 않는다.

보직 영웅·수호 분대는 자동 차출하지 않으며 명시적으로 전환/선택한다. 포드 크기 0.55 반지름/1.8 길이·발사 간격 0.25초는 프로토타입 참조값, 속도 약 165m/s·회피 0.40은 시험 기준값이다.

## 쉴드·장갑·진입 위치

- 적 쉴드를 통과할 수 없다. 포드 쉴드 충돌은 요격과 같은 탑승자 결과, 강습선은 자체 쉴드가 깎이며 진입 불가다.
- 장갑은 레이저 드릴로 뚫는다. 쉴드 없이 도달한 뒤 진입 자체에 실패 확률은 없다. 구멍 생성과 장갑 HP의 연동은 미정이다.
- 진입 전 내부 구조는 숨긴다. 진입 후 구조를 공개하되 적 유닛은 아군 시야 구역에서만 표시한다. 공개 유지 기간은 R26이다.
- **실제 도달 지점을 대상 로컬 좌표로 변환해 상면/하면/측면 구역을 먼저 분류**한다. 상면→최상층, 하면→1F, 측면→함체 데이터의 높이별 층 구역이다. 3층 측면 중앙 구역은2F이며 단층은 항상1F다. 모함의 월드Z나 단순 Z>=0 반구 판정으로 덮어쓰지 않는다. 구역 경계는 함체에 명시하고 모서리 귀속은 R17과 일관되게 검증한다.
- 외곽 슬롯 중 진입 지점을 확률적으로 선택한다. 동일 Wave의 후속 포드는 선도 진입 슬롯 또는 인접 슬롯에 합류한다. 선도 실패/진입실 파괴 시 재선정은 R18이다.

## 선내 단위와 이동·교전

영웅은 개별 유닛, 일반 경비/강습 병력은 분대 명령 단위다. 분대 사망·잔존 인원은 개별 인원별로 관리한다. 운영 승무원 게이지는 전투 유닛과 구분하며 피격·화재·감압으로 감소하고 점령 시 억류/비활성이다.

함체의 고정 방·문·복도·승강 샤프트 그래프에서 실제 거리 기반 이동을 한다. 적 전투 유닛/터렛/로봇과 만나면 자동 교전한다. 근거리 전열과 원거리 후열을 사용하고 표적 우선은 `플레이어 지정 → 자신/분대를 공격 중인 적 → 사거리 안 가까운 적`이다.

문 입구 교전 구역과 방 내부 제어 지점을 나눈다. 입구에서 적을 막는 동안 제어 지점의 작전이 가능하지만 방 안의 적 전투 병력을 몰아내야 한다. 점령 방해 범위·경로 봉쇄 상세는 R26이다.

함교·코어·생명유지 시설의 기본 경비 분대1개는 **출격 시 초기 방어 편제**이며 전투 중 재배치할 수 있다. 이를 작전 내내 이동 금지로 강제하지 않는다. 체급별 방어 영웅1~3명 배치 방향은 유지한다. 보안 터렛·로봇은 무인 개조 시설이며 나포 후 재부팅을 거쳐 소속이 바뀐다. 중복 시설별 초기 분대 배분은 R26이다.

## 점령·사보타주

| 작전 | 기본 게임 시간 |
| --- | --- |
| 일반 시설 점령 | 18초 |
| 함교 점령 | 36초, 물리 파괴된 함교는 불가 |
| 시설 파괴 공작 | 30초 |

인원·영웅 스탯으로 최대 50% 단축한다. 사보타주 중단 시 **진행률1/3·2/3 체크포인트**를 보존한다. 기본30초에서는10/20초, 50% 단축된15초에서는5/10초에 해당하며 절대10초 단위로 고정하지 않는다. 점령 중단의 보존 여부는 R26이다. 공작 30초를 완료하고 추가 무제한 공격 시간을 요구하는 별도 단계는 확정하지 않았다.

일반 시설 점령은 기존 소유 측의 기능을 마비시킨다. 정밀 사보타주는 시설을 물리 파괴하되 외장 장갑은 보존한다. 유폭을 유발했을 때 연쇄 시설/장갑의 원인 처리 상세는 R23이다.

## 함교 나포·재탈환

- 함교 점령 완료 즉시 소유/조종권 이전, 기존 명령 취소·정지. 이후 새 소유 측이 명령한다. 기존에 발사된 공격의 소속/경로는 소급 변경하지 않는다.
- 운영 승무원은 함교의 명령권 장치를 따르나 영웅·일반 경비/강습 분대는 원 소속 유지. 다른 방의 점령·파괴·무인원도 유지한다.
- **함교를 비우거나 유예 시간이 끝났다는 이유만으로 소유권을 자동 반환하지 않는다.** 잔존 적이 함교를 실제로 확보하고 점령 절차를 완료해야 재탈환된다. 함교 주둔은 방어 선택이며 강제 소유 유지 타이머가 아니다. 전체 인원 전멸에 따른 중립화·함교 파괴의 별도 전이는 유지한다. 기존30~60초 상주 유예로 자동 상실하는 안은 사용하지 않는다.
- 나포 상태의 함교가 외부 포격으로 파괴되면 그 방의 일반 병력 사망, 영웅은 큰 피해 후 인접 방으로 튕겨남(HP 0은 사망), 함선 중립 정지. 일반 함교 파괴의 자동 전투와 구분한다.
- 나포 직후 외부 적의 자동 표적 우선순위를 일시 낮추는 방향이다. 무적·피해 면역·발사된 공격 삭제가 아니다. 기간·수동 집중 공격 예외는 R18이다.
- 모함 소유물 귀속은 모함 운용을 따른다.

## 명령과 탈출 결과

상위 명령은 목표 점령/파괴, 수호, 우회, 방어 대기, 후퇴/비상 탈출이다. 경로가 없으면 알림을 제공한다.

| 사건 | 결과 |
| --- | --- |
| 출발 준비 실패 | 강습 취소 |
| 비행/귀환 중 포드 요격·쉴드 충돌 | 일반 병력 즉사, 영웅 우주 구조 대기 |
| 영웅 구조 대기 | 아군 구조 또는 적 납치 가능, 유효 시간/거리·동시 판정 미정 |
| 비행 중 목표 완파·FTL 이탈 | 귀환 |
| 귀환 중 모함 완파·FTL 이탈 | 가장 가까운 아군 함선으로 목적지 변경, 발사 시설 없어도 도킹. 아군 전무하면 정지·구조 대기 |
| 정상 탈출 | 최초 진입 지점으로 돌아가 사용한 포드로 귀환 |
| 퇴각 경로 완전 차단 | 외곽 방에서 일정 시간 후 우주 비상 탈출·구조 대기 |
| 내부 작전/탈출 실패 | 사망 또는 포로, 판정 미정 |
| 내부 잔류 상태에서 함선 완파 | 영웅·병력 전원 사망. 우주 구조 예외 미적용 |

귀환 도착 슬롯은 발사 시설/격납고 또는 안전한 아군 통제 슬롯을 사용한다. 우주복의 생명유지 면역/저항 수치는 R26이다. 중요 사건 자동 일시정지는 [전략·경제](STRATEGY_ECONOMY.md)를 따른다.

## 첫 통합 검증 목표

고도별 진입·정보 공개 → 통로/경비 교전 → 쉴드실 점령/공작 → 3D 쉴드 해제 → 포격 → 정상/비상 탈출을 끝까지 수행한다. 이 목표는 3단계이며 2B에 강습 완성을 요구하지 않는다. 미결정은 [R18/R26](OPEN_QUESTIONS.md)에서 관리한다.

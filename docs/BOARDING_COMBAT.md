# 선내 자동 전투·점령 기본안

> 사용자의 요청에 따라 설계한 **첫 플레이 검증용 기본안**이다. 확정된 강습·나포 규칙을 기반으로 하지만, 아래 전투 행동과 시간 수치는 조정 가능한 제안이다. 시간은 1배속 게임 시간 기준이다.

## 전투 단위와 이동

- 영웅은 개별 유닛, 일반 경비·강습 병력은 분대 단위로 명령한다. 병력의 체력·사망은 개별 인원별로 관리하고 분대 인원이 줄면 전투력도 줄어든다. 분대 최대 인원과 함선별 수용량은 추후 결정한다.
- 시설 슬롯의 방, 문, 복도 구간을 연결한 경로에서 움직인다. 구간의 실제 길이를 이동 속도로 나누어 소요 시간을 계산한다. 노드 수만으로 이동 시간을 정하지 않는다.
- 문과 복도에는 함체 설계에 맞는 전투 위치를 미리 둔다. 앞쪽에는 근거리 유닛, 뒤쪽에는 원거리·지원 유닛이 자리를 잡는다. 한 점에 무제한으로 겹치거나 적을 통과하지 않는다.
- 일반 시설 운영 승무원과 전투용 경비·강습 병력은 구분한다. 운영 승무원은 별도 전투 유닛으로 계산하지 않으며, 점령할 때 전투 병력처럼 모두 처치해야 하는 대상으로 삼지 않는 안이다.

## 자동 교전

- 목표 이동 중 적 전투 유닛과 만나면 자동으로 교전한다. 기본 상태는 생존과 길목 확보를 우선하며 무리하게 적을 통과하지 않는다.
- 근거리 유닛은 접근해 전방에서 싸우고, 원거리 유닛은 실제 사거리와 사선이 확보된 위치에서 사격한다. 벽과 닫힌 문을 관통해 공격하지 않는다. 사거리는 방 개수로 판정하지 않는다.
- 기본 표적 우선순위는 `플레이어 지정 표적 → 자신·분대를 공격 중인 적 → 사거리 안의 가까운 적`이다. 지원형·지휘형도 각자의 공격 능력과 사거리를 사용하며, 특수 능력의 자동 사용 조건은 개별 능력 설계 때 정한다.
- 체력, 공격력, 방어력, 명중률, 사거리, 공격 간격, 이동 속도를 기본 스탯으로 둔다. 실제 명중과 피해 수치는 아직 정하지 않는다.
- 시설 파괴는 시설 내구도에 피해를 주며, 영웅·병력 피해와 별도로 계산한다. 선내 시설 피해는 기존 시설·전체 체력·연쇄 폭발 규칙에 연결한다.

## 점령과 사보타주

- 점령은 해당 방의 적 전투 병력을 몰아낸 뒤 제어 지점에서 수행한다. 같은 방에 적 전투 병력이 진입하면 진행을 중단하고 교전한다.
- 일반 시설 점령 기본 시간은 **6초**, 함교 점령은 **12초**로 시작한다. 여러 유닛이 몰려도 기본 점령 시간이 무제한으로 단축되지 않도록 한다.
- 교전으로 중단된 점령 진행도는 같은 작전 측이 방에 남아 있으면 보존한다. 해당 측이 방을 완전히 떠나거나 반대 측이 제어 지점을 확보하면 초기화한다.
- 일반 시설 점령 완료는 기존 소유 측의 운영을 마비시킨다. 점령 측의 모든 영웅·병력이 떠나면 무조건 즉시 복구되는 것이 아니라 방을 회수하고 운영 승무원이 재진입해야 한다.
- 함교는 점령 진행이 완료되는 **그 순간** 기존 확정 규칙대로 소유·조종권을 즉시 이전한다. 재탈환에도 같은 점령 절차를 적용한다. 함교 장치의 명령권은 운영 승무원에게만 적용되며 영웅·경비·강습 병력의 소속은 바꾸지 않는다.
- 시설 파괴 명령은 제어 지점에 **10초간 파괴 공작 준비**를 한 뒤 시설에 공작 피해를 주는 안이다. 준비 중 교전·이동으로 중단되면 준비를 다시 시작한다. 준비 완료만으로 시설을 확정 파괴하지 않으며, 시설 내구도와 영웅의 파괴 능력을 반영한다. 반복·재사용 간격과 피해량은 추후 조정한다.
- 코어에는 운영 승무원이 없으며, 제어 시설 점령과 물리적 파괴를 구분한다. 코어 점령만으로 완파되지 않는다.

## 플레이어 명령

| 명령 | 자동 행동 |
| --- | --- |
| 목표 점령 | 목표로 이동, 경로상 적 교전, 방 확보 후 점령 |
| 목표 파괴 | 목표로 이동, 적 교전, 공작 준비 후 시설 공격 |
| 수호 | 지정 방·복도 구역을 지키며 침입자를 상대하고 과도하게 추격하지 않음 |
| 우회 | 알려진 교전 구간을 피하는 대체 경로 탐색. 경로가 없으면 상태 알림 |
| 방어 대기 | 현재 구역에서 방어하며 다음 명령 대기 |
| 후퇴 | 기존 작업 취소, 원래 진입 지점으로 이동해 포드 재탑승. 막힌 경로를 순간 통과하지 않음 |

## 정보 표시와 실패 처리

- 진입 전에는 내부 시설 이름과 위치를 공개하지 않는다. 목표 시설의 종류를 미리 명령했다면 진입 후 공개된 구조를 이용해 경로를 정한다.
- 첫 진입 후 시설 배치는 알 수 있다. 적 병력의 실시간 위치까지 전부 공개할지는 별개이며, 초안에서는 아군 유닛이 볼 수 있는 구역의 적만 표시한다.
- UI는 현재 행동·목표·도착 예상 시간·점령 진행·교전·경로 차단을 보여준다. 경로가 없을 때 영웅이 끝없이 재탐색하거나 명령 없이 위험한 시설을 파괴하지 않도록 한다.
- 방 파괴만으로 고정 복도를 영구 삭제하지 않는 안이다. 화재·감압은 기존 환경 위험으로 적용한다. 통로가 실제 막히는 기능은 별도 설계한다.
- 후퇴 실패를 즉시 확률 사망으로 처리하지 않는다. 실제 교전과 포로 판정 등으로 결과를 정하며, 포로가 되는 구체적인 조건은 후속 설계한다.

## 첫 검증 시나리오

1. 포드 진입 지점을 무작위로 정하고 내부 구조를 공개한다.
2. 분대가 실드제어실로 이동하다 복도에서 경비 분대와 교전한다.
3. 플레이어가 교전 지속·우회·수호·퇴각 중 하나를 선택한다.
4. 시설을 확보하고 점령 또는 파괴 공작을 수행한다.
5. 원래 진입 지점까지 돌아가 포드로 귀환한다. 나포·재탈환과 외부 포격도 이후 이 흐름에 추가해 검증한다.

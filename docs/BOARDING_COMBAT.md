# 선내 자동 전투·점령 기본안

> 상태: 1~4차 기획 검토 및 확정 사항 반영 최신본. 체급별 가변 1~3층 구조, 수직 통로 이동, 점령 시간 3배 상향, 선내 보안 시설 및 운영 승무원 게이지 방식이 반영되었다. 시간은 1배속 게임 시간 기준이다.

## 전투 단위, 층간 이동 및 정보 표시

- 영웅은 개별 유닛, 일반 경비·강습 병력은 분대 단위로 명령한다. 병력 체력·사망은 개별 인원별로 관리한다.
- **방어 상주 편제:** 함교·코어·생명유지장치에는 기본 경비 분대 1개가 반드시 상주하며, 함선 체급에 따라 영웅 1~3명이 배치된다. 기지 개조를 통해 **선내 보안 시설(터렛·전투 로봇)**을 배치할 수 있다.
- **가변 층수 및 수직 통로 이동:** 함선은 체급에 따라 1~3층 구조를 가지며, 시설 슬롯의 방, 문, 복도 및 층간을 연결하는 **고정 수직 통로(승강 샤프트)**를 따라 실제 거리 기반으로 이동한다.
- **층 전환 UI:** 화면 측면 20~30% 미니맵에는 한 번에 한 층의 단면도만 표시하며, **1F / 2F / 3F 버튼**으로 전환한다. 교전·위기 발생 층은 버튼 강조 테두리로 알린다.
- **운영 승무원 게이지:** 일반 운영 승무원은 개별 전투 유닛이 아니라 **각 시설 방에 귀속된 '인원 게이지'**로 관리한다. 방 피격이나 화재·감압 시 인원 게이지가 줄어 효율이 낮아지고, 적 점령 시 일시 비활성(억류) 처리된다.

## 자동 교전 및 구역 분리

- 목표 이동 중 적 전투 유닛·보안 터렛·전투 로봇과 만나면 자동 교전한다. 근거리 유닛은 전방, 원거리 유닛은 사거리·사선이 확보된 후방에서 싸운다.
- **방 내부 제어 지점과 문 입구 교전 구역 분리:** 아군 분대가 문 입구나 인접 복도를 방어하는 동안 방 내부의 영웅이 교전 방해 없이 점령/공작을 진행할 수 있도록 구역을 분리한다.
- 기본 표적 우선순위는 `플레이어 지정 표적 → 자신·분대를 공격 중인 적 → 사거리 안의 가까운 적`이다.
- **선내 보안 시설(터렛·전투 로봇):** 무인 시설로 인원 부족 패널티가 없으며, 함교가 나포되면 **긴 재부팅(비활성) 시간**을 거친 뒤 새 소유주 소속으로 전환된다.

## 점령과 사보타주 (3배 상향 및 보완 규칙)

- 점령은 방의 적 전투 병력을 몰아낸 뒤 제어 지점에서 수행한다.
- **기본 소요 시간 (1배속 기준):**
  * 일반 시설 점령: **18초**
  * 지휘함교 점령: **36초** (파괴된 함교는 점령 불가)
  * 시설 파괴 공작(사보타주): **30초**
- **시간 단축 및 체크포인트:** 분대 잔존 인원수와 영웅의 점령/공작 스탯에 따라 **최대 50%까지 시간 단축**이 가능하다. 파괴 공작(30초)은 중단 시 완전 초기화하지 않고 **10초 단위 체크포인트(33% / 66%)**를 보존한다.
- **함교 점령 유지 조건:** 함교 점령 완료 시 즉시 소유권이 이전되나, 선내 적 세력을 모두 소탕하기 전까지는 **일반 강습 병력(또는 아군화된 터렛/로봇)을 함교에 남기거나 유예 시간(30~60초)을 유지**해야 소유권이 보존된다. 영웅은 잔존 적 소탕을 위해 이동할 수 있으며, 적 전멸 후에는 함교를 비워도 영구 유지된다.
- **파괴 사보타주 장갑 보존:** 선내 영웅의 파괴 공작으로 내부 시설을 파괴할 때는 외장 장갑이 파괴되지 않고 보존된다.

## 플레이어 명령 및 비상 탈출

| 명령 | 자동 행동 |
| --- | --- |
| 목표 점령 | 목표로 이동(수직 통로 포함), 경로상 적 교전, 방 확보 후 점령(18초/36초) |
| 목표 파괴 | 목표로 이동, 적 교전, 공작 준비(30초, 10초 체크포인트) 후 시설 공격 |
| 수호 | 지정 방·복도·수직 통로 구역을 지키며 침입자 방어 |
| 우회 | 알려진 교전 구간을 피하는 대체 경로 탐색. 경로가 없으면 상태 알림 |
| 방어 대기 | 현재 구역에서 방어하며 다음 명령 대기 |
| 후퇴 / 비상 탈출 | 원래 진입 지점 포드로 이동해 재탑승. **경로가 완전히 차단된 경우 외곽 슬롯 방에서 우주 공간으로 직접 비상 탈출(표류/구조 대기)** 가능 |

## 정보 표시와 안전장치

- 적 강습 포드가 아군 함선에 진입한 순간 또는 아군 지휘함교·코어 방에 적이 진입해 점령·공작을 시작한 순간에는 **자동 일시정지(또는 1배속 강제 감속)**가 작동해 3배속 플레이 중 순식간에 나포되는 사고를 방지한다.
- 진입 전에는 내부 구조를 공개하지 않으며, 진입 후 해당 함선의 구조를 공개하고 아군 시야 구역의 적만 표시한다.

## 첫 검증 시나리오

1. 모함/포드 도달 고도에 맞춰 적함 상층(또는 하층) 외곽 슬롯에 진입하고 1F/2F/3F UI에 내부 구조를 공개한다.
2. 분대가 수직 통로를 거쳐 실드제어실로 이동하다 경비 분대 및 보안 터렛과 교전한다.
3. 문 입구 교전 구역을 분대로 막은 채 영웅이 실드제어실을 점령(18초) 또는 파괴 공작(30초)한다.
4. 원래 진입 지점 포드로 귀환하거나, 경로 차단 시 외곽 방에서 우주 비상 탈출을 수행한다.

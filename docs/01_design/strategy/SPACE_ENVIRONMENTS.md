# 우주 환경·전장 제약 — D117 초안

> **사용자 방향:** 우주의 환경 차이로 전투 변수를 추가한다. 운석지대·우주 방사능 지대·태양 플레어·소규모 블랙홀이 제시됐다. **아래 종류별 효과·예고·대응·중첩 정책은 설계 제안**이며 아직 사용자 채택/수치 확정/구현 완료가 아니다. 수치와 기존 전투 결과를 변경하지 않았다.

## 담당 범위와 목적

성계의 환경 분포·지속/주기·전장 효과·대응 수단을 이 문서에서 관리한다. 자원/항로는 [전략·경제](STRATEGY_ECONOMY.md), 피해는 [함선](../fleet/SHIP_SYSTEMS.md), 이동/사격/FTL은 [함대](../fleet/FLEET_COMBAT.md), 정보 표시는 [UI](../interface/UI_SYSTEMS.md)가 원 규칙을 관리한다.

각 환경은 다른 판단을 요구한다. 운석은 공간과 사선, 방사능은 노출 시간과 방호, 플레어는 시점과 엄폐, 블랙홀은 항로와 기동 부담을 중심으로 한다. 전장 전체에 같은 공격력/방어력 감소를 주는 방식으로 통일하지 않는다. 환경은 적도 이용하고 우회할 수 있으며 초대형의 결전 화력을 일괄 하향하는 근거로 쓰지 않는다.

## 초판 후보4종

| 환경 | 형태/지속 | 핵심 제약 제안 | 전술적 활용/대응 |
| --- | --- | --- | --- |
| 운석지대 | 고정 대형 운석과 통로 | 실제 장애물·사선 차단, 큰 함체의 통로 선택 제약 | 소형의 우회/측면 공격, 대형의 출구 통제, 안전한 채굴/호위 경로 선택 |
| 우주 방사능 지대 | 경계가 있는 지속 노출 구역 | 외부 방사선 부하로 쉴드 소모, 방호 상실 후 내부 피해 위험 | 노출 시간을 줄이는 통과/교대, 방호 준비, 위험 자원지의 채굴 효율과 복구비 비교 |
| 태양 플레어 | 예고 후 방향성을 가진 일시적 파동 | 쉴드에 순간 부하·레이더 일시 교란 | 대형 운석/지형 뒤 엄폐, 파동 전후 출격/이동 시점 선택 |
| 소규모 블랙홀 | 외곽 영향권·고위험 중심 구역 | 중력권의 추진/가감속/선회 부담, 위험 구역 우회 | 안전 항로/접근 방향 선점, 추격/퇴각 경로 차단, 엔진 상태를 고려한 진입 |

첫 환경 집합을 이4종으로 제한한다는 확정은 아니다. 성운·잔해/기뢰·전기 폭풍 등은 후속 후보이며 이번에 함께 추가하지 않는다. 환경 강도는 약/중/강 후보로 구분하되 함선/무장 티어나 자원 등급과 같은 값으로 취급하지 않는다.

## 운석지대 — 공간 제약

- 큰 운석은 실제 충돌/사선 장애물이다. 장식용 작은 파편과 판정용 운석을 구분하고, 화면에 보이지 않는 장식 파편의 무작위 피해를 기본으로 만들지 않는다.
- 빔/포탄/미사일이 실제 운석에 닿으면 차단하는 기본안을 제안한다. 빔의 높은 명중률이 장애물 관통을 보장하지 않는다. 유도 미사일의 추적이 자동 장애물 우회를 보장하지 않으며 실제 경로/충돌과 별도로 다룬다.
- 이동 가능 통로는 함체 크기로 검사한다. 소형이 지나는 틈을 대형 편대 전체가 통과한다고 가정하지 않는다. 통과 불가능한 함선을 무한 재명령하거나 진형을 억지로 밀어 넣지 않는다.
- 첫 버전은 사선/이동 차단을 중심으로 한다. 레이더 차폐·충각 피해·파괴 가능한 운석/채굴 광맥은 별도 채택/수치 설계가 필요하다. 운석 뒤에 있다고 자동으로 탐지가 끊긴다고 선언하지 않는다.

## 방사능 지대 — 지속 노출

- 제안 기본안은 외부 환경 피해를 기존 방호 경로에 연결하는 것이다. 활성 쉴드가 우선 흡수하고, 쉴드 상실 후에는 장갑/시설 피해를 통해 승무원 손실이 생길 수 있다. 정상 쉴드를 무시하고 영웅/승무원을 직접 죽이는 방사선 관통은 별도 규칙이 없으면 적용하지 않는다.
- D116의 활성 회복0·비활성 차등 회복·피격 회복 지연 없음은 유지한다. 환경에 노출됐다는 이유로 별도 회복 대기 초기화를 추가하지 않는다. 환경 노출을 전투/비전투 중 어느 회복 상태로 분류할지는 R36에서 결정한다.
- 실제 선내 인원은 함선 방호를 공유한다. 포드·함재기·우주 구조 대기 영웅은 각자의 보호 능력을 사용하며, 동일한 환경 피해를 모함/탑승체/인원에 중복 청구하지 않는다.
- 방사선 방호 장비·승무원 보호 설비·노출 예측 연구는 후속 연구 후보다. 기존 지원형의 화재/감압 저항을 방사선 완전 면역으로 확대하지 않는다. 별도 개인 누적 피폭 게이지/치료 체계는 아직 추가하지 않는다.

## 태양 플레어 — 예고되는 시점 제약

- 주기는 `평상 → 예고 → 파동 통과 → 정상화`로 제안한다. 예고 시간·주기·파동 속도/두께·피해/교란 시간은 미정이다. 정지/배속과 같은 게임 시간을 사용한다.
- 파동 방향과 예상 도달을 표시하고, 실제 큰 장애물이 가리는 영역을 엄폐 후보로 사용한다. 카메라에서 보이지 않는다고 엄폐된 것이 아니며 대형 함체의 부분 노출도 후속 판정 대상이다.
- 쉴드 피해는 기존 외부 피해 경로, 레이더 교란은 별도 임시 환경 보정으로 처리하는 안이다. 교란을 시설 물리 파괴/점령/승무원 사망으로 기록하지 않는다.
- 교란이 끝나면 임시 보정만 해제한다. 실제 잃은 쉴드/선체/인원은 무료 복구하지 않는다. 탐지가 끊긴 동안 신규 사격 금지와 기발사 공격의 수명 유지도 기존 규칙을 따른다.

## 소규모 블랙홀 — 기동과 항로 제약

- 게임용 중력 이상 영역으로 설계한다. 초기 구현 제안은 중력권의 추진/가감속/선회 부담을 수치화하는 방식이다. 함선과 모든 발사체를 실제 중력 궤도로 적분하는 기능은 후속 후보로 분리한다.
- 중심부는 명확히 표시되는 고위험 구역으로 둔다. 자동 항로는 중심부를 피한다. 접근 한계/통과 가능 여부·중심부 지속 피해/완파 조건은 미정이며 예고 없는 즉사 구역으로 확정하지 않는다.
- 외곽 위험도와 우회 경로를 읽을 수 있게 하고 엔진 손상 상태의 진입 위험을 표시한다. 소형/대형의 유불리는 실제 추진/기동 데이터로 조정하며 크기만으로 자동 면역을 주지 않는다.
- **FTL 충전 중 위치 고정·일반 피격으로 충전 중단 없음**은 유지한다. 초기안에서 강제 중력 표류·FTL 자동 취소를 추가하지 않는다. 중력권 충전 시간 증가/시작 제한이나 실제 견인력을 채택하려면 기존 FTL/Hold와의 충돌을 먼저 해결해야 한다.
- 탄도 휘어짐·빔 굴절·이벤트 호라이즌 흡입은 초판 필수로 묶지 않는다. 실제 견인력을 추가할 때는 엔진0·고정 함선·수동 자세·충돌/구조 가능성까지 별도 검증한다.

## 공통 제안과 기존 규칙의 경계

| 항목 | 제안 원칙 |
| --- | --- |
| 전술/전략 연결 | 장식 배경과 실제 영향 영역을 구분. 같은 성계 환경 정의를 전투·이동·항로/채굴에 연결 |
| 공정한 정보 | 관측된 구역의 경계·위험도·예고만 제공. 환경 알림으로 적 영웅 수/레벨·기체/화물을 공개하지 않음 |
| 명령 | 이동 자동은 알려진 위험을 항로 비용에 반영. 이동 수동/Hold를 자동 우회 명령으로 바꾸지 않고 경고 표시 |
| 양측 적용 | 진영별 무료 면역 없이 실제 노출/장비로 판정. AI도 자기 관측 정보로 경로/엄폐를 선택 |
| 피해 | 환경 원인/사건ID를 부여하고 기존 피해 경로를 재사용. 사격 보류가 환경 피해 면역을 주지 않음 |
| 배속/표시 | 동일 게임 시간의 누적 피해·예고/지속 시간이 일치. 여러 UI 창이 같은 환경 효과를 다시 실행하지 않음 |
| 중첩 | 초판은 같은 종류의 지속 효과에 가장 강한1개만 적용하는 안. 다른 종류는 각각 적용하고 감속 등 합성 상한은 수치화 |
| 경계 | 함체 중심/반경/부분 노출의 기준을 종류별 명시. 경계 왕복으로 효과/알림이 매 프레임 깜박이지 않게 적용/해제 조건 분리 |
| 이탈/복구 | 이탈 시 임시 보정만 해제. HP/쉴드·쿨타임·영웅 소모품·부상은 초기화하지 않음 |
| 환경 이벤트 | 파동1회가 같은 대상에 중복 명중하지 않게 기록. 지속 노출은 게임 시간×강도로 적분 |

환경은 안전한 우회·엄폐·대기·장비 준비 중 최소 하나의 대응을 제공하는 방향을 권한다. 위험 지역의 자원/항로 이득도 함께 설계하되 모든 고급 자원을 반드시 한 종류 위험지대에만 잠그지 않는다. 기지 건설 가능 구역과 환경 피해/방호는 본기지/전초별로 후속 결정한다.

## 다음 세부 결정과 검증

[R36](../../00_overview/OPEN_QUESTIONS.md#r36)에서 종류별 효과 채택, 방사능 피해/회복 상태, 운석의 센서 차폐·파괴/채굴, 플레어 예고/엄폐, 중력/FTL 예외, 중첩/방호 상한·기지 건설을 관리한다. 강도·크기·지속/예고·피해량·회복/이동 보정·연구 가격은 다음 수치 설계다.

검증 순서는 환경 없는 기존 전투 유지 → 환경1종씩 → 강도/통과/엄폐 → 강습/귀환/수리/FTL 경계 → 복합 환경이다. 환경 때문에 모든 교전 시간을 다시 강제 연장하지 않는다. 이번 문서 추가는 **기획 초안**이며 Python 모형/UE에 환경을 구현하거나 새 시뮬레이션을 실행한 것이 아니다. 기존 D116 결과는 환경 없는 조건으로 유지한다.

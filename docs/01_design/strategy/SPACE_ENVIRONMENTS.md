# 우주 환경·전장 제약 — D123 현행 규칙

> 2026-11-17 KST. 사용자가 D117의 환경별 기존 제안·공통 원칙을 채택하고 충돌·파괴·노출·엄폐·중력 규칙을 구체화했다. 아래 **확정 규칙**과 **남은 결정/수치·구현 제안**을 구분한다. Python/UE 환경 구현과 신규 시뮬레이션은 아직 수행하지 않았다.

## 담당 범위와 목적

성계의 환경 분포·지속/주기·전장 효과·대응을 이 문서에서 관리한다. 자원/항로는 [전략·경제](STRATEGY_ECONOMY.md), 피해는 [함선](../fleet/SHIP_SYSTEMS.md), 이동/사격/FTL은 [함대](../fleet/FLEET_COMBAT.md), 표시와 알림은 [UI](../interface/UI_SYSTEMS.md)가 담당한다.

환경마다 다른 판단을 요구한다. 운석은 공간과 사선, 방사능은 노출 위치·시간과 방호, 플레어는 예고 시점과 엄폐, 블랙홀은 지속 기동과 탈출 경로가 핵심이다. 적도 환경을 활용·회피하며 초대형함의 결전 화력을 일괄 하향하는 근거로 사용하지 않는다.

## 1. 환경별 확정 요약

| 환경 | 확정 효과 | 주된 대응 |
| --- | --- | --- |
| 운석지대 | 실제 이동·사선 장애물, 충돌 피해, 파괴 가능, 파괴 후 통로·엄폐 변화 | 함체 크기에 맞는 항로, 우회·출구 통제, 운석 파괴 |
| 방사능 지대 | 중심에 가까울수록 강한 지속 피해, 실제 노출 부위만 피해, 노출은 전투 상태, 후속 연구로 피해 감소 | 노출 시간·면적 조절, 방호·수리·교대 |
| 태양 플레어 | 예고되는 방향성 파동, 쉴드 부하·임시 레이더 교란, 부분 엄폐 비율에 따른 피해, 쉴드 없는 함선·함재기·포드 정지 | 예고에 따른 이동·엄폐·출격 조절 |
| 소규모 블랙홀 | 실제 중심 방향 견인, 지속 기동 필요, 중심부 도달 시 완파, 엔진 상실 후에도 견인 지속 | 안전 항로·추력 확보·지속 기동, 후속 인양 |

이 네 종류 외 환경은 후속 후보이며 이번에 자동 추가하지 않는다. 강도는 함선/무장 티어·자원 등급과 별개다. 환경의 수치·크기·빈도는 아직 확정하지 않았다.

## 2. 운석지대 — 파괴 가능한 공간·사선 제약

### 확정 규칙

- 판정용 큰 운석과 장식용 작은 파편을 구분한다. 큰 운석은 실제 충돌/사선 장애물이다. 화면에 보이지 않는 장식 파편의 무작위 피해를 기본으로 만들지 않는다.
- 빔·포탄·미사일은 실제 운석에 닿으면 차단된다. 빔의 높은 명중률이 장애물 관통을 보장하지 않으며 유도 미사일도 자동 우회를 보장하지 않는다.
- 함선이 운석과 충돌하면 피해를 받는다. 충돌했다는 이유만으로 즉시 완파를 강제하지 않는다. 중심부 접촉 완파인 블랙홀과 구분한다.
- 운석은 공격으로 파괴할 수 있다. 파괴 결과를 실제 이동 통로와 엄폐/사선 판정에 반영한다. 시각만 사라지고 보이지 않는 충돌체가 남으면 안 된다.
- 함체 크기와 편대 폭을 검사한다. 소형만 지나는 틈으로 대형을 무한 재명령하거나 강제로 밀어 넣지 않는다.

### 남은 결정/구현 제안

- 운석 HP·방어/저항·크기별 충돌 피해와 속도/질량 계수, 충돌 재피해 간격은 수치 설계가 필요하다.
- 레이더 차폐는 미정이다. 사선 차단을 자동 탐지 차단으로 확대하지 않는다.
- 채굴 가능한 광맥과 파괴 후 자원 드랍은 아직 확정하지 않았다. 파괴 가능이 곧 무료 채굴 수입을 뜻하지 않는다.
- 파괴 후 잔해가 장식인지 새 장애물인지, 함선/함재기/포드별 충돌 범위는 별도 상세화한다.
- 구현 시 파괴 이벤트에 맞춰 경로·사선·플레어 엄폐 캐시를 함께 갱신하고, 고속 이동/탄의 연속 충돌을 검증한다. 한 충돌을 물리 이벤트와 환경 이벤트에서 중복 피해로 처리하지 않는다.

## 3. 방사능 지대 — 거리·노출 부위 기반 지속 피해

### 확정 규칙

- 구역 중심에 가까울수록 지속 피해가 증가하고 멀어질수록 감소한다. 강도 함수·최대/최소값·구역 크기는 미정이다.
- 함선의 실제 노출 부위에만 피해를 준다. 일부 노출을 이유로 모든 장갑면/내부 시설에 동일 피해를 뿌리지 않는다. 노출 판정의 방향·샘플·엄폐 인정 범위는 상세화가 필요하다.
- 활성 쉴드가 먼저 흡수하고, 쉴드 상실 후 노출 장갑/시설을 통해 선체·운영 인원 피해가 생긴다. 정상 쉴드를 무시해 내부 영웅/승무원을 직접 죽이지 않는다.
- 방사능 노출은 **전투 상태**로 취급한다. 노출 중 비전투 쉴드 회복 속도를 사용하지 않는다.
- 활성 쉴드 회복 금지, 비활성 쉴드 회복과 실제 승무원 효율, 피격 회복 지연 없음은 유지한다. 환경 피해마다 회복 대기 시간을 새로 초기화하지 않는다.
- 실제 탑승 인원은 함선 방호를 공유한다. 모함·탑승체·인원에 같은 환경 피해를 중복 청구하지 않는다. 외부 함재기·포드·구조 대기 영웅은 각자의 방호 조건을 따른다.
- 후속 연구로 방사능에 받는 피해를 감소시킬 수 있다. 면역·공짜 치료·지원 영웅의 기존 화재 저항을 방사능 면역으로 확대하지 않는다.

### 남은 결정/구현 제안

- 방사능 강도 함수, 노출 면적/시간 계산, 저항 단계·상한·비용·연구 선행을 정해야 한다.
- 전방향 쉴드의 총 피해 흡수와 노출 장갑면 판정을 구분한다. 피해량을 노출로 가중한 뒤 기존 방호 경로를 한 번 통과시키는 구조를 검토한다.
- 구역 이탈 후 전투→비전투 전환은 기존 전환 정책과 연결하며 별도 임의 시간을 중복 추가하지 않는다.
- 방사선 전투 판정을 공격자 존재·적 탐지로 오인하지 않는다. 방호 연구로 피해가 줄어도 노출 상태 자체와 회복 모드를 구분한다.
- 별도 개인 누적 피폭 게이지/치료 체계는 이번에 추가하지 않는다.

## 4. 태양 플레어 — 예고·파동·부분 엄폐·정지

### 확정 규칙

- 진행은 평상 → 예고 → 파동 통과 → 정상화다. 파동 방향과 예상 도달을 표시한다.
- 예고 시간·발생 주기·파동 속도·두께·피해량은 환경/전투 시뮬레이션으로 적정값을 찾는다. 현재 숫자를 확정하지 않는다.
- 실제 큰 장애물의 그림자 영역을 엄폐로 사용한다. 카메라에서 보이지 않는다는 이유로 엄폐 판정하지 않는다.
- 함선이 일부만 가려지면 노출/엄폐 비율에 따라 피해가 달라진다. 중심점 하나만으로 완전 엄폐/전체 피격을 결정하지 않는다.
- 쉴드에 부하를 주고 레이더를 임시 교란한다. 교란을 시설 물리 파괴·점령·승무원 사망으로 기록하지 않는다.
- **쉴드가 없는 함선 및 함재기·포드는 일시 정지하며, 이동뿐 아니라 무장·요격 등 작동 기능도 잠시 중단한다.** 정지 지속 시간은 다른 플레어 수치와 함께 시뮬레이션으로 정한다(D124). 일시 중단은 시설 물리 파괴·탑승 인원 사망·소유권 변경이 아니다.
- 교란 종료 시 임시 보정만 해제한다. 실제 소모된 쉴드·장갑·HP·인원은 무료 복구하지 않는다. 탐지 상실 중 신규 사격 제한과 기발사 공격 유지도 기존 규칙을 따른다.
- 파동1회가 같은 대상에 중복 명중하지 않도록 파동ID/대상ID를 사용한다. 정지·배속은 공통 게임시간을 따른다.

### 일시 정지의 확정 범위와 남은 결정

D124에서 이동·무장·요격 등 작동 기능의 일시 중단과 지속 시간의 시뮬레이션 결정을 확정했다. 영구 파괴로 처리하거나 무료 시설/인원 복구를 실행하지 않는다. 전체 작동 기능과 생명유지/코어/선내 인원·스킬·FTL의 세부 상호작용은 아직 별도 상세화가 필요하다.

- 기능 중단이 끝난 뒤 다른 고장/파괴/승무원/점령 조건을 확인해 가동한다. 쿨타임·살보·명령·재고를 무료 초기화하지 않는다. 정확한 재개/복구 절차는 후속 구현에서 명시한다.
- 쉴드 없음의 기준이 활성 방호 없음인지, 시설 미장착인지. 피해로 같은 파동 도중 쉴드가 깨진 경우도 정지하는지.
- 함재기/포드의 자체 쉴드가 정상일 때도 모두 정지하는지, 쉴드 없는 기체만 정지하는지.
- 정지 중 기발사 공격·미사일·중력 등 외력을 어떻게 처리할지. 함재기/포드 정지를 격추·승객 사망으로 바꾸지 않는다.
- 완전 엄폐된 무쉴드 대상의 정지 면제와 부분 노출에 따른 정지 지속시간 변화.

임시 시험안을 만들 때는 이 미결정 상태를 표시하고 확정 규칙과 분리한다.

## 5. 소규모 블랙홀 — 실제 견인과 중심부 완파

### 확정 규칙

- 영향권에서 함선을 실제로 중심 방향으로 끌어당긴다. 단순 속도/선회 감소만 적용한 상태로 완료 처리하지 않는다.
- 함선은 지속해서 기동해야 중심부로 끌려가는 위험을 피할 수 있다. 자동 항로는 고위험 중심부를 회피하고, 수동/Hold 상태는 경고 없이 자동 안전 항로로 바꾸지 않는다.
- 중심부에 닿으면 선체/쉴드 잔량과 관계없이 완파다. 일반 지속 피해·단순 행동 불능과 구분한다. 내부 잔류 인원은 기존 완파 사망 규칙을 따른다.
- 엔진 파괴로 자력 이동이 불가능해져도 중력은 지속되며 중심부에 닿으면 완파된다. 엔진 파괴 순간 곧바로 완파시키지 않는다.
- 후속으로 다른 함선을 통한 인양/견인 시스템을 추가한다. 향후 인양 가능성을 현재 무료 구조·자동 복귀로 대체하지 않는다.
- **FTL의 충전 시간·사용 조건을 환경 때문에 변경하지 않는다.** 일반 피격으로 취소되지 않는 규칙과 엔진 파괴 시 취소도 유지한다.
- FTL 충전을 위해 자력 이동하지 않고 대기하는 동안에도 중력에 의해 중심부로 끌려갈 수 있으며, 중심부 도달 시 완파된다.

### 기존 위치 고정과의 충돌 정리

기존 FTL의 절대 위치 고정에 **D123 중력 외력 예외**를 명시한다. 충전 중 자력 이동·사선 확보·자동 회피는 계속 금지하지만 중력으로 세계 위치가 변하는 것을 막지 않는다. 중력 변위 자체로 충전을 취소/재시작하거나 충전 시간을 늘리지 않는다. Hold도 중력 면역/무한 위치 고정으로 사용하지 않는다. 이는 새 환경 예외이며 과거 구현에 이미 존재했다고 표현하지 않는다.

### 남은 결정/구현 제안

- 영향권·완파 중심부 크기, 거리별 견인 가속도, 추력/질량/체급과의 관계를 정해야 한다.
- 중심부 도달을 함체 표면 접촉 또는 함체 중심 중 무엇으로 판단할지 결정해야 한다. 크기별 위험과 UI 경계를 일치시킨다.
- 함재기·포드·운석·발사체까지 같은 중력을 적용할지는 미정이다. 함선 견인 결정을 근거로 탄도 휘어짐/빔 굴절을 자동 추가하지 않는다.
- FTL 완료와 중심부 접촉이 같은 시각인 경우 이벤트 순서를 명시하고, 큰 프레임 간격에서도 먼저 일어난 결과를 보존한다.
- 후속 인양의 대상·역할 선박·사거리·속도·추력·자원·나포 상태·FTL 동반 이동은 별도 기획이다. 견인 중 충돌·중심부 접촉도 면역이 아니다.
- 초기 자동 항로에 중력 영향을 반영하되 실제 엔진 성능을 넘는 탈출을 보장하지 않는다. 수동/충전 중 함선의 위험 도달 예상은 표시한다.

| 정보 | 관측된 경계·위험도·예고만 제공. 적 영웅/재고/화물을 유출하지 않음 |
| 명령 | 자동 이동은 알려진 위험을 반영. 수동/Hold는 자동 우회로 바꾸지 않고 경고 |
| 양측 적용 | 진영별 무료 면역 없이 실제 노출·장비로 판정. AI도 자체 관측 정보 사용 |
| 피해 | 환경 사건ID와 기존 피해 경로 사용. 사격 보류가 환경 면역을 주지 않음 |
| 배속 | 같은 게임시간의 결과 일치. UI/프리뷰가 같은 효과를 다시 실행하지 않음 |
| 중첩 | 같은 종류의 지속 효과는 가장 강한1개, 다른 종류는 각각 적용. 감속 등 합성 상한은 후속 수치화 |
| 경계 | 환경별 중심/반경/부분 노출 정의. 경계 왕복의 알림/효과 깜박임 방지 |
| 이탈 | 임시 보정만 해제. 실제 HP·쉴드·쿨타임·소모품·부상은 유지 |
| 반복 사건 | 파동 중복 명중 방지. 지속 노출은 시간×강도로 적분 |

안전 우회·엄폐·대기·장비 준비 등 대응 수단을 제공한다. 중심부 완파 위험은 사전 경계와 경고로 읽을 수 있어야 한다. 위험 지역의 자원/항로 이득을 별도 설계하되 모든 고급 자원을 한 위험 유형에만 잠그지 않는다. 기지/전초 건설 가능 구역·환경 방호는 후속 결정이다.

## 7. 남은 수치와 검증

[R36](../../00_overview/OPEN_QUESTIONS.md#r36)은 미채택 효과 전체가 아니라 남은 정지 세부 상호작용·노출/충돌 판정·중심부 접촉·견인/방호 수치·연구·인양·기지/자원 조건을 관리한다.

검증 순서:
1. 환경 없는 기존 전투 회귀.
2. 운석1개 충돌/파괴, 통로/사선/플레어 엄폐 변경.
3. 방사능 거리·노출 부위·저항·전투 회복 상태.
4. 플레어 전체/부분 엄폐, 정지·복구, 파동ID 중복 방지.
5. 블랙홀 기동/엔진 상실/Hold/FTL·중심부 완파.
6. 강습·함재기·수리·귀환·나포와 환경의 경계.
7. 복합 환경과1/2/3배속·저FPS·경계 왕복·경고·성능.

FTL 중 중력 변위, 운석 파괴 후 경로 무효화, 파동 도중 쉴드 소실처럼 기존 모형이 표현하지 못하는 항목은 지원 후 검증한다. 기존 D116 결과는 환경 없는 입력으로 유지하며 새 환경 검증으로 이름만 바꾸지 않는다. 플레어 등의 수치 탐색을 위해 별도 환경 프로필을 작성하되 이번 기획 반영만으로 시뮬레이션/UE 완료를 주장하지 않는다.

## 8. 플레어 정지 시간의 초기 민감도 시험 — D124

[설계 모형과 결과](../../../reference/SpaceEnvironmentCalibration/README.md)에0/2/3/5/8/12초 정지, PD1/2/3/5/8/11기, 기발사 미사일3/6/12발,100시드의12초 요격 구간10,800회를 기록했다. 기본PD성능과 기존 시험 프로필을 사용한 고립 민감도 실험이며 전체 환경/함대/영웅 전투나UE 검증이 아니다.

기본 **3게임초**를 초기 시험값으로 권한다. 강한 환경은5초,8초 이상은 스트레스 조건 후보로 둔다. 이 값은 사용자 고정 상한/최종 밸런스가 아니다.100개 시드와18개 조합을 균등 가중하면 평균7발의 기발사 탄 중 추가 도달은 정지3초1.06발·5초2.01발·8초3.49발이다. 도달을 선체 명중/파괴로 환산하지 않는다. 플레어 예고·주기·파동 속도·두께·피해량은 아직 이 실험에서 조정하지 않았으며 실제 엄폐/쉴드 소모·강습 운송을 포함한 후속 모형에서 탐색한다.

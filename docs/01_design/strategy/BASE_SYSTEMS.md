# 입체 모듈형 기지 — 구조와 시설

> 2026-11-16. **사용자 확정 구조**와 **수치/운영 제안**을 구분한다. 이 문서는 본기지 모듈을 관리하며 성계/물류는 [전략·경제](STRATEGY_ECONOMY.md), 함선/무장은 각 분야 명세, 조선 비용/시간은 [초기 밸런스 초안](../../02_balance/BASE_BALANCE_DRAFT.md)을 따른다. 아직 구현된 기능이 아니다.

## 사용자 확정 구조 — D103~D108

- 중앙 코어에 규격 연결면과 연결 모듈로 시설을 붙여 XYZ 입체 확장한다. 확장한 가지끼리 다시 연결하는 순환 연결을 허용한다.
- 자원 비용·건설 시간·모듈 설치 공간과 **코어 티어별 설치 가능 모듈 수**가 기지 크기를 제한한다. 코어 업그레이드가 추가 확장에 필요하다.
- 기능 시설에는 연구소·영웅 아카데미 등이 있다. 영웅 아카데미는 초능력자·강화인간의 영입·능력 제어/신체 적응 훈련·회복과 증폭 장비를 담당한다. 비용/큐는 [영웅 명세](../boarding/HERO_SYSTEMS.md)를 따른다. 방어 모듈은 방어 무장/시설을 제공한다.
- 접안 모듈은 함선을 주차/보호한다. 외부 대기도 가능하나 접안 보호는 받지 못한다. 보호의 구체 판정은 아직 미확정이다.
- 소형/중형/대형/초대형 조선 모듈은 체급이 클수록 커진다. 상위는 하위 함체를 건조하되 **초대형 조선은 초대형1 또는 대형2만** 허용한다. 무장 교체와 내부 개조도 조선에서 수행한다.
- 대형 조선 용량은 대형1=중형2=소형4이며 **중형1+소형2 혼합 동시 건조를 허용**한다. 작업칸 환산·소형/중형 조선 세부 용량과 기타 운영 정책은 아래 제안이다.

## 시설 분류

| 분류 | 시설 | 담당 |
| --- | --- | --- |
| 지휘 | 중앙 코어 | 기지 연결/확장 한도·핵심 관리 |
| 구조 | 연결 모듈 | 시설 간 규격 연결·공간 확보·순환 경로 |
| 연구/인원 | 연구소·영웅 아카데미·인원 지원소 | 기술 연구·영웅 관련 활동·운영 승무원/분대 충원 |
| 자원/물류 | 자원 창고·물류 터미널 | 기지 재고·수송 처리 |
| 접안 | 표준/중형/대형/초대형 접안 | 주차·보호·출격 |
| 생산/개조 | 체급별 조선 모듈 | 건조·무장 교체·시설 재배치 |
| 방어 | 함포/빔·미사일·PD·레이더·방호 | 접근 억제·요격·탐지·기지 보호 |

중앙 코어 업그레이드가 함체 연구·무장 티어·조선 설비를 자동 해금/장비 교체하는 것은 아니다. 코어/연구/생산 설비가 각각 필요하다.

## 건설 운영 제안 — 아직 수치와 함께 초안

- 기능 모듈은 크기와 무관하게 한도1개를 사용한다. 중앙 코어 자체는 제외한다. 큰 모듈은 자원/시간/3D 공간 비용으로 추가 제한한다.
- 연결 모듈은 자유로운 입체/순환 배치를 위해 기능 한도에서 제외하되 별도의 구조 개수 한도를 둔다. 비용/건설 시간은 소모한다. 연결 모듈에 생산/저장/방어 기능을 숨겨 한도를 우회하지 않는다.
- 공사 시작 시 설치 공간·연결면·기능/구조 한도·자원을 예약한다. 공사 중/연결 끊긴 소유 모듈도 한도를 점유해 반복 분리로 확장 제한을 우회하지 못한다.
- 순환 연결은 하나의 자원망이며 연구/생산 효율을 경로 수만큼 중복 적용하지 않는다. 중앙 코어까지 하나의 유효 경로라도 있으면 연결이다.
- 코어 업그레이드는 같은 위치/연결면을 유지한다. 외형 확대로 주변 모듈을 밀어내지 않고 외장/내부 변화로 표현한다.
- 연결 단절 모듈은 즉시 폭발하지 않고 연결 상실 상태다. 초안은 생산/연구/자원망 사용 일시정지·완료 진행률/투자 보존. 자립 방어/접안 보호 지속 여부는 별도 결정 필요다.
- 공사 취소는 미소모 자원 반환, 소모된 자원은 손실로 제안한다. 자원은 진행률에 따라 소모하며 공사 완성 전 기능은 없다. 완성 모듈 철거 반환율은 별도 수치 조정이다.
- 전력·열·산소·복잡한 처리량 제한은 이번 초기 경제의 선행 조건으로 추가하지 않는다. 기존 선내 생명유지 규칙과 기지 경영 자원을 혼동하지 않는다.

## 조선 운영 제안

현행 중형 생산 대상은 백터급 구축함(1F)·바스티온급 구축함(2F)을 별개 설계로 취급한다. 두 함체 모두 중형 작업2칸을 쓰는 제안은 동일하지만 제작 가격/시간과 세부 선행은 각각 재산정한다.

D119에 따라 수송선은 중형 임무선이다. 중형 건조·개조는 기존 조선 체급 규칙상 중형 또는 대형 조선에서 다루고 초대형 조선의 중형 제외를 유지한다. 실제 작업칸 점유·건조 비용/시간·해금 조건은 확정하지 않았다.

표준 작업칸은 소형1/중형2/대형4다. 소형 조선1칸, 중형2칸, 대형4칸으로 제안한다. 초대형은 별도 슬롯 체계로 대형1칸/초대형2칸만 받는다. 초대형의 빈1칸에 중형/소형을 끼워 넣지 않는다.

선체가 차지한 칸은 완성·출항할 때까지 유지한다. 건조1척이 여러 칸을 차지한다고 건조시간을 나누지 않는다. 각 작업은 자기 속도로 병렬 진행하고 대기열은 아직 칸/자원을 점유하지 않는다. 조선 모듈 중복은 독립 건조 능력이며 함선 내부 중복 시설100/150/200% 규칙을 적용하지 않는다.

무장 교체/시설 개조는 해당 체급 건조와 같은 칸을 점유하도록 제안한다. 새 무장은 연구/티어/시설 조건을 충족해야 하며 탈거 장비는 창고에 보존한다. 신규 건조 표의 표준 패키지는 기본 무장/시설/승무원·기본 경비를 포함해 중복 청구하지 않고, 함재기·영웅·추가 장비는 별도다.

## 접안 운영 제안과 미정

접안 용량과 최댓값 크기를 따로 검사한다. 점수만 남는다고 큰 함선을 작은 출입구에 넣지 않는다. 주차는 생산/개조 작업칸을 사용하지 않으며 접안만으로 무료 수리/충원을 제공하지 않는다. 보호 방식은 보호막/외피 대리 피격·직접 피격 차단 중 미정이며 완전 무적으로 확정하지 않는다.

조선/접안은 모듈 본체 외에 함체 크기에 맞는 출입/발진 여유 공간까지 예약한다. 함체/에셋 크기가 바뀌면 출입 가능 여부를 다시 검증한다. 기지 코어 파괴 결과, 방호 범위/합산, 시설 피해/강습은 함선 규칙을 무조건 복사하지 않고 별도 상세화한다.

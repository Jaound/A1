# 입체 모듈형 기지 — 구조와 시설

> 2026-11-16. **사용자 확정 구조**와 **수치/운영 제안**을 구분한다. 이 문서는 본기지 모듈을 관리하며 성계/물류는 [전략·경제](STRATEGY_ECONOMY.md), 함선/무장은 각 분야 명세, 조선 비용/시간은 [초기 밸런스 초안](../../02_balance/BASE_BALANCE_DRAFT.md)을 따른다. 아직 구현된 기능이 아니다.

## 사용자 확정 구조 — D103~D108

- 중앙 코어에 규격 연결면과 연결 모듈로 시설을 붙여 XYZ 입체 확장한다. 확장한 가지끼리 다시 연결하는 순환 연결을 허용한다.
- 자원 비용·건설 시간·모듈 설치 공간과 **코어 티어별 설치 가능 모듈 수**가 기지 크기를 제한한다. 코어 업그레이드가 추가 확장에 필요하다.
- 기능 시설에는 연구소·영웅 아카데미 등이 있다. 영웅 아카데미는 초능력자·강화인간의 영입·능력 제어/신체 적응 훈련·회복과 증폭 장비를 담당한다. 비용/큐는 [영웅 명세](../boarding/HERO_SYSTEMS.md)를 따른다. 방어 모듈은 방어 무장/시설을 제공한다.
- 접안 모듈은 함선을 주차/보호한다. 외부 대기도 가능하나 접안 보호는 받지 못한다. 보호의 구체 판정은 아직 미확정이다.
- 소형/중형/대형/초대형 조선 모듈은 체급이 클수록 커진다. 상위는 하위 함체를 건조하되 **초대형 조선은 초대형1 또는 대형2만** 허용한다. 무장 교체와 내부 개조도 조선에서 수행한다.
- 대형 조선 용량은 대형1=중형2=소형4이며 **중형1+소형2 혼합 동시 건조를 허용**한다. 작업칸 환산·소형/중형 조선 세부 용량과 기타 운영 정책은 아래 제안이다.

## 건설 운영 제안 — 아직 수치와 함께 초안

- 기능 모듈은 크기와 무관하게 한도1개를 사용한다. 중앙 코어 자체는 제외한다. 큰 모듈은 자원/시간/3D 공간 비용으로 추가 제한한다.
- 연결 모듈은 자유로운 입체/순환 배치를 위해 기능 한도에서 제외하되 별도의 구조 개수 한도를 둔다. 비용/건설 시간은 소모한다. 연결 모듈에 생산/저장/방어 기능을 숨겨 한도를 우회하지 않는다.
- 공사 시작 시 설치 공간·연결면·기능/구조 한도·자원을 예약한다. 공사 중/연결 끊긴 소유 모듈도 한도를 점유해 반복 분리로 확장 제한을 우회하지 못한다.
- 순환 연결은 하나의 자원망이며 연구/생산 효율을 경로 수만큼 중복 적용하지 않는다. 중앙 코어까지 하나의 유효 경로라도 있으면 연결이다.
- 코어 업그레이드는 같은 위치/연결면을 유지한다. 외형 확대로 주변 모듈을 밀어내지 않고 외장/내부 변화로 표현한다.
- 연결 단절 모듈은 즉시 폭발하지 않고 연결 상실 상태다. 초안은 생산/연구/자원망 사용 일시정지·완료 진행률/투자 보존. 자립 방어/접안 보호 지속 여부는 별도 결정 필요다.
- 공사 취소는 미소모 자원 반환, 소모된 자원은 손실로 제안한다. 자원은 진행률에 따라 소모하며 공사 완성 전 기능은 없다. 완성 모듈 철거 반환율은 별도 수치 조정이다.
- 전력·열·산소·복잡한 처리량 제한은 이번 초기 경제의 선행 조건으로 추가하지 않는다. 기존 선내 생명유지 규칙과 기지 경영 자원을 혼동하지 않는다.

## 조선 운영 제안

현행 중형 생산 대상은 백터급 구축함(1F)·바스티온급 구축함(2F)을 별개 설계로 취급한다. 두 함체 모두 중형 작업2칸을 쓰는 제안은 동일하지만 제작 가격/시간과 세부 선행은 각각 재산정한다.

D119에 따라 수송선은 중형 임무선이다. 중형 건조·개조는 기존 조선 체급 규칙상 중형 또는 대형 조선에서 다루고 초대형 조선의 중형 제외를 유지한다. 실제 작업칸 점유·건조 비용/시간·해금 조건은 확정하지 않았다.

표준 작업칸은 소형1/중형2/대형4다. 소형 조선1칸, 중형2칸, 대형4칸으로 제안한다. 초대형은 별도 슬롯 체계로 대형1칸/초대형2칸만 받는다. 초대형의 빈1칸에 중형/소형을 끼워 넣지 않는다.

선체가 차지한 칸은 완성·출항할 때까지 유지한다. 건조1척이 여러 칸을 차지한다고 건조시간을 나누지 않는다. 각 작업은 자기 속도로 병렬 진행하고 대기열은 아직 칸/자원을 점유하지 않는다. 조선 모듈 중복은 독립 건조 능력이며 함선 내부 중복 시설100/150/200% 규칙을 적용하지 않는다.

무장 교체/시설 개조는 해당 체급 건조와 같은 칸을 점유하도록 제안한다. 새 무장은 연구/티어/시설 조건을 충족해야 하며 탈거 장비는 창고에 보존한다. 신규 건조 표의 표준 패키지는 기본 무장/시설/승무원·기본 경비를 포함해 중복 청구하지 않고, 함재기·영웅·추가 장비는 별도다.

## 접안 운영 제안과 미정

접안 용량과 최댓값 크기를 따로 검사한다. 점수만 남는다고 큰 함선을 작은 출입구에 넣지 않는다. 주차는 생산/개조 작업칸을 사용하지 않으며 접안만으로 무료 수리/충원을 제공하지 않는다. 보호 방식은 보호막/외피 대리 피격·직접 피격 차단 중 미정이며 완전 무적으로 확정하지 않는다.

조선/접안은 모듈 본체 외에 함체 크기에 맞는 출입/발진 여유 공간까지 예약한다. 함체/에셋 크기가 바뀌면 출입 가능 여부를 다시 검증한다. 기지 코어 파괴 결과, 방호 범위/합산, 시설 피해/강습은 함선 규칙을 무조건 복사하지 않고 별도 상세화한다.

## 기지 규격 · 운영 정책 · 방안 A(25m 격자 정규화) 최종 확정안

- **기준 격자 정규화 (방안 A 확정)**: 정수 격자 비율(`5×5×5`, `10×7×6`, `12×8×7`)은 유지하고 1칸 단위를 **25m (2500cm, UE 5.8 Z-Up)**로 정규화하여 인게임 함선 실측(`OVCalibration`)·무기 사거리(700~1,500m)·쉴드 반경과 정합합니다.
- **중앙 코어 및 통로 규격**: 중앙 코어 `5×5×5` (125×125×125m · 홀수 중앙 정렬) / 일자형 연결 통로 `1×1×1` (25m · 동시 건설 슬롯 제외, 15초 건설 유지로 파괴 리스크 보존) / 연결 분기 허브 `1×1×1`.
- **3중 다층 방어 쉴드 체계**: 시설 기본 체력·장갑 내구도 상향 + 코어 기본 반경 **500m** 쉴드 + 기지 방호 모듈 반경 **450m** 쉴드 + 접안 모듈 **자체 개별 쉴드** 보호.
- **통합 방어 플랫폼 (±Z 상하 반전 허용)**: 함포·빔·PD·미사일을 공용 기지 방어 모듈(`2×2×2 · 50m`)의 로컬 큐에 선택 장착하며, 3D 하부 사각지대 대응을 위해 `-Z` 반전 설치를 허용합니다.
- **해금 단계 통일 및 창고/업그레이드 규칙**: 영웅 아카데미·심우주 레이더는 코어 II로 통일, 자원 창고는 1→2→3단계 **개별 업그레이드(최종 22k, 최소 2동 필수)**, 제자리 상위 업그레이드는 **소형→중형→대형까지만** 허용(초대형은 별도 신축), 해체 환급 **75%**.
- **연동 통합 문서**: `docs/01_design/strategy/BASE_MASTER_GDD.md`, `docs/02_balance/BASE_BALANCE_DRAFT.md`, `docs/01_design/base/MODULAR_BASE_3D_ARCHITECTURE.md`

### 확정 구조 요약 (D103~D108)

- **D103. XYZ 입체 확장 및 순환 연결 허용**: 중앙 코어(5×5×5 · 홀수 중앙 정렬)의 정중앙 규격 연결면에서 일자형 연결 통로(1×1×1)와 연결 분기 허브(1×1×1)를 통해 X·Y·Z 3축으로 시설을 확장하며, 뻗어나간 가지끼리 다시 잇는 순환 연결(링 구조)을 허용합니다.
- **D104. 코어 티어별 설치 한도 및 3중 성장 제약**: 기지 크기는 자원 비용, 건설 시간, 3D 설치 공간, 그리고 코어 티어(I~IV)별 기능/연결 모듈 설치 한도로 제한됩니다.
- **D105. 기능 시설 분업 · 통합 방어 플랫폼(±Z) · 다층 쉴드 체계**: 기술 연구는 전략 연구소, 영웅 영입·훈련은 영웅 아카데미(코어 II), 무장 방어는 단일 기지 방어 모듈(±Z 상하 반전 설치) 로컬 큐에 함포·빔·PD·미사일을 선택 장착합니다. 기지 코어는 기본 반경 500m 쉴드를, 외곽은 기지 방호 모듈(반경 450m)이, 접안 모듈은 자체 개별 쉴드가 방어합니다.
- **D106. 체급 비례 조선 모듈 · 제자리 업그레이드 한계(S→M→L)**: 소형/중형/대형/초대형 조선소는 체급이 올라갈수록 본체 격자와 출입 여유가 크게 증가합니다. 제자리 상위 업그레이드는 소형→중형→대형까지만 지원하며 초대형 조선소/접안은 별도 신축해야 합니다.
- **D107. 대형 조선소 1 = 2 = 4 혼합 동시 건조**: 대형 조선소 표준 용량은 대형 1 = 중형 2 = 소형 4이며, 중형 1척 + 소형 2척 같은 혼합 동시 건조를 허용합니다.
- **D108. 접안 모듈 자체 쉴드 보호 · 초대형 32점 고유 혜택**: 접안 모듈 4종은 개별 자체 쉴드를 보유해 높은 방어력으로 함선을 주차·보호합니다. 초대형 접안 모듈은 32점(최대 초대형 4척)과 수리 속도 +30% · 고속 긴급 출격 · 전용 쉴드 충전 혜택을 제공합니다.

### 건설 · 연결 · 쉴드 · 운영 확정 정책

- **[확정 · 건설·한도] 기능 모듈 1개당 한도 1점 (크기 무관)**: 중앙 코어 자체는 한도에서 제외하며, 모든 기능 모듈은 크기와 무관하게 기능 한도 1개를 사용합니다. 영웅 아카데미와 기지 레이더는 코어 II 해금으로 통일합니다.
- **[확정 · 건설·한도] 연결 통로(1×1×1) 동시 건설 한도 제외 · 15초 건설 시간 유지**: 일자형 통로(1×1×1)와 분기 허브(1×1×1)는 별도 연결 한도(24/48/84/132)를 사용하며 기지 동시 건설 슬롯(1~4건)을 점유하지 않습니다. 단 피격으로 통로가 파괴됐을 때 단절 리스크를 살리기 위해 5초 즉시 연장은 채택하지 않고 15초 건설 시간을 유지합니다.
- **[확정 · 건설·한도] 자원 창고 1~3단계 개별 업그레이드 (최종 22k · 최소 2동 필수)**: 자원 창고는 1단계(6k) → 2단계(12k) → 3단계(22k)로 성장합니다. 창고 업그레이드 연구 완료 시 자동 일괄 적용되지 않으며 각 창고 모듈을 개별 업그레이드해야 합니다. 코어 IV(28k/6k/800) 및 초대형 함체(32k) 비축을 위해 최소 2동 이상 건설이 필요합니다.
- **[확정 · 건설·한도] 철거 75% 환불 · 제자리 업그레이드(소형→중형→대형)**: 완성 모듈 철거 시 자원의 75%를 반환합니다(공사 취소 100%, 건조·접안 작업 중 철거 금지). 제자리 상위 업그레이드는 소형→중형→대형까지만 지원하며, 대형→초대형은 미지원(별도 신축 필수)입니다.
- **[확정 · 연결·단절] 순환 연결 단일 자원망 · 단절 시 일시정지 및 방어 60초 비상 가동**: 코어까지 유효 경로가 하나라도 있으면 정상 연결입니다. 단절 시 즉시 파괴되지 않고 생산·연구·자원망만 일시정지되며, 단절된 기지 방어 모듈은 보급·수리가 중단된 채 비상 전력으로 60초간 자립 사격 후 정지합니다.
- **[확정 · 방어·쉴드] 기지 방어 모듈 상·하 반전(±Z) · 상부 포탑 로컬 장착 큐**: 기지 방어 모듈은 3D 하부 사각지대 대응을 위해 상·하 반전(-Z) 설치를 허용합니다. 본체(90초)만 기지 동시 건설 슬롯을 사용하며, 함포·빔·PD·미사일 장착 및 교체는 방어 모듈 자체 로컬 큐로 처리(기존 포탑 창고 보관 또는 50% 환불)합니다.
- **[확정 · 방어·쉴드] 고내구 시설 + 코어 500m / 방호 450m / 접안 자체 쉴드 3중 방어**: 기지 시설은 기본적으로 높은 체력·장갑 내구도를 가지며, 기지 코어가 기본 반경 500m 쉴드를 제공합니다. 코어 반경 밖은 기지 방호 모듈(반경 450m, 3D 반투명 돔 미리보기)로 보호하며, 접안 모듈은 별도의 개별 자체 쉴드를 보유합니다.
- **[확정 · 방어·쉴드] 기지 코어 파괴 시 전초기지 임시 이관 (복구 미션)**: 본기지 중앙 코어가 파괴되더라도 보유 전초기지가 존재하면 지휘 기능을 임시 이관하여 본기지 복구 미션으로 이어가며, 잔여 전초기지가 없을 때 패배 처리합니다.
- **[확정 · 조선·접안] 전방 출입 여유(2~5칸 · 50~125m) + 기지 외곽 개방선(Open Exit Ray) 검증**: 1칸 25m 격자 기준으로 조선소·접안 모듈은 전방 출입 여유(소형 2칸 50m · 중형 3칸 75m · 대형 4칸 100m · 초대형 5칸 125m)뿐 아니라 그 너머 기지 외곽 바운딩 박스까지 가로막지 않는 개방선(Open Exit Ray)을 확보해야 합니다.
- **[확정 · 조선·접안] 접안 자체 쉴드 대리 피격 · 도크 완파 시 강제 비상 출격**: 접안 중인 함선은 외부 공격에 직접 피격되지 않고 접안 모듈의 자체 쉴드·장갑이 대리 피격합니다. 도크가 완파되면 내부 함선은 즉시 강제 비상 출격해 동반 침몰을 방지합니다.

### 3D 에셋 · 하이브리드 이미지 마킹 소켓 계약

- **01. 방안 A 확정: 25m 가변 격자 + 규격 소켓 · 2m 도킹 칼라 버퍼**: 기지 1칸 격자를 25m(2,500cm)로 정규화해 UE 5.8 실제 함선·무기 사거리(700~1,500m)·코어 쉴드(500m)와 비율을 맞추고, 연결면은 표준 Socket_*과 2m 도킹 칼라 버퍼로 오차 5cm 이내 정합을 보장합니다.
- **02. 폐쇄형 vs 개방형(접안 · 조선소) 모듈 분할 제작 전략**: 개방형 모듈은 단일 통메쉬로 뽑지 말고, (1) 후방 관제·기계 본체(폐쇄형), (2) 좌우 도크 갠트리 암/프레임(대칭 파츠), (3) 상·하부 지지 크레인/포털 아치로 분할 생성한 뒤 UE 5.8 Blueprint 또는 Blender에서 내부 베이 공간을 비워 조립합니다.
- **03. 일자형 연결 통로 (1×1×1 · 25m) 회귀 및 3D 배치 UX 규약**: 일자형 연결 통로를 1×1×1(25m)로 정규화하고 동시 건설 슬롯에서 제외하되(15초 유지), 기본 배치는 Z=0 수평 자동 스냅 + 통로 자동 배선 + Q/E 회전 + PageUp/PageDown ±25m 층 이동 + 녹색/빨강/시안(쉴드 반경) 시각 피드백으로 제어합니다.
- **04. 이미지 기반 커스텀 소켓 마킹 + 하이브리드 격자 어댑터 계약**: 각 모델링 이미지(탑뷰 + 측면)에 통로 연결 가능 지점을 직접 마킹하되, (1) 바닥 기준 통로 높이(Deck Z) 1개만 통일하고 (2) 마킹된 포트와 가장 가까운 정수 격자 소켓 사이의 잔여 오차(±2~5m)는 UE 5.8 신축 도킹 칼라가 자동 보정합니다.

## 1. 사용자 확정 구조 (D103~D108)

- **D103. XYZ 입체 확장 및 순환 연결 허용**: 중앙 코어(5×5×5 · 홀수 중앙 정렬)의 정중앙 규격 연결면에서 일자형 연결 통로(1×1×1)와 연결 분기 허브(1×1×1)를 통해 X·Y·Z 3축으로 시설을 확장하며, 뻗어나간 가지끼리 다시 잇는 순환 연결(링 구조)을 허용합니다. _(홀수 격자 중앙 정렬로 모든 축의 연결 통로가 정중앙에 대칭 결합되며, 단일 가지가 파괴되어도 다른 우회 경로가 살아 있으면 코어 연결이 유지됩니다.)_
- **D104. 코어 티어별 설치 한도 및 3중 성장 제약**: 기지 크기는 자원 비용, 건설 시간, 3D 설치 공간, 그리고 코어 티어(I~IV)별 기능/연결 모듈 설치 한도로 제한됩니다. _(코어 업그레이드는 외형 확대로 주변 모듈을 밀어내지 않고 제자리(5×5×5)를 유지한 채 한도와 접근 등급만 확장합니다.)_
- **D105. 기능 시설 분업 · 통합 방어 플랫폼(±Z) · 다층 쉴드 체계**: 기술 연구는 전략 연구소, 영웅 영입·훈련은 영웅 아카데미(코어 II), 무장 방어는 단일 기지 방어 모듈(±Z 상하 반전 설치) 로컬 큐에 함포·빔·PD·미사일을 선택 장착합니다. 기지 코어는 기본 반경 500m 쉴드를, 외곽은 기지 방호 모듈(반경 450m)이, 접안 모듈은 자체 개별 쉴드가 방어합니다. _(시설 기본 체력·장갑 내구도를 높게 유지하면서도 코어(500m)·방호(450m)·접안 자체 쉴드의 3중 방어선이 배치에 따라 보호 범위가 달라집니다.)_
- **D106. 체급 비례 조선 모듈 · 제자리 업그레이드 한계(S→M→L)**: 소형/중형/대형/초대형 조선소는 체급이 올라갈수록 본체 격자와 출입 여유가 크게 증가합니다. 제자리 상위 업그레이드는 소형→중형→대형까지만 지원하며 초대형 조선소/접안은 별도 신축해야 합니다. _(초대형 조선소는 초대형 1척 또는 대형 2척 전용이며, 소형·중형 함체 끼워넣기를 금지합니다.)_
- **D107. 대형 조선소 1 = 2 = 4 혼합 동시 건조**: 대형 조선소 표준 용량은 대형 1 = 중형 2 = 소형 4이며, 중형 1척 + 소형 2척 같은 혼합 동시 건조를 허용합니다. _(건조 시간은 함선 1척 고유의 속도로 병렬 진행되며 여러 칸을 차지한다고 건조 시간이 단축되지 않습니다.)_
- **D108. 접안 모듈 자체 쉴드 보호 · 초대형 32점 고유 혜택**: 접안 모듈 4종은 개별 자체 쉴드를 보유해 높은 방어력으로 함선을 주차·보호합니다. 초대형 접안 모듈은 32점(최대 초대형 4척)과 수리 속도 +30% · 고속 긴급 출격 · 전용 쉴드 충전 혜택을 제공합니다. _(접안 중 함선은 외부 직접 피격을 받지 않으며 도크가 완파되더라도 강제 비상 출격으로 억울한 동반 침몰을 방지합니다.)_

## 2. 건설 · 연결 · 방어 쉴드 · 운영 확정 정책

- **[확정 · 건설·한도] 기능 모듈 1개당 한도 1점 (크기 무관)**: 중앙 코어 자체는 한도에서 제외하며, 모든 기능 모듈은 크기와 무관하게 기능 한도 1개를 사용합니다. 영웅 아카데미와 기지 레이더는 코어 II 해금으로 통일합니다.
- **[확정 · 건설·한도] 연결 통로(1×1×1) 동시 건설 한도 제외 · 15초 건설 시간 유지**: 일자형 통로(1×1×1)와 분기 허브(1×1×1)는 별도 연결 한도(24/48/84/132)를 사용하며 기지 동시 건설 슬롯(1~4건)을 점유하지 않습니다. 단 피격으로 통로가 파괴됐을 때 단절 리스크를 살리기 위해 5초 즉시 연장은 채택하지 않고 15초 건설 시간을 유지합니다.
- **[확정 · 건설·한도] 자원 창고 1~3단계 개별 업그레이드 (최종 22k · 최소 2동 필요)**: 자원 창고는 1단계(6k) → 2단계(12k) → 3단계(22k)로 성장합니다. 창고 업그레이드 연구 완료 시 자동 일괄 적용되지 않으며 각 창고 모듈을 개별 업그레이드해야 합니다. 코어 IV(28k/6k/800) 및 초대형 함체(32k) 비축을 위해 최소 2동 이상 건설이 필요합니다.
- **[확정 · 건설·한도] 철거 75% 환불 · 제자리 업그레이드(소형→중형→대형)**: 완성 모듈 철거 시 자원의 75%를 반환합니다(공사 취소 100%, 건조·접안 작업 중 철거 금지). 제자리 상위 업그레이드는 소형→중형→대형까지만 지원하며, 대형→초대형은 미지원(별도 신축 필수)입니다.
- **[확정 · 연결·단절] 순환 연결 단일 자원망 · 단절 시 일시정지 및 방어 60초 비상 가동**: 코어까지 유효 경로가 하나라도 있으면 정상 연결입니다. 단절 시 즉시 파괴되지 않고 생산·연구·자원망만 일시정지되며, 단절된 기지 방어 모듈은 보급·수리가 중단된 채 비상 전력으로 60초간 자립 사격 후 정지합니다.
- **[확정 · 방어·쉴드] 기지 방어 모듈 상·하 반전(±Z) · 상부 포탑 로컬 장착 큐**: 기지 방어 모듈은 3D 하부 사각지대 대응을 위해 상·하 반전(-Z) 설치를 허용합니다. 본체(90초)만 기지 동시 건설 슬롯을 사용하며, 함포·빔·PD·미사일 장착 및 교체는 방어 모듈 자체 로컬 큐로 처리(기존 포탑 창고 보관 또는 50% 환불)합니다.
- **[확정 · 방어·쉴드] 고내구 시설 + 코어 500m / 방호 450m / 접안 자체 쉴드 3중 방어**: 기지 시설은 기본적으로 높은 체력·장갑 내구도를 가지며, 기지 코어가 기본 반경 500m 쉴드를 제공합니다. 코어 반경 밖은 기지 방호 모듈(반경 450m, 3D 반투명 돔 미리보기)로 보호하며, 접안 모듈은 별도의 개별 자체 쉴드를 보유합니다.
- **[확정 · 방어·쉴드] 기지 코어 파괴 시 전초기지 임시 이관 (복구 미션)**: 본기지 중앙 코어가 파괴되더라도 보유 전초기지가 존재하면 지휘 기능을 임시 이관하여 본기지 복구 미션으로 이어가며, 잔여 전초기지가 없을 때 패배 처리합니다.
- **[확정 · 조선·접안] 전방 출입 여유(2~5칸 · 50~125m) + 기지 외곽 개방선(Open Exit Ray) 검증**: 1칸 25m 격자 기준으로 조선소·접안 모듈은 전방 출입 여유(소형 2칸 50m · 중형 3칸 75m · 대형 4칸 100m · 초대형 5칸 125m)뿐 아니라 그 너머 기지 외곽 바운딩 박스까지 가로막지 않는 개방선(Open Exit Ray)을 확보해야 합니다.
- **[확정 · 조선·접안] 접안 자체 쉴드 대리 피격 · 도크 완파 시 강제 비상 출격**: 접안 중인 함선은 외부 공격에 직접 피격되지 않고 접안 모듈의 자체 쉴드·장갑이 대리 피격합니다. 도크가 완파되면 내부 함선은 즉시 강제 비상 출격해 동반 침몰을 방지합니다.

### 04. 이미지 기반 커스텀 소켓 마킹 + 하이브리드 격자 어댑터 계약
- **과제**: 모델링마다 통로 연결 포트 위치가 서로 달라 단순 규칙만 적용하면 에셋 교체 시 어긋나고, 반대로 격자를 무시한 임의 좌표만 쓰면 순환 링(D103)이 닫히지 않습니다.
- **해법**: 각 모델링 이미지(탑뷰 + 측면)에 통로 연결 가능 지점을 직접 마킹하되, (1) 바닥 기준 통로 높이(Deck Z) 1개만 통일하고 (2) 마킹된 포트와 가장 가까운 정수 격자 소켓 사이의 잔여 오차는 2m 도킹 칼라로 수용 가능한 경우에만 에셋 어댑터에서 처리합니다. 범위를 초과하면 어댑터 또는 메시를 수정합니다.
  - 필수 2컷: 탑뷰(수평 마킹 위치) + 측면/아이소(공통 통로 높이 Deck Z 확인)
  - 색상 규약: 빨강 = 통로 연결 허용 포트 · 초록 = 함선 출입 개방 면 (외곽 개방선 보장)
  - 링 결합 기준: 모듈 외형·포트 위치는 이미지 마킹대로 유지하고 통로망은 1×1×1 정수 격자 스냅 유지

### 05. 돌출형 연결구 맞대기

사용자 예시 이미지의 돌출된 팔각형 연결구가 실제 접합부다. 모듈과 통로 또는 서로 호환되는 모듈은 연결구의 노출된 앞면을 서로 마주 보게 맞댄다.

- 연결 소켓은 돌출부가 끝나는 앞면의 중심에 둔다. 소켓의 바깥 방향은 해당 접합면의 법선으로 기록한다.
- 접합 시 두 면의 중심을 맞추고, 바깥 방향이 서로 반대가 되도록 회전한다. 입구 테두리와 상하 방향이 맞는지도 확인한다.
- 이미지에 표시가 필요한 경우 연결구마다 P1, P2처럼 번호를 붙여 같은 위치를 가리킨다. 실제 모델에서 접합면 중심과 방향을 확인한 뒤 25m 논리 격자의 해당 포트와 연결한다.
- 원본 모델을 반입한 뒤 테두리 간격, 메시 겹침, 통로 개구부의 정렬을 확인한다. 크기가 다른 연결구의 호환 여부와 어댑터 규격은 모델을 대조해 정한다.

# 모함·격납고·함재기 운용

> 현행 명세: 2026-11-16. 수용량·소유량·관제·나포 귀속을 관리한다. PD는 [함대](FLEET_COMBAT.md), 시설 HP는 [함선](SHIP_SYSTEMS.md), 포드 운송은 [선내 작전](../boarding/BOARDING_COMBAT.md)이 담당한다.

## 격납고와 수용량

- 보관소/출격소를 통합한 `격납고`를 사용한다. 소형 함체에는 설치하지 않으며 대형 이상 설치를 권장한다. 중형의 설치 허용 범위는 R15.
- **격납고 시설 1개당 소형함(1층) 1척 또는 함재기 최대20대**를 선택 보관한다. 1개 시설에 두 용량을 동시에 더하지 않는다. 여러 격납고가 있으면 격납고별로 용도를 배분한다. 함재기 탑재에는 별도 `함재기 운용 시설`이 필요하다.
- 일반 대형/초대형함은 수납 소형함 최대 5척이다. 항공모함은 해당 일반 제한 없이 격납고를 다수 설치할 수 있다. 무한 공간을 뜻하지 않으며 실제 슬롯/시설 수용량이 필요하다.
- **함재기 총 용량은 함재기용 격납고 수×20대**다. 5개라면100대지만, 최종 티어 항모의 최대 설치수가5개라는 점은 아직 확정하지 않는다. 사용자 추정의 확인 결과는 [원형 조사](../../../reference/PlayGame3Hangar/README.md)에 있다. 기존 전체100대 제한은 기본 규칙으로 사용하지 않는다(R15).
- 격납고 소형함은 보관 중 자체 수리한다. 비용/속도는 미정이다. 출격 후 재수납 쿨타임·도킹 대기 시간이 있으며 수치는 미정이다.

## 소유량과 전투 상태

같은 기체는 보관/출격/귀환/도킹 대기/관제 상실/완파 중 하나의 상태를 가진다. 출격은 **보관 수→출격 수 이동**이며 총 보유량 차감이 아니다. 완파만 영구 손실이다. 귀환/수리로 새 개체를 생성하지 않는다.

함재기는 플레이어가 개별 비행 조종하지 않고 AI가 교전한다. 일반 무장은 함재기를 표적 선정하지 않으며 PD와 적 함재기가 상대한다. 기체별 반경·고도·선회 방향과 돌입→이탈→재돌입 궤적으로 동일 원 궤도의 기차 행렬을 피한다.

## 출격·귀환·관제 상실

- 교전 시 가용 함재기 일제 출격. 부채꼴 등 분산 배치로 겹침을 피한다.
- **전투 중 정기 귀환·탄약 고갈·출격 지속 시간에 의한 강제 귀환을 요구하지 않는다.** 모함의 명시적 복귀 명령으로 함재기를 귀환시켜 수리할 수 있다. 기존 비전투5초 자동 귀환/재무장 의무는 이번 정책으로 대체하고 기본 자동 귀환 조건으로 사용하지 않는다. 무장 공급은 실시간 생산이며 수리 비용/시간·재출격 절차는 R23/R25다.
- 모함 FTL 충전 시 긴급 귀환 명령을 내린다. 기본 도약은 회수 완료를 기다리며, **잔여 기체 포기 후 도약**을 명시적으로 선택하면 충전 완료 후 미귀환 기체를 남기고 이탈한다. 남은 기체의 모함/관제 상실 처리는 별도 적용하며 포기 선택만으로 모두 완파/재생성하지 않는다.

| 사건 | 내부 보관 기체 | 외부 기체 |
| --- | --- | --- |
| 격납고 마비 | 보관 유지·출격 잠금 | 재수납 불가 |
| 격납고 파괴 | 해당 격납고 소형함/함재기 완파 | 소형함 정상. 함재기는 관제 시설이 살아 있으면 교전 지속, 해당 격납고 귀환/수리/재무장 불가 |
| 함재기 운용 시설 전부 가동 불가 | 함재기 신규 출격 불가 | 함재기 관제 상실로 정지, 시설 복구 시 재가동 |
| 모함 완파 | 내부 전부 완파 | 외부 함재기 정지. 외부 독립 소형함은 모함 내부 완파 규칙을 적용하지 않음 |

다중 격납고 대체 귀환·관제 상실 표류·회수 및 FTL 이탈 처리 상세는 R25다.

## 나포 시 소속과 가동 조건

함교 나포가 결정되면 모함과 관련 소유물은 다음과 같이 처리한다. 소속 변경과 수리/관제 복구를 혼동하지 않는다.

| 대상 | 결과 |
| --- | --- |
| 외부 출격 함재기 | 즉시 새 모함 세력으로 전환, 모함 관제를 따름. 고장난 관제/기체는 자동 복구하지 않음 |
| 내부 보급수리함·채굴선·함재기·자원 | 즉시 새 소유 측 귀속, 정상 가동 조건을 충족하면 사용 가능 |
| 내부 초계함·호위함 등 소형 전투함 | 무장해제된 중립 노획 상태. 보급수리함 승무원 주입 또는 전투 후 기지 회수로 정식 편입 |
| 선내 영웅·일반 경비/강습 병력 | 소속 유지, 재탈환·탈출 가능 |
| 선내 보안 터렛·로봇 | 긴 재부팅 후 새 세력 소속 |

독립 출격 소형함의 나포 연동 소속 전환은 위 외부 함재기 규칙으로 확대하지 않는다. 상세 미정은 R18이다.

## 시험 수치의 지위

함재기 hull 160/shield 75, 이탈 반경 55~85m, 긴급 귀환 속도 1.5배는 프로토타입 참조값이다. 회피 0.62와 확정된 곱셈 PD 관계는 R09, 실제 절대 스탯·티어/개조·정비 효율은 R16/R23에서 관리한다. [과거 개선 기록](../../05_references/PROTOTYPE_IMPROVEMENT_PLAN.md)이 현행 소유량 규칙을 덮어쓰지 않는다.

# 모함·격납고·함재기 운용

> 현행 명세: 2026-11-21. 수용량·소유량·관제·나포 귀속을 관리한다. PD는 [함대](FLEET_COMBAT.md), 시설 HP는 [함선](SHIP_SYSTEMS.md), 포드 운송은 [선내 작전](../boarding/BOARDING_COMBAT.md)이 담당한다.

## 함재기와 전장 보충 (2026-11-23)

- 기본 기체는 선체 220, 쉴드 60, 회피 60%, 발당 피해 19, 최소 발사 간격 1.2초다. 대함 기준 사거리는 100m다. 큰 목표는 중심 거리 판정에 함체 반경 절반을 더한다. 이는 명중 보장이 아니며 발사된 탄은 실제 경로로 충돌한다.
- 항모의 가동 중인 함재기용 격납고는 정원에 결원이 생기면 각각 7게임초에 새 기체 1대를 보관한다. 인원 50%면 14초다. 출격·귀환·착함 대기·관제 상실 중인 기체도 살아 있는 재고다. 새 기체마다 가동 중인 자원 적재실에서 일반 35, 고급 5를 차감한다. 최고급은 사용하지 않는다.
- 시험 편제의 기본 보충 화물은 설치 격납고당 25대분이다. 임무가 초기 적재량을 지정할 수 있다. 4격납고·100대분의 예에서는 80대를 싣고 출발하고 기존 화물로 최대 100대를 추가 생산한다. 격납고 파괴 시 해당 생산 라인과 20자리, 유일한 적재실 파괴 시 남은 화물을 잃는다.
- 플레이어의 **함재기 출격** 명령은 가동 중인 격납고의 대기 기체를 함께 보낸다. **자동 출격**은 적 표적이 있고 출격 가능한 대기 기체가 가동 정원을 채웠거나 다음 1대분의 재료가 부족할 때만 출격한다. 적 항모도 같은 집결 기준을 따른다. **항공 보급**은 근처 아군 보급수리함의 실제 재고와 모함 빈 용적 안에서 완성 가능한 기체분을 인계한다. 복귀한 기체는 기존 손상을 보존한다.

## 격납고와 수용량

- 보관소/출격소를 통합한 `격납고`를 사용한다. 대형·초대형 함체만 설치할 수 있다. 소형·중형에는 설치할 수 없다(D126).
- **격납고 시설 1개당 소형함(1층) 1척 또는 함재기 기본20대**를 선택 보관한다. 1개 시설에 두 용량을 동시에 더하지 않는다. 여러 격납고가 있으면 격납고별로 용도를 배분한다. 함재기 탑재에는 별도 `함재기 운용 시설`이 필요하다.
- **함체별 격납고 설치 상한(D126): 항공순양함6 / 항공모함4 / 구축전함4 / 전함2 / 전략 미사일함1개.** 실제 설치 수는 시설 커스터마이징으로 선택하며 기본 패키지·기체 지급량과 다르다. 함재기 운용 시설 설치와 함재기 운용은 항공모함·항공순양함만 허용한다. 구축전함·전함·전략 미사일함의 격납고는 소형함 전용이다.
- 항공순양함 외형에서는 설치하지 않은 격납고 위치의 문을 닫아 둔 상태로 표현한다(D120). 문짝의 정확한 위치·개수 배분·개폐 동작과 설치한 격납고의 대기 중 문 상태는 모델링/구현에서 별도 결정한다. 닫힌 문만으로 시설의 설치 여부를 판정하지 않는다.
- 소형함 수용량은 소형함용으로 실제 설치한 격납고 수와 같다. 종전 공통 최대5척·항모 예외 대신 D126의 함체별 격납고 상한을 적용한다.
- **기본 함재기 용량은 함재기용 격납고 수×20대**다. D116의 격납 효율 연구는 각 함재기용 격납고에 추가 공간을 제공한다. 시험안은 단계당+2대·3단계로 최종26대/격납고다. 소형함1척 용량은 증가시키지 않는다. 일반 항공모함은 최대4개를 모두 함재기용으로 설치했을 때 기본80대 공간이며 항공순양함은 최대6개·기본120대 공간이다. 과거5개/100대 가정은 현행 항모 상한으로 사용하지 않는다. 사용자 추정의 확인 결과는 [원형 조사](../../../reference/PlayGame3Hangar/README.md)에 있다. 기존 전체100대 제한은 기본 규칙으로 사용하지 않는다(R15).
- 격납고 소형함은 보관 중 자체 수리한다. 비용/속도는 미정이다. 출격 후 재수납 쿨타임·도킹 대기 시간이 있으며 수치는 미정이다.

## 함재기 전용 연구·개조 — D116

함재기 전용 연구와 기체별 개조/업그레이드를 제공한다. **공간 확대는 기체 지급이 아니다.** 기존 재고는 그대로이며 새 기체를 자원/시간으로 생산해야 빈자리를 채운다. 연구·기체 구매·개조 비용을 함선 기본 가격에 중복 포함하지 않는다.

| 시험 연구 | 최대 단계 | 단계별 효과 | r단계 비용 일반/고급/최고급 | 시간 | 선행 |
| --- | --- | --- | --- | --- | --- |
| 격납 효율 | 3 | 격납고당 함재기+2대, 최대26대 | 900r/180r/0 | 180r초 | 항공운용·직전 단계, 코어II/III/IV |
| 함재기 화력 제어 | 5 | 기본 공격+4%, 합계20% | 500r/100r/0 | 120r초 | 항공운용·직전 단계, 코어I/I/II/II/III |
| 함재기 생존 공학 | 5 | 최대HP+5%, 합계25% | 500r/100r/0 | 120r초 | 항공운용·직전 단계, 코어I/I/II/II/III |

연구소 큐를 사용한다. 현재는 능동 정기 귀환·유한 탄약을 새로 도입하지 않는다. 연구 완료 효과는 새 기체/다음 안전한 도킹·출격 때 동기화하는 기준안이며, 비행 중 재고/HP/쿨타임을 초기화하지 않는다.

기체별 통합 개조 패키지 후보는 공격+8%·HP+8%·회피+3%p, 비용18/4/0·기체당8초다. 격납고의 기체 정비 큐1개를 수리와 공유하며 도킹 상태에서만 가능하다. 기존 개체ID와 현재HP를 유지하고 새 최대HP로 상한만 조정한다. 연구/개조의 공격·HP 보너스는 각 기본값에 가산하며 회피의 시험 상한은70%다. 새 기체는30/6/0·12초 후보이며 개조는 별도 비용이다. 이 값은 사용자 요청을 구체화한 설계값으로 실제 경제/생산 검증은 별도다.

격납고 파괴는 그 안의 실제 보관 기체만 잃게 하고 외부 기체 재고를 다시 차감하지 않는다. 용량 감소/귀속 변경으로 초과 기체가 생겨도 중복 생성·즉시 삭제하지 않으며 대체 도킹/기지 이송을 사용한다. 함체별 설치 상한은 위 D126 규칙을 따르며, 기존 시험의 항모2/항공순양함4격납고는 대표 편제로서 항공순양함의 새 상한을 대체하지 않는다.

## 소유량과 전투 상태

같은 기체는 보관/출격/귀환/도킹 대기/관제 상실/완파 중 하나의 상태를 가진다. 출격은 **보관 수→출격 수 이동**이며 총 보유량 차감이 아니다. 완파만 영구 손실이다. 귀환/수리로 새 개체를 생성하지 않는다.

함재기는 플레이어가 개별 비행 조종하지 않고 AI가 교전한다. 일반 무장은 함재기를 표적 선정하지 않으며 PD와 적 함재기가 상대한다. 기체별 반경·고도·선회 방향과 돌입→이탈→재돌입 궤적으로 동일 원 궤도의 기차 행렬을 피한다.

## 출격·귀환·관제 상실

- 교전 시 가용 함재기 일제 출격. 부채꼴 등 분산 배치로 겹침을 피한다.
- **전투 중 정기 귀환·탄약 고갈·출격 지속 시간에 의한 강제 귀환을 요구하지 않는다.** 모함의 명시적 복귀 명령으로 함재기를 귀환시켜 수리할 수 있다. 기존 비전투5초 자동 귀환/재무장 의무는 이번 정책으로 대체하고 기본 자동 귀환 조건으로 사용하지 않는다. 무장 공급은 실시간 생산이며 수리 비용/시간·재출격 절차는 R23/R25다.
- 모함 FTL 충전 시 긴급 귀환 명령을 내린다. 기본 도약은 회수 완료를 기다리며, **잔여 기체 포기 후 도약**을 명시적으로 선택하면 충전 완료 후 미귀환 기체를 남기고 이탈한다. 남은 기체의 모함/관제 상실 처리는 별도 적용하며 포기 선택만으로 모두 완파/재생성하지 않는다.

| 사건 | 내부 보관 기체 | 외부 기체 |
| --- | --- | --- |
| 격납고 마비 | 보관 유지·출격 잠금 | 재수납 불가 |
| 격납고 파괴 | 해당 격납고 소형함/함재기 완파 | 소형함 정상. 함재기는 관제 시설이 살아 있으면 교전 지속, 해당 격납고 귀환/수리/재무장 불가 |
| 함재기 운용 시설 전부 가동 불가 | 함재기 신규 출격 불가 | 함재기 관제 상실로 정지, 시설 복구 시 재가동 |
| 모함 완파 | 내부 전부 완파 | 외부 함재기 정지. 외부 독립 소형함은 모함 내부 완파 규칙을 적용하지 않음 |

다중 격납고 대체 귀환·관제 상실 표류·회수 및 FTL 이탈 처리 상세는 R25다.

## 나포 시 소속과 가동 조건

함교 나포가 결정되면 모함과 관련 소유물은 다음과 같이 처리한다. 소속 변경과 수리/관제 복구를 혼동하지 않는다.

| 대상 | 결과 |
| --- | --- |
| 외부 출격 함재기 | 즉시 새 모함 세력으로 전환, 모함 관제를 따름. 고장난 관제/기체는 자동 복구하지 않음 |
| 내부 보급수리함·채굴선·함재기·자원 | 즉시 새 소유 측 귀속, 정상 가동 조건을 충족하면 사용 가능 |
| 내부 초계함·호위함 등 소형 전투함 | 무장해제된 중립 노획 상태. 보급수리함 승무원 주입 또는 전투 후 기지 회수로 정식 편입 |
| 선내 영웅·일반 경비/강습 병력 | 소속 유지, 재탈환·탈출 가능 |
| 선내 보안 터렛·로봇 | 긴 재부팅 후 새 세력 소속 |

독립 출격 소형함의 나포 연동 소속 전환은 위 외부 함재기 규칙으로 확대하지 않는다. 상세 미정은 R18이다.

## 시험 수치의 지위

함재기 hull 160/shield 75, 이탈 반경 55~85m, 긴급 귀환 속도 1.5배는 프로토타입 참조값이다. 회피 0.62와 확정된 곱셈 PD 관계는 R09, 실제 절대 스탯·티어/개조·정비 효율은 R16/R23에서 관리한다. [과거 개선 기록](../../05_references/PROTOTYPE_IMPROVEMENT_PLAN.md)이 현행 소유량 규칙을 덮어쓰지 않는다.

## 화면·개체별 격납고 표시 — D122

[UI 명세](../interface/UI_SYSTEMS.md)의 함재기 현황과 개별 기체 카드가 실제 격납고/기체ID를 읽는다. 시설 설치 상한·실제 설치·가동·공간·기체 소유량을 분리한다. 항공순양함은D121의 강한 주포를 가진 항공 전투함이며 전용 주포2문/격납고 최대6개(D126)다. 생존 기체 비율의 경보는 임시 표본 분모와 소유권 변경을 숨기지 않으며, 도킹/출격으로 손실 경보를 재발동하거나 전멸로 판정하지 않는다.

# 강습 운송·선내 작전·점령

> 현행 명세: 2026-11-16. 강습 수단부터 진입·선내 교전·나포·탈출까지 관리한다. 시설 기능은 [함선](../fleet/SHIP_SYSTEMS.md), 함재기/모함 귀속은 [모함 운용](../fleet/CARRIER_OPERATIONS.md), 영웅 유형은 [영웅](HERO_SYSTEMS.md)이 담당한다.

## 강습 수단과 탑승

포드는 발사 시설에서 보장 근거리 내 목표로 발사한다. **영웅·일반 병력 모두 탑승자 개인1명당 포드1기**다(D113). 영웅4명+일반 병력6명은 포드10기이며 일반 병력10명도10기다. 분대는 명령/표시 단위로 유지하지만 포드 하나에 분대 전체를 넣지 않는다. 각 포드는 탑승자ID·분대ID·개별HP·발사 시각·진입/귀환 상태를 가진다. 발사 직전마다 조건을 검사해 취소된 미발사 인원은 출발함에 남는다. 비행 중 수동 회항 가능, 회항 중에도 요격된다. 포드 발사 시설은 새 출격에 필요하지만 이미 출발한 포드의 귀환에는 필요하지 않다.

강습선은 **소형함·공격 무장0·요격 시스템1기**로 확정한다(D113). 방어력·속도·쉴드에 집중하고 적의 함포/빔/미사일에 노출된다. **PD는 함선인 강습선에 피해를 주지 않는다.** 시험 수치와12명(영웅최대4) 정원은 [통합v0.6](../../02_balance/INTEGRATED_COMBAT_BALANCE.md)을 따른다. 접안 중에도 대함 피격 대상이고 실제3D 도킹은 후속 구현이다. 포드와 같은 시설에서 발사하거나 반드시80m에서 포드로 환승한다고 확정하지 않는다.

보직 영웅·수호 분대는 자동 차출하지 않으며 명시적으로 전환/선택한다. 포드 크기 0.55 반지름/1.8 길이·발사 간격 0.25초는 프로토타입 참조값, 속도 약 165m/s·회피 0.40은 시험 기준값이다.

## 쉴드·장갑·진입 위치

- 적 쉴드를 통과할 수 없다. 포드 쉴드 충돌은 요격과 같은 탑승자 결과, 강습선은 자체 쉴드가 깎이며 진입 불가다.
- 장갑은 레이저 드릴로 뚫는다. 쉴드 없이 도달한 뒤 진입 자체에 실패 확률은 없다. 구멍 생성과 장갑 HP의 연동은 미정이다.
- 진입 전 내부 구조는 숨긴다. 진입 후 구조를 공개하되 적 유닛은 아군 시야 구역에서만 표시한다. 공개 유지 기간은 R26이다.
- **실제 도달 지점을 대상 로컬 좌표로 변환해 상면/하면/측면 구역을 먼저 분류**한다. 상면→최상층, 하면→1F, 측면→함체 데이터의 높이별 층 구역이다. 3층 측면 중앙 구역은2F이며 단층은 항상1F다. 모함의 월드Z나 단순 Z>=0 반구 판정으로 덮어쓰지 않는다. 구역 경계는 함체에 명시하고 모서리 귀속은 R17과 일관되게 검증한다.
- 외곽 슬롯 중 진입 지점을 확률적으로 선택한다. 동일 Wave의 후속 포드는 선도 진입 슬롯 또는 인접 슬롯에 합류한다. 선도 실패/진입실 파괴 시 재선정은 R18이다.

## 선내 단위와 이동·교전

영웅은 초능력자·강화인간인 개별 유닛, 일반 경비/강습 병력은 분대 명령 단위다. 능력의 원천이 달라도 목표 기반 자동 전투·실제 노드 이동·점령/공작 시간과 소속/영구 사망 규칙은 동일하다. 초능력으로 쉴드·벽을 무시해 진입하거나 함교를 즉시 원격 나포하지 않는다. 분대 사망·잔존 인원은 개별 인원별로 관리한다. 운영 승무원 게이지는 전투 유닛과 구분하며 피격·화재·감압으로 감소하고 점령 시 억류/비활성이다.

함체의 고정 방·문·복도·승강 샤프트 그래프에서 실제 거리 기반 이동을 한다. 적 전투 유닛/터렛/로봇과 만나면 자동 교전한다. 근거리 전열과 원거리 후열을 사용하고 표적 우선은 `플레이어 지정 → 자신/분대를 공격 중인 적 → 사거리 안 가까운 적`이다.

문 입구 교전 구역과 방 내부 제어 지점을 나눈다. 입구에서 적을 막는 동안 제어 지점의 작전이 가능하지만 방 안의 적 전투 병력을 몰아내야 한다. 점령 방해 범위·경로 봉쇄 상세는 R26이다.

함교·코어·생명유지 시설의 기본 경비 분대1개는 **출격 시 초기 방어 편제**이며 전투 중 재배치할 수 있다. 이를 작전 내내 이동 금지로 강제하지 않는다. 영웅 수비는 전체 세력3/6/10/15 지휘 예산과 함선 상주 편제를 공유한다(v0.5). 모든 함선에 최소1명을 자동 지급하지 않는다. 일반 소형/중형/대형/초대형의 출격 상주 한도1/2/4/6과 실제 수호/보직 분배는 [영웅 명세](HERO_SYSTEMS.md)를 따른다. 보안 터렛·로봇은 무인 개조 시설이며 나포 후 재부팅을 거쳐 소속이 바뀐다. 중복 시설별 초기 분대 배분은 R26이다.

## 점령·사보타주

| 작전 | 기본 게임 시간 |
| --- | --- |
| 일반 시설 점령 | 18초 |
| 함교 점령 | 36초, 물리 파괴된 함교는 불가 |
| 시설 파괴 공작 | 30초 |

인원·영웅 스탯으로 최대 50% 단축한다. 사보타주 중단 시 **진행률1/3·2/3 체크포인트**를 보존한다. 기본30초에서는10/20초, 50% 단축된15초에서는5/10초에 해당하며 절대10초 단위로 고정하지 않는다. 점령 중단의 보존 여부는 R26이다. 공작 30초를 완료하고 추가 무제한 공격 시간을 요구하는 별도 단계는 확정하지 않았다.

일반 시설 점령은 기존 소유 측의 기능을 마비시킨다. 정밀 사보타주는 시설을 물리 파괴하되 외장 장갑은 보존한다. 유폭을 유발했을 때 연쇄 시설/장갑의 원인 처리 상세는 R23이다.

## 함교 나포·재탈환

- 함교 점령 완료 즉시 소유/조종권 이전, 기존 명령 취소·정지. 이후 새 소유 측이 명령한다. 기존에 발사된 공격의 소속/경로는 소급 변경하지 않는다.
- 운영 승무원은 함교의 명령권 장치를 따르나 영웅·일반 경비/강습 분대는 원 소속 유지. 다른 방의 점령·파괴·무인원도 유지한다.
- **함교를 비우거나 유예 시간이 끝났다는 이유만으로 소유권을 자동 반환하지 않는다.** 잔존 적이 함교를 실제로 확보하고 점령 절차를 완료해야 재탈환된다. 함교 주둔은 방어 선택이며 강제 소유 유지 타이머가 아니다. 전체 인원 전멸에 따른 중립화·함교 파괴의 별도 전이는 유지한다. 기존30~60초 상주 유예로 자동 상실하는 안은 사용하지 않는다.
- 나포 상태의 함교가 외부 포격으로 파괴되면 그 방의 일반 병력 사망, 영웅은 큰 피해 후 인접 방으로 튕겨남(HP 0은 사망), 함선 중립 정지. 일반 함교 파괴의 자동 전투와 구분한다.
- 나포 직후 외부 적의 자동 표적 우선순위를 일시 낮추는 방향이다. 무적·피해 면역·발사된 공격 삭제가 아니다. 기간·수동 집중 공격 예외는 R18이다.
- 모함 소유물 귀속은 모함 운용을 따른다.

## 명령과 탈출 결과

상위 명령은 목표 점령/파괴, 수호, 우회, 방어 대기, 후퇴/비상 탈출이다. 경로가 없으면 알림을 제공한다.

| 사건 | 결과 |
| --- | --- |
| 출발 준비 실패 | 강습 취소 |
| 비행/귀환 중 포드 요격·쉴드 충돌 | 일반 병력 즉사, 영웅 우주 구조 대기 |
| 영웅 구조 대기 | 아군 구조 또는 적 납치. 시험안120초·150m·준비5초, 먼저 실제 확보를 완료한 유효 구조측에 귀속. 근접 동시 사건은 결정적 순서로1회 처리 |
| 비행 중 목표 완파·FTL 이탈 | 귀환 |
| 귀환 중 모함 완파·FTL 이탈 | 가장 가까운 아군 함선으로 목적지 변경, 발사 시설 없어도 도킹. 아군 전무하면 정지·구조 대기 |
| 정상 탈출 | 최초 진입 지점으로 돌아가 사용한 포드로 귀환 |
| 퇴각 경로 완전 차단 | 외곽 방에서 일정 시간 후 우주 비상 탈출·구조 대기 |
| 내부 작전/탈출 실패 | HP0은 사망, 생존 상태로 적에게 확보되면 포로. 단순 작전 시간 초과를 자동 사망/포로로 바꾸지 않음 |
| 내부 잔류 상태에서 함선 완파 | 영웅·병력 전원 사망. 우주 구조 예외 미적용 |

D116: 강습선이 탑승자를 내부로 이송하기 전에 완파되면 일반 병력은 사망, 영웅은 포드 격추와 같은 구조 대기로 처리하는 시험안을 쓴다. 진입을 끝낸 인원은 수송선 완파 때문에 원격 사망하지 않는다. 직접 접안은 준비3초 후보이며 PD가 강습선 선체를 공격하지 않는다. 정상 포드 귀환은 원 진입 장소까지 **실제 이동** 후 시작한다. 비상 탈출은 외곽 방에서 준비15초 후보이며 봉쇄·피격·소속 조건을 검사한다. 실제 비상 탈출/포로 확보의 모든 경로는 후속 공간 검증 대상이다.

강습선으로 진입했다면 원 진입 지점에서 **같은 강습선의 회수**를 우선한다. 준비/접근 시간을 거쳐 재탑승하며 포드 귀환의 PD 판정을 적용하지 않는다. 강습선이 파괴·적 소유 등으로 회수 불가하면 외곽에서 비상 탈출을 준비한 뒤 영웅은 구조 대기, 일반 병력은 이 시험의 우주 생존 규칙에 따라 사망한다. 사용하지 않았던 강습 포드를 새로 생성해 무료 귀환시키지 않는다. 미래의 다른 강습선 지원/밀폐 문/다중 회수 경쟁은 별도 검증한다.

귀환 도착 슬롯은 발사 시설/격납고 또는 안전한 아군 통제 슬롯을 사용한다. 원 모함이 파괴/도약/적 소유가 됐으면 유효한 아군 목적지를 다시 선택하고 추가 비행 시간을 계산한다. 순간 귀환·적함 자동 도킹으로 처리하지 않는다. 우주복의 생명유지 면역/저항 수치는 R26이다. 중요 사건 자동 일시정지는 [전략·경제](../strategy/STRATEGY_ECONOMY.md)를 따른다.

## 전투 연동과 작전 AI — D116

외부전/선내전은 같은 게임 시간을 쓴다. 강습 대상의 **진입부터 탈출까지 생존 시간**을 전체 전투 종료 시간과 따로 측정한다. 방별 이동·전열/후열·치료/공격/점령/후퇴 우선순위를 시험하고, 외부 포격/시설 재난이 내부 인원에게 영향을 준다. 일반 시설18초·함교36초·공작30초와 단축 상한50%를 유지한다. 공작 체크포인트는1/3·2/3, 일반 점령 중단은 진행 초기화하는 시험안이다.

치료는 사거리/시야 안HP50% 이하의 살아 있는 아군 중 가장 위급한 대상을 우선한다. 회복 자원/쿨타임을 보직 전환·이동·레벨업으로 초기화하지 않는다. 후퇴 명령은 점령/공격보다 우선하며 영웅 생존을 보장하는 순간이동은 없다. 자동 철수 후보는 대상 선체25% 미만 또는 작전 영웅1명 이하이며 **실제 관측/아군 통신 정보**에 의존한다. 정밀 외부 HP 추정이 불가능한 실제 UI에서는 관측된 치명 손상 경보로 연결한다.

내부 구조는 진입 후 공개하되 적 영웅 수/레벨을 전체 로스터로 공개하지 않는다. 발견한 구역의 적과 능력 사용만 관측하며, 방어AI도 알람/시야로 침투에 대응한다. 보직 영웅을 수호로 전환하면 해당 외부 보직 효과가 즉시 사라진다. 재탈환은 생존 병력이 실제 함교/시설을 확보해야 하며 시간 경과만으로 소유가 반환되지 않는다.

## 첫 통합 검증 목표

고도별 진입·정보 공개 → 통로/경비 교전 → 쉴드실 점령/공작 → 3D 쉴드 해제 → 포격 → 정상/비상 탈출을 끝까지 수행한다. 이 목표는 3단계이며 2B에 강습 완성을 요구하지 않는다. 미결정은 [R18/R26](../../00_overview/OPEN_QUESTIONS.md)에서 관리한다.

## 초기 수치 시험과 구분

[전투 수치v0.2](../../archive/balance/COMBAT_BALANCE.md)은 병사4명/분대·역할별HP/회복·포드HP·대표 통로 거리·작전 가속의 시험 제안이다. [연동 모형](../../archive/analysis/COMBAT_SIMULATION.md)에서는 함대 승리와 점령/생환을 별도로 집계했다. 1D 교전/대표 경로이며 실제 방/문 그래프·전열·재탈환·강습선·포로·구조 회수·화재/감압은 미검증이다. 확정된 18/36/30초·최대50% 단축·체크포인트 비율을 새로 바꾸지 않는다.

초기 장기전 후속 검토(D112)는 [v0.3 수치](../../02_balance/FLEET_ENDURANCE_BALANCE.md)와 [전 함종 코스트 분석](../../04_analysis/FLEET_ENDURANCE_RESULTS.md)을 따른다. 일반전 목표10~15분으로 이전 짧은 외부전 목표를 대체했던 기록이다. 현재 D116의 적용 필드/검증은 [통합v0.6](../../02_balance/INTEGRATED_COMBAT_BALANCE.md)을 따른다. UE 구현 완료가 아니다.

D113의 [강습 재검토](../../04_analysis/BOARDING_REVIEW.md)는 영웅 수 비교·개인별 포드·강습선 대함 피격을 분리 시험한다. 이전v0.3의 공격4영웅/방어0영웅·경비8명 및 일괄 포드 도착 모형을 현행 개인별 운송 규칙의 구현 완료로 간주하지 않는다.

D114/v0.5 후보: 강습팀 총12명·영웅최대4명·나머지 일반 병력(4영웅이면8병사, 영웅0이면12병사), 강습선도 총12명(영웅최대4)이다. 이 정원은 전투 함선의상주/보직 좌석과 별개이며 전체세력 영웅15점은 항상 공유한다. 일반 분대4명도 개인별 포드4기를 쓴다. D116의 [통합 시험](../../04_analysis/INTEGRATED_COMBAT_RESULTS.md)이 새 성장/스킬/공간 정원의 적용 범위를 관리하며 과거 결과와 구분한다.

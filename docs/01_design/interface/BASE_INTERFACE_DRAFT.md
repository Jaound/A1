# 기지 전용 인터페이스 v0.2

> 2026-11-24 · 전용 3D 기지 화면과 자유 전환은 확정이다. 패널 구성과 세부 조작은 구현 검증과 함께 조정한다. 배치와 운영 규칙은 [기지 통합 명세 v1.0](../strategy/BASE_MASTER_GDD.md)을 따른다.

## 화면 구성 제안

| 위치 | 표시와 조작 |
| --- | --- |
| 상단 | 기지 이름·코어 티어, 자원 3종의 보유량/저장 한도, 기능·연결 한도, 시간 제어 |
| 좌측 | 모듈 이미지 카드. 연결·생산·접안/물류·연구/인원·방어 분류. 잠긴 카드에는 해금 조건 표시 |
| 중앙 | 입체 기지와 활성 높이의 25m 격자. 회전·팬·줌, 배치 미리보기, 연결·방호·출입로 오버레이 |
| 우측 | 선택 시설의 상태, 가동 조건과 작업. 조선소는 작업칸과 건조/개조, 창고는 저장량과 개별 증설, 접안 모듈은 점유와 출격 표시 |
| 좌하단 | 건설·연구·조선 작업을 종류별로 전환해 표시. 선택 시 해당 모듈에 카메라 이동 |

기지 화면의 기본 모드는 운영이다. 건설 모드 진입 시 카메라 조작을 유지하며 모듈 배치 입력을 활성화한다. 세력 전체 영웅 명단을 공유하고, 아카데미에서는 영입·훈련·치료 작업으로 연결한다. 자원 수치는 숫자용 고정폭 서체를 사용할 수 있게 구성한다.

## 건설 흐름

1. 모듈 카드를 선택하면 연결 가능한 포트와 본체 미리보기를 표시한다. 시작 배치 평면은 Z=0이며 Q/E로 90° 회전, PageUp/PageDown으로 활성 높이를 ±25m 이동한다.
2. 미리보기에서 본체, 연결 통로 제안, 조선·접안 출입 여유와 외곽 개방선을 구분한다. 자동 연결 제안은 확정 전에 경로, 통로 수와 합산 비용을 표시한다.
3. 공간·소켓·코어 연결·연구·자원·동시 건설·설치 한도를 현재 상태로 검사한다. 예를 들어 ‘접안 출입로 막힘’, ‘고급 자원 500 저장 공간 부족’처럼 원인과 필요한 조치를 표시한다. 색과 문구를 함께 사용한다.
4. 확정 시 자원·공간·연결 포트·한도를 함께 예약한다. 통로는 15초가 걸리며 기능 모듈의 동시 건설 슬롯은 사용하지 않는다. 공사 취소와 완성 모듈 철거의 예상 환불을 각각 표시한다.
5. 순환 연결의 한 통로가 끊겨도 우회 연결이 있으면 가동 상태를 유지한다. 마지막 코어 경로가 끊기면 어떤 생산·연구 작업이 정지했는지, 방어 시설에 비상 사격 시간이 얼마나 남았는지 표시한다.

## 기지와 함대 전환

상단의 기지·함대 화면 전환으로 두 화면을 자유롭게 오간다. 기본 구현은 전환 시 각 화면의 카메라·선택·작업 상태를 보존하고 공통 게임 시간과 배속을 사용한다. 전환 자체로 자동 정지하거나 전투를 재시작하지 않는다. 기존 긴급 경보 정책은 유지한다. 기지 배치 입력이 함대 명령으로 전달되지 않도록 화면별 입력을 분리한다.

## 제작 범위

기지 시스템과 전용 화면, 기지 모델 반입·교체를 먼저 제작한다. 캠페인, 튜토리얼, 고정 시작 플레이·첫 목표는 후속 단계에서 설계한다. 이번에 사용하는 코어 I와 임시 자원은 건설 검증용 값이다.

- 배치·건설 검증에는 코어, 통로, 분기 허브, 창고를 사용한다. 모듈 확장 시 조선·접안 출입로와 코어·방호·접안 쉴드를 차례로 연결한다.
- 에셋 교체 시 25m 점유 격자, 전방과 피벗, 소켓 위치, 출입 공간을 다시 측정한다. 참고 모델의 외형과 실제 건설 판정은 별도로 검증한다.

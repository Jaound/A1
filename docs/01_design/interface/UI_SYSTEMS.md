# UI·카메라·입력

> 현행 명세: 2026-11-16. 게임 규칙은 담당 시스템에서 읽으며 UI가 피해·소유권·점령을 별도 계산하지 않는다. 기술 격리는 [UE5 기준](../../03_development/UE5_IMPLEMENTATION_CONTRACT.md), 현재 구현은 [구현 상태](../../03_development/IMPLEMENTATION_STATUS.md)를 따른다.

## 전투 정보와 공격 의도 — D116

자기 세력의 영웅·기체·화물은 정상 조회한다. **적 영웅 총수/레벨·함재기 총 재고·수리 화물·편성 코스트는 자동 공개하지 않는다.** 실제 탐지한 함체·발사/출격 행동·시야 안 인원 등 드러난 정보만 제공한다. 정보가 없으면 `미확인`이며0명/빈 화물로 표시하지 않는다. 개발용 전체 진단/분석 보고서는 별도 권한이고 전투AI/HUD에 공급하지 않는다.

함선 명령에 `선체 격파 / 무장 무력화`와 표적별 `계속 사격 / 목표 달성까지 보류 / 영웅 이탈까지 보류`를 표시한다. 보호 중 강제 무장 공격은 명시적 명령과 상태 표시를 사용한다. 유효한 관측 무장이 없으면 완료/대기 사유를 보여주고 자동 선체 공격으로 바꾸지 않는다. 구조 대기·포로·사망·귀환을 같은 성공 표시로 합치지 않는다.

## 영웅 능력의 표시 — D115

영웅은 움직이는 2D 설계도 위의 애니메이션 캐릭터로 표현한다. 4개 유형과 능력 원천(초능력/강화/복합)을 구분해 표시하고, 스킬 명칭은 [영웅 명세](../boarding/HERO_SYSTEMS.md)의 현행 명칭을 사용한다. 역장·초감각·재생·신경 공명 연출은 판정 이벤트를 읽으며 별도 피해/회복을 실행하지 않는다. 소모품은 **재생 촉매 잔량**, 보직 정비는 **정비 증폭기 충전/수리 재료**를 구분한다. 원천은 현재 설명용이며 추가 스탯을 뜻하지 않는다. 미공개 적 시설·적 영웅 정보를 초감각 연출로 노출하지 않는다.

로컬 구현과 비교할 때는 [2A 조작 가이드](PHASE2A_GUIDE.md), [2B 시험장 가이드](PHASE2B_GUIDE.md), [검증 결과](PHASE2B_VALIDATION.md)의 소스/기획 기준을 함께 확인한다. 2026-11-16의 `80eaf88`은 최신 정책 정렬 전 작업 보존 지점이며, 아래 독립 자동화 등 현행 명세가 모두 적용됐다는 뜻이 아니다.

## 화면 구성과 창 수명

| 영역 | 역할 |
| --- | --- |
| 상단 전략/시간 바 | 성계명·3등급 자원·정지/1/2/3배속·지도·개조·저장 |
| 사건 배너 | 자동 일시정지 원인·요약·현장 이동 |
| 메인 3D 전장 | XYZ 함대전·사거리·고도·표적·상태 오버레이 |
| 함선 상세 플로팅 창 | 외부/무장 3D ↔ 층별 2D ↔ 격납고 |
| 하단 지휘/요약 | 모드·명령·표적·공급 상태·전투 로그·다중 선택 카드 |
| 좌측 아웃라이너 | 함종·HP/쉴드·상태, 클릭 선택·더블 클릭 카메라 이동 |

상세창은 **이동·리사이즈·최소화·최대화·닫기·최대 2핀** 가능한 플로팅 창이다. 우측 25~30%, 전장 약 70~80%는 초기 배치 예시이며 고정 화면 분할이 아니다. 선택 해제 시 비고정 상세창을 숨긴다. 핀 예외·닫기 후 재선택·선택 변경 시 창 교체 정책은 R13이다. 미선택 ‘100% 전장’은 상세창 점유 제거를 뜻하며 상단 바/알림까지 모두 숨긴다는 뜻이 아니다.

## 카메라·입력 — 현재 채택과 목표 구분

2A 보완 `be544d7`에서 PlayGame3 프로필이 기본이며 P/상단 버튼으로 Legacy와 비교한다. 사용자가 조작을 직접 확인했다. 원본 수치·변환은 [이식 참조](../../05_references/PLAY_GAME_3_CONTROLS.md), 정확한 현재 키/값은 코드 브랜치의 [조작 가이드](https://github.com/Jaound/A1/blob/be544d7/docs/PHASE2A_GUIDE.md)를 따른다. 과거 이식안은 미적용 상태를 설명하는 당시 기록이다.

- 기본 카메라는 기준점 궤도 회전·줌 연동 pan·F 추적. 평면 수동 이동 시 추적 해제.
- 전장 또는 상세 프리뷰에서 시작한 회전 제스처는 그 화면이 버튼 release/취소까지 소유한다. Alt 선해제·포커스 상실·창 밖 해제를 정리한다.
- PlayGame3 이동은 RMB press 위치의 함선 고도 평면 XY를 고정 → 드래그 Z → 전장 release 시 한 번 확정한다. 휠은 카메라 줌이다. V/Enter 정밀 모드는 별도 유지한다.
- 적 우클릭의 작은 흔들림은 표적 우선, Shift 강제 이동을 분리한다. 표적 지정은 발사 요청이 아니다.
- 실제 레이 기준면과 디스크를 일치시킨다. 8px 고도 표시 임계·25px 적함 표적 임계는 현재 참조 동작이며 좌표/DPI/입력 경계와 함께 검증한다.
- 이동 입력·표적 지정이 소비한 클릭으로 선택을 다시 해제하지 않는다. UI 입력은 전장 명령/카메라로 투과하지 않는다.
- 빈 전장 클릭 선택 해제, F 추적, R 수리 대상, 1~9 부대 선택/Ctrl+1~9 저장, F1~F4 시간 제어(현재 F1 정지·F2/F3/F4=1/2/3배), Space 정지 보조를 분리한다.
- 무장 그룹은 논리 그룹 1~3이지 숫자키 1~3 확정이 아니다. Q/E·고도 키·Tab·ESC·추가 발사 키의 최종 배치는 R13이며 기존 설정과 충돌시키지 않는다. ESC PIE 종료와 게임 취소를 구분한다.

## 3D 전장 표시

- 함선 오버레이: 이름·이동/공격 각각의 수동/자동·쉴드·선체 HP·FTL 충전·강습 중. 포드·구조 영웅 SOS/남은 시간은 해당 정책 확정 시 표시한다.
- 대표 함선 한 척의 보장 근거리(점선), 무장 사거리(실선), 레이더 탐지(보라 대시)를 구분한다. 다중 선택에서 모든 범위를 중첩하지 않는다.
- 개별 무장 선택 시 위치·사각·수평 링/수직 아치 강조. 공격 표적 마커와 조준선, 발사 가능/불가 원인·재사용 상태를 표시한다.
- 이동 프리뷰: 전술 디스크·교점 링·고도 기둥·경로, 목적지 사거리/ETA. 표시 위치와 실제 확정 위치는 같다.
- 먼 줌/센서 토글에서 전술 심볼·Z=0 고도선·레이더 구체·경로를 강조하고 이름표 LOD를 적용한다. 줌 임계·전용키는 미정이다.
- 심리스 줌으로 성계/은하 지도까지 연결하는 것은 장기 목표다. M 지도 창은 초기 접근 수단이며 즉시 제거하지 않는다.

## 지휘 HUD

요약은 함종/소속·HP/쉴드·속도·포탄/빔/미사일 **공급 상태**·공격 목표·이동/공격 각각의 자동화 상태다. 유한 재고인 기체·병력과 탄약 공급을 혼동하지 않는다.

이동 자동/수동과 공격 자동/수동을 따로 설정하며 전체 자동/수동 버튼은 두 설정을 함께 바꾸는 프리셋으로 유지한다. 혼합 상태도 표시한다. 자동 공격은 이동 수동 상태의 경로/자세를 빼앗지 않으며 PD는 항상 자동이다. 현재2A 단일모드가 이미 이 기능을 지원한다고 표시하지 않는다.

3×4 커맨드 카드와 단축키 배지를 지향하며 함종/시설 조건에 따라 활성화한다. 필요한 명령은 수동/자동, 이동/정지, 표적 지정/해제, **발사 요청**, 선체 방향/자세(유지·정면·좌/우현), 과부하·열, PD 우선순위, 강습/회항, 호위, FTL/편대 동시 도약, R 수리 지정이다. 발사 차단은 최소한 **무장 사거리 부족 / 유효 탐지 없음 / 포탑 정렬 중 / 아군 사선 차단 / 제어·공급 시설 정지 / 개별 무장 파괴 / 재사용 대기**를 구분해 보여준다. 버튼이 있다는 이유로 미구현 기능을 작동 가능 표시하지 않는다. 강습선은 포드 시설 하나만으로 활성화하지 않으며 운용 조건 확정이 필요하다.

## 상세창

### 외부/무장 3D

기본 진입 화면이다. 읽기 전용 프리뷰 회전/줌과 스튜디오 내구도 뷰 ↔ 실시간 전장 캠을 제공한다. 함선 자세·로컬 포탑각·발사 섬광·피격 스파크/화재·쉴드 파동을 원 시뮬레이션에서 동기화한다. 내구도 색은 초록→노랑→빨강→회색이다.

무장 클릭 정보는 이름·계열/종류·티어·HP/상태·위치/사각·사거리·공격력·조준 목표이며 전장 범위 표시와 연동한다. 6면 피격 방향 펄스/화살표, 위험 구획 Shift+클릭의 수리/층 바로가기를 지향하되 지원 함선·정보 접근 조건을 검사한다.

실제 게임 액터를 프리뷰에서 복제 시뮬레이션하지 않는다. UE 구현은 SceneCapture/RenderTarget 또는 표시 프록시 등으로 선택한다. Godot의 SubViewport/own_world_3d는 UE API가 아니다.

### 층별 2D 설계도

실제 함체 층수만큼 1F/2F/3F 버튼을 노출한다. 위기 층은 테두리/! 배지로 알린다. 코어/함교·승강 샤프트·방/문/복도·시설 HP·운영 승무원·점령/공작 진행·유닛 HP/애니메이션·보안 재부팅을 표시한다. 문 입구와 제어 지점은 구분한다.

진입 전 적 내부는 숨기고 진입 후 구조만 공개하며 적 유닛은 아군 시야 범위에서 표시한다. 툴팁·로그·피격 리포트·3D 뷰어로 숨긴 시설/인원을 유출하지 않는다. DEV 공개는 실제 플레이와 별도다.

명령은 점령·공작·우회·수호·대기·포드 후퇴·비상 탈출이다. 영웅/분대 로스터에서 보직과 전투 투입, 탑승 선택을 지원한다. 강습 중인 적함 바로가기와 `[영웅/분대 HP·목표·진행률]` 미니 트래커를 제공한다.

### 격납고

수납 소형함 이름/함종·HP/자체 수리·재수납 쿨타임·개별 출격, 각 격납고의 소형함1척/함재기20대 용도와 점유량, 함재기 보관/출격/정지/손실 수·일제 출격/명시적 복귀·수리 상태를 표시한다. FTL 회수 대기 및 잔여 기체 포기 후 도약을 명확히 구분한다. 중립 노획 전투함은 출격 잠금으로 표시하며 소유량 계산은 모함 시스템에서 읽는다.

## 전략·개조·리포트·개발 도구

M 지도는 성계·항로·소유·전초 전문화·자원·FTL 파견, B 개조는 건조 비용·시설/무장 배치 검증·영웅 영입/편대 설정을 제공한다. 강제 삭제 차단 조건은 함선 설계 규칙에서 읽는다.

호버 툴팁은 탐지 가능한 함종·쉴드/장갑·레이더 포착·포드 사거리만 제공한다. 전투 중/후 무장 계열별 피해 리포트, 중요 전황 무전/텍스트를 지향한다.

DEV 소환·AI 동결·전장 초기화·직접 피해/수리 도구는 시험 전용이다. F9 패널은 과거 후보이며 현재 로그 키와 충돌하지 않게 한다. 전장 캠·핀·리포트·전략 화면은 전체 목표이며 2A Canvas 도식의 완료 범위가 아니다.

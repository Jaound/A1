## 5. 비정형 최종 3D 모델링 교체 파이프라인

1. 본 문서의 JSON(`OVModularBaseStructure_v1`)으로 UE 5.8 그레이박스(정확한 가변 체급 박스 + 가느다란 통로 + 출입 여유 공간)를 먼저 생성합니다.
2. 3D 모델러는 각 모듈의 **최대 외곽(cm)** 과 **전방 출입 여유 구역**을 침범하지 않도록 모델링하고, 소켓 중심에 `Socket_*` 빈 노드와 `SocketCollarDepth` 완충 플랜지를 배치합니다.
3. 최종 FBX 임포트 시 본 규격의 `UCX_*_Hull_01` / `InteriorNav_01` / `LaunchClearance_01` 검증을 통과하면 기존 배치 코드 수정 없이 즉시 교체됩니다.

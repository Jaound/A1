## C/D 실제 기능 검증

첫 C/D 빌드24.06초 성공 뒤 자동67개 중66개가 통과했다. 배치 버전 변경으로 막힌 인원의 상태를 시설 수호 분기가 덮어쓰던 결함을 수정했고, 다음 빌드6.23초와 자동67/67이 통과했다. 선내 PIE API36/36도 통과했다. 첫 API 실패는 포드 발사 시설 없는 vector를 고른 시험 편성 오류였으며, 포드 시설이 있는 기존 편성으로 바꾸고 실제 발사 수를 검사하도록 보완했다. 초기 쉴드 제거는 C 단위 시험의 명시 fixture이며 D의 실제 무장 시험을 대신하지 않는다.

## 최종 검증과 한계

CD4 기능 빌드19.98초, 기존2A57/57·종합79/79·2C77/77·선내36/36·통합29사례316검사 모두 재통과. CD5는 시설 소속 상속값을 잘못 가정한 검사 기대와 Runtime/DEV 문구만 수정했으며 빌드17.33초·자동69/69 성공이다. 기존56자동 ID를 모두 보존하고 C9/D4를 추가했다. 한국어 엔진 자체 검사15건은 프로젝트 검사 실패와 분리한다. MSVC14.51.36260/설치14.51.36231, SDK10.0.26100.0을 사용하며 선호 버전 경고를 숨기지 않는다.

신규 마지막2검사는 실제 영웅/일반병의 강습선 나포·완파·FTL 및 내부 잔류 목표의 FTL 정지/원운송 기록/후속 실제 완파를 확인한다. 이탈 후 선내 작전이 몰래 계속되던 결함을 수정했다. 실제 성계 여행은 구현하지 않았다.

최종 [통합 사례](validation/Phase3D-Final.json), [복수시드 비교 집계](validation/Phase3D-Comparison.json)에 쉴드 제거·운송 생존·내부 작업 시간·철수 회수율·세력별 함선/영웅/병력/기체 손실이 있다. [선내API](validation/Phase3C-API.json)와 회귀57/79/77 증거는 같은 폴더에 보존했다. 최종 [화면](validation/Phase3-Screens/02_실제_선내지도.png)은 실제 렌더이며 입력 성공이나 임무 완주 증거를 대신하지 않는다. 기본 플레이의 기체별 관제 문구 중첩을 선택 아군 모함 요약으로 바꾼 전후 화면도 보존했다.

기존 대함/공중전 공유 경유점과 무제한 우선 추격을 분리했다. 표적 현재 위치·자세 기준 접근/짧은 이탈/선회·재집결, 실제 속도와 유한 선회, 4기 소편대의 서로 다른 경로/시차를 사용한다. 명시 복귀·관제/모함 상실·소속·보호·완파·이탈 경계는 재사용한다. DEV 모드에서만 구역/상태를 표시한다.

## B 최초 계측과 직접 입력

메모리1887→1967MB, UObject52080→52179(최대52422), 기체이벤트256/PD128/대함128 상한을 관측했다. 짧은 편성 변경 실험만으로 누수 여부를 확정하지 않는다. 600초 연속 실행과 최적화 전후는 아직 진행 전이다. CPU trace는 한국어 경로 오류로 실패했고 CSV는 정상이며, 추적 출력 경로를 ASCII로 고쳐 재검증 예정이다.

별도 플레이 창 직접 화면 캡처가 두 번 모두 `window capture timed out: timed out waiting on channel`로 실패했다. OS 입력을 주입하지 않았으며 실제 입력은 미검증이다. 이후 API/렌더 증거와 혼동하지 않는다.
